# Медиа страницы приложения

Готовые иллюстрации подготовлены настоящим игровым рендерером, без аккаунта и серверных действий. Показан возможный прогресс: дом 2, мастерская 1, шахта 1, лесной участок 1. Мост и маяк сохраняют начальные состояния; остальные здания берутся из Tiled.

| Файл | Размер | Назначение |
|---|---|---|
| `poster.webp` | 1440 × 900 | Полянка с домом, кустом и Мохликом |
| `map.webp` | 1600 × 1600 | Дневная панорама, около 334 КБ |
| `map-night.webp` | 1600 × 1600 | Вечерняя панорама с освещением, около 346 КБ |
| `media.json` | JSON | URL, размеры, описания, уровни; `video: null` |

## Повторная подготовка

`scripts/prepare-site-media.mjs` читает текущие данные `features/world/tiled/forest.generated.json` и изображения из `public/world/`. Используются игровые compositor, освещение, перекрытия, тени и спрайт Мохлика. Скрипт готовит только три WebP и метаданные; видеозапись не создаёт.

Нужны зависимости проекта и отдельный Canvas для подготовки медиа. Canvas не требуется production-приложению и не добавлен в его зависимости:

```bash
npm install --prefix /tmp/zhiv-site-render @napi-rs/canvas@0.1.100
SITE_MEDIA_NODE_MODULES=/tmp/zhiv-site-render/node_modules node scripts/prepare-site-media.mjs
```

Canvas также ищется в `CODEX_PRIMARY_RUNTIME_NODE_MODULES`. `esbuild` и `sharp` берутся из зависимостей проекта. После изменения карты сначала выполните `world:export` / `world:check`. Проверьте три результата и относительные точки мест на панораме. Подготовка медиа не входит в обычную сборку сайта.

## Будущая видеопрогулка

Прежний синтетический MP4 удалён. На сайте стоит неинтерактивный `SiteVideoPlaceholder` в `features/site/site-demos.tsx`, с текстом «Скоро здесь появится видеопрогулка». Он не загружает видео и не показывает кнопку воспроизведения.

Когда будет готова настоящая запись, замените этот компонент на проигрыватель и задайте его источники отдельным изменением. Сохраняйте постер, явный запуск, `playsInline`, стандартные controls, обработку сетевой ошибки и паузу при скрытой странице. Скрипт подготовки иллюстраций не должен перезаписывать авторский ролик.
