# Медиа страницы приложения

Это подготовленные игровые иллюстрации, а не запись аккаунта или интерактивного прохождения. Заголовок ролика — **«Видеопрогулка по полянке»**. Камера, ходьба Мохлика и ускоренная смена освещения поставлены специально для презентации; данные игрока и экономические действия не используются.

| Файл | Размер | Назначение |
|---|---|---|
| `poster.webp` | 1440 × 900 | Главный кадр: дом-пень, куст и Мохлик |
| `map.webp` | 1600 × 1600 | Дневная панорама текущего мира |
| `map-night.webp` | 1600 × 1600 | Та же панорама с вечерним освещением |
| `forest-tour.mp4` | 854 × 480, 12 секунд, 20 fps | H.264 / yuv420p, около 330 КБ, без звуковой дорожки, faststart |
| `media.json` | JSON | URL, размеры, альтернативные описания и показанные уровни |

## Источники и повторная подготовка

`scripts/prepare-site-media.mjs` читает актуальный `features/world/tiled/forest.generated.json` и исходные изображения из `public/world/`. Статика и кадры ролика рисуются настоящими `paintFixedWorld`, `drawBuildingDetails`, `drawForestLighting`, `drawForestLightEmitters`; геометрия, перекрытия, тени, спрайт Мохлика и точки света берутся из игры. Новая графика и ручная расстановка зданий не добавляются.

Показан возможный игровой прогресс: дом 2, мастерская 1, шахта 1, лесной участок 1. Мост и маяк сохраняют начальные состояния: их восстановление ещё не доступно в экономике. Остальные здания используют уровни из Tiled. Смена дня и вечера в ролике ускорена и не показывает длительность игровых суток.

Нужны Node.js, зависимости проекта (`npm ci`), системный `ffmpeg` с `libx264` и отдельный Canvas для подготовки медиа. В проверенном окружении: `@napi-rs/canvas` 0.1.100, FFmpeg 6.1.1. Canvas не нужен веб-приложению или production-сборке, поэтому он не добавлен в зависимости приложения. Его можно поставить отдельно:

```bash
npm install --prefix /tmp/zhiv-site-render @napi-rs/canvas@0.1.100
SITE_MEDIA_NODE_MODULES=/tmp/zhiv-site-render/node_modules node scripts/prepare-site-media.mjs
```

Скрипт также находит Canvas в `CODEX_PRIMARY_RUNTIME_NODE_MODULES`, когда эта переменная задана средой. `FFMPEG_PATH` позволяет указать другой исполняемый файл. Только картинки: `node scripts/prepare-site-media.mjs --stills-only`. Сборщик TypeScript (`esbuild`) и `sharp` берутся из установленных зависимостей проекта. Временный bundle удаляется после работы; исходная карта и игровые ресурсы не меняются.

Для мобильной загрузки дневная панорама кодируется в WebP quality 30 с сохранением 1600 × 1600. Ролик сначала рисуется в 720p, затем сжимается в два прохода H.264 до 480p/20 fps при 210 кбит/с; изображение немного мягче исходного рендера, зато весь ролик занимает около 330 КБ.

После обновления карты сначала выполните штатные `world:export` / `world:check`, затем этот скрипт. Просмотрите три картинки, начало/середину/конец ролика и его характеристики через `ffprobe`. Скрипт не входит в обычную сборку сайта: готовые компактные файлы хранятся в Git.

## Подключение

Задавайте картинкам явные размеры, чтобы они не сдвигали страницу. Видео должно иметь постер и понятную кнопку воспроизведения; не загружайте MP4 до взаимодействия пользователя. При `prefers-reduced-motion` сохраняйте статичный кадр до явного запуска. Панорамы подходят для лёгкого переключения дня/вечера без загрузки игрового движка. Карта и медиа не заменяют реальные данные аккаунта.
