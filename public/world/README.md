# Изображения, загружаемые игрой

Все редактируемые PNG находятся за пределами `public/`: **[art/README.md](../../art/README.md)** содержит полный каталог и порядок ручного экспорта.

| Каталог | Кто использует | Содержимое |
| --- | --- | --- |
| `prototype/` | `/prototype/tiled-world` и редактор Tiled | Семь WebP: `forest-ground`, `home-level-1/2/3`, `workshop-empty`, `workshop-level-1/2` |
| `runtime/` | Основное приложение | Карта, два быстрых превью, детальная поляна и лодка; имена включают хеш содержимого |
| `routes/` | Экран лесной прогулки | `trail.webp` |

## Обновление нового мира

Редактировать `art/world/prototype/<name>.png`, самостоятельно экспортировать целое изображение в `public/world/prototype/<name>.webp`, затем выполнить `npm run world:export` и `npm run world:check`. Эти команды проверяют и обновляют ссылки, **не перекодируют изображения**. Готовые PNG и WebP имеют одинаковую композицию; вырезать дом из полной поляны больше не требуется.

Обычная игра продолжает использовать собственные изображения через `features/world/runtime-art.json` и `features/world/art.ts`. Подготовка её WebP — отдельный `scripts/prepare-world-assets.mjs`, исходники — `art/world/main/`. Нельзя менять байты файла с хешем в имени, сохраняя старое имя: это нарушает кеш. После подготовки скрипт обновляет реестр ссылок.

Идентификатор геометрии `forest-region-v3` в `map-manifest.ts` оставлен как ID версии разметки; это не имя файла. Детальная домашняя область основной игры: `(486, 514, 256, 256)`. Карта и кружок используют одни координаты.

Папки исходников `maps/`, `objects/` перенесены в `art/world/main/`; папка прототипа `tiled/` переименована в `prototype/`. Отдельная `routes/river.webp` удалена как неиспользуемая текущим кодом. Рисунок Мохлика, освещение, вода и прочие эффекты по-прежнему рисуются кодом.
