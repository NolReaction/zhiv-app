# Изображения, загружаемые игрой

Мастера фона и куста находятся в `art/world/prototype/`; пять уровней дома пока хранятся только как PNG в `public/world/prototype/`. Полный порядок экспорта: **[art/README.md](../../art/README.md)**.

| Файл | Назначение |
| --- | --- |
| `prototype/forest-ground.webp` | Единая новая карта для основной игры, круглой камеры и `/prototype/tiled-world`; 2560 × 2560, WebP без потерь |
| `prototype/home-level-1.png` … `home-level-5.png` | Пять вариантов дома; рисунок, рамка, точки и коллизия выбираются вместе из Tiled |
| `prototype/bushv1.png` | Размещённый прозрачный куст `clearing-bush-image`; ягоды, землю и влажность рисует код |
| `runtime/boat-wreck-lowquality.webp` | Сохранённая графика лодки; на чистой карте не отображается |
| `routes/trail.webp` | Иллюстрация лесной прогулки |

## Обновление карты

Редактировать текущий мастер `art/world/prototype/forest-ground.png`, затем выполнить:

```bash
node scripts/prepare-world-assets.mjs
npm run world:export
npm run world:check
```

Первый скрипт экспортирует полное изображение без потерь и обновляет реестр `features/world/runtime-art.json`. Все поля карты и её превью указывают на один WebP; версия в `?v=` меняется вместе с содержимым. `world:export` обновляет метаданные Tiled и данные сцены, не перекодируя изображение. `world:check` ничего не записывает.

Размер текстуры 2560 × 2560 отделён от логических координат мира 1254 × 1254. Круглая камера показывает область `focus` из Tiled. Дом и куст подключены отдельными изображениями; скрипт подготовки фона их не меняет. После замены PNG выполните `world:export`, чтобы обновить версию URL, затем `world:check`.

Навигация рассчитывается по Tiled-геометрии, а не по пикселям дорожек. Тени домов/куста, корзинка и костёр рисуются кодом; корзинку можно перенести точкой `Garden → berry-basket`. Не добавляйте копии этих эффектов на фон карты.
