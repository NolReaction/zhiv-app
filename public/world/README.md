# World artwork v1

Generated specifically for the Mochlik personal world, 2026-09-08. Pixel forest clearing and a 3×2 object atlas: house levels 1–3, workshop, signpost, empty cell. Converted from the generated PNG masters to WebP for on-demand loading. The atlas uses a neutral background key removed once by the Canvas texture loader; props are cropped to their alpha bounds and cached.

The character and retained gifts use the existing application pixel rig. No image generator is called at runtime. Paths include a version suffix so future art changes can use new URLs.
