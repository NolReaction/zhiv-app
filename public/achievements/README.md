# Достижения

Медали хранятся отдельными файлами: четырнадцать в SVG, прежний «Хранитель находок» в PNG. Не меняйте ID в имени: на него ссылается состояние аккаунта. В меню игрока показаны четырнадцать карточек; ступени развиваются внутри одной карточки.

Названия, цели, описания и подсказки собраны в [game-rewards.ts](../../features/game/game-rewards.ts). Компонент [achievement-medal.tsx](../../features/game/achievement-medal.tsx) загружает изображение по ID. Серый вид до получения и цветной после него задаёт [game-achievements.module.css](../../features/game/game-achievements.module.css).

Для изменения размера сохраняйте `viewBox`, внутренние пропорции и прозрачный фон. Новые восемь SVG используют общую зелёную эмаль и золотой обод, каждый со своим рисунком. Ступень и подтверждённый прогресс показывает карточка, без отдельных файлов на каждый уровень.

Карточки открываются по серверным датам выдачи, включая выдачу модератором. Заполненная полоса без даты не открывает медаль. У рецептов и трёх биомов прогресс начинается с появления достижений: прежняя подробная история не восстанавливается. «Счастливая находка» требует новой личной находки после обновления. Полные условия доступны в подсказках карточек.

| Медаль | Файл | Условие |
|---|---|---|
| Хранитель находок | [full_collection.png](full_collection.png) | Прежнее достижение за все 12 находок лесного и речного наборов |

Новая медаль создана через imagegen: тёмно-зелёная круглая эмаль, золотой обод, открытый альбом с листом и жемчужиной, без надписей. Компонент ограничивает PNG круглой CSS-маской; блокировка использует общие стили достижений.

«Хранитель находок» скрыт в текущем меню игрока. ID, файл, сохранённое владение и работа модерации остаются совместимыми.
