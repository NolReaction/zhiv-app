# Звук для браузера

Здесь будут находиться подготовленные записи. **Сейчас аудиофайлов нет:** все 84 места в [каталоге](../../features/audio/catalog/audio-catalog.json) имеют `status: "pending"`, намеренно молчат и не запускают загрузку.

- `effect/` — короткие UI, голосовые и игровые эффекты, PCM WAV.
- `loop/` — короткие петли воды, леса, огня и работы, PCM WAV.
- `music/` — длинные темы: Opus с AAC `.m4a` как запасным вариантом.

Это соглашение инструмента подготовки; движок принимает безопасный локальный `/audio/...` из каталога. Используется один ID на конкретную запись, несколько записей объединяются в звуковое событие (`cue`), события — в профиль. Музыка воспроизводится потоково, короткие эффекты декодируются в ограниченный кеш.

Порядок отбора, сохранения оригиналов, монтажа, экспорта и оформления происхождения: [`art/audio/README.md`](../../art/audio/README.md). Сначала подготовьте файл и заполните лицензионную карточку, затем включайте слот через `status: "ready"`. Проверка: `npm run audio:check`.

Не копируйте сюда исходные монтажные проекты, страницы с лицензиями, личные записи или файлы без подтверждённого права публикации. Любой файл внутри `public/` доступен пользователю приложения. Список этих файлов сам по себе ничего не включает: воспроизведение всегда определяется каталогом и игровыми событиями.
