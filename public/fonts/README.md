# Resident dialogue font

`pangolin-residents-v1.woff2` is a subset of **Pangolin Regular 1.101**,
Copyright 2016 The Pangolin Project Authors. See [Pangolin-OFL.txt](Pangolin-OFL.txt)
for the SIL Open Font License 1.1. CSS uses the local alias `Zhiv Residents`.

Source: https://github.com/google/fonts/tree/main/ofl/pangolin
Upstream project: https://github.com/googlefonts/pangolin

Downloaded source `Pangolin-Regular.ttf` SHA-256:
`cf4f0a46704c7859d4943320fce6c6d06cc7dc450ef971c3676ef36f9f482299`.
Bundled WOFF2 SHA-256:
`8f63f72bfd68808acfd5298c158de09cb787632e7847519e7bcd2f7043f625d6`.

Subset covers U+0020–007E, U+0400–045F, U+2000–206F and
U+00A0, U+00AB, U+00BB, U+00B7, U+00D7, U+20BD where provided upstream.
Russian upper/lower case, Ё/ё and dialogue punctuation are verified.
FontTools subset with Brotli produced the WOFF2; timestamps were preserved,
with name records 13/14 (license) retained alongside the default name records.
The bundled file is 88,944 bytes and requires no runtime font CDN.
