# Звуковая система

Общий клиентский движок музыки, окружения, действий, голосов и интерфейса. Основная инструкция — [устройство звука](../../docs/game/audio-system.md); исходники и экспорт — [art/audio/README.md](../../art/audio/README.md). Сейчас каталог содержит подготовленные `pending`-слоты: реальные записи ещё не выбраны, обычная игра молчит.

| Папка | Ответственность |
|---|---|
| `domain/` | Чистые контракты, настройки, расстояния, затухание зон, стереопанорама |
| `catalog/` | Постоянные ID записей, звуковых событий (`cue`), профилей и сведения о происхождении |
| `runtime/` | Один браузерный сервис: Web Audio, потоковая музыка, ограниченный кеш, лимиты голосов, отмена и дедупликация |
| `ui/` | Жизненный цикл приложения, семантические UI-события, настройки и подписка на диагностику |
| `dev/` | Прослушивание, тестовый тон, сведения об источниках и флаг разметки карты |

Интеграция мира находится в [features/world/audio/](../world/audio/): она читает камеру, Tiled, погоду и состояния занятий, затем передаёт нейтральный `AudioFrame` и события. Подтверждённые экономические результаты обрабатывает [features/economy/integration/audio-feedback.ts](../economy/integration/audio-feedback.ts). Звуковой модуль не импортирует мир, экономику, оболочку или сервер и не меняет прогресс игрока.

`getAudioRuntime()` из `runtime/audio-service.ts` возвращает один сервис на браузер. Создание сервиса не разрешает воспроизведение. `AudioProvider` монтируется один раз в `AppShell`; сцены и диалоги не создают свои `AudioContext`. Начальные настройки выключены, а первое включение требует пользовательского жеста.

Для нового действия выберите существующий `cueId` или добавьте событие в каталог. Вызовите `play({ id, cueId, occurredAt, gain?, pan? })` в месте подтверждённого события. `id` должен обозначать конкретное событие, а не текущий кадр. Для интерфейса используйте `data-audio-cue="ui.open"` на кнопке либо `playUiCue()` из `ui/audio-lifecycle.ts`; одновременно оба способа не подключайте. Награды отправляет интеграция экономики после подтверждения команды.

Для новой локации сначала создайте/выберите профиль, затем разместите точку `AudioEmitters` или полигон `AudioZones` в Tiled. Для нового героя нужны собственные записи в каталоге и маркер соответствующего действия в `world/audio/world-audio-markers.ts`. Painter не воспроизводит звук.

Проверки: `npm run audio:check`, `npm run world:check`, тесты `audio-*`, `world-audio` и `tiled-audio`. Они проверяют правила и жизненный цикл; качество записи, стык петли и поведение настоящего iPhone/PWA проверяются прослушиванием после добавления материалов.
