# Звуковая система

Общий клиентский движок музыки, окружения, действий, голосов и интерфейса. Основная инструкция — [устройство звука](../../docs/game/audio-system.md); исходники и экспорт — [art/audio/README.md](../../art/audio/README.md). Первый набор [originals-v1](../../art/audio/originals-v1/README.md) заполняет все 112 вариантов: две инструментальные темы, окружение, UI, действия и синтезированные реакции шести героев. Для нового устройства звук включён с музыкой на 10%, шагами животных на 25% и интерфейсом на 100%; регулируется через «Профиль → шестерёнка настроек → Звук» на главном экране и на карте.

| Папка | Ответственность |
|---|---|
| `domain/` | Чистые контракты, настройки, расстояния, затухание зон, стереопанорама |
| `catalog/` | Постоянные ID записей, звуковых событий (`cue`), профилей и сведения о происхождении |
| `runtime/` | Один браузерный сервис: Web Audio, потоковая музыка, ограниченный кеш, лимиты голосов, отмена и дедупликация |
| `ui/` | Жизненный цикл приложения, семантические UI-события, настройки и подписка на диагностику |
| `dev/` | Прослушивание, тестовый тон, сведения об источниках и флаг разметки карты |

Интеграция мира находится в [features/world/audio/](../world/audio/): она читает камеру, Tiled, погоду и состояния занятий, затем передаёт нейтральный `AudioFrame` и события. Подтверждённые экономические результаты обрабатывает [features/economy/integration/audio-feedback.ts](../economy/integration/audio-feedback.ts). Звуковой модуль не импортирует мир, экономику, оболочку или сервер и не меняет прогресс игрока.

Музыку простого вида и меню подключает [features/app/integration/use-menu-audio.ts](../app/integration/use-menu-audio.ts) через нейтральный контроллер `ui/menu-audio.ts`. Полянка, карта и меню используют общие ID музыкальных дорожек; настройки громкости не требуют пересоздания сцены. Полянка и меню передают `soundscape: false`: звучат музыка и интерфейс. Окружение, действия и голоса разрешены только на полной карте; выход плавно завершает эти слои. Кнопка «Сбросить громкость» возвращает общий баланс, сохраняя выбор включения звука.

`getAudioRuntime()` из `runtime/audio-service.ts` возвращает один сервис на браузер. Создание сервиса не разрешает воспроизведение. `AudioProvider` монтируется один раз в `AppShell`; сцены и диалоги не создают свои `AudioContext`. Начальные настройки включены; запрет браузерного autoplay снимается только пользовательским жестом. Сохранённое выключение и уровни громкости обновление не меняет.

`prepare()` готовит файлы без ожидания разрешения на воспроизведение. Подготовку заставки ведёт [features/startup/](../startup/), выбранной дневной/ночной музыки — интеграция меню. `runtime/audio-asset-transport.ts` сохраняет только общедоступные файлы `/audio/` в ограниченном CacheStorage; при недоступном хранилище работает сеть. `audio-asset-cache.ts` допускает два запроса и одно нативное декодирование одновременно, давая приоритет текущим UI-событиям. Подготовленная музыка остаётся сжатой и действительно используется потоковым проигрывателем. При выключенном звуке прогрев коротких файлов не создаёт AudioContext.

Для нового действия выберите существующий `cueId` или добавьте событие в каталог. Вызовите `play({ id, cueId, occurredAt, gain?, pan? })` в месте подтверждённого события. `id` должен обозначать конкретное событие, а не текущий кадр. Для интерфейса используйте `data-audio-cue="ui.open"` на кнопке либо `playUiCue()` из `ui/audio-lifecycle.ts`; одновременно оба способа не подключайте. Награды хозяйства отправляет интеграция экономики после подтверждения команды. Ежедневный подарок озвучивает [game-rewards-audio.ts](../game/game-rewards-audio.ts) только после подтверждённого получения, без повторов при сверке или повторном открытии.

Для новой локации сначала создайте/выберите профиль, затем разместите точку `AudioEmitters` или полигон `AudioZones` в Tiled. Для нового героя нужны собственные записи в каталоге и маркер соответствующего действия в `world/audio/world-audio-markers.ts`. Painter не воспроизводит звук.

Проверки: `npm run audio:check -- --require-ready`, `npm run world:check`, тесты `audio-*`, `menu-audio`, `world-audio` и `tiled-audio`. Они проверяют правила и жизненный цикл; тембр, баланс слоёв, стык петли и поведение настоящего iPhone/PWA проверяются прослушиванием. Наличие файла не означает, что каждый зарезервированный `cue` уже вызывается игрой: выбор деревянных шагов по поверхности и некоторые реакции усилия остаются будущей интеграцией.

Пространственные петли переживают краткий выход за радиус через обратимое затухание; после полного удаления возвращаются с продолжающейся временной позиции. В DEV показаны накопительные счётчики запусков петель/музыки и текущий владелец звука — это позволяет отличить повторные старты от особенностей самой записи.

`runtime/audio-session.ts` запрашивает смешиваемый режим `ambient` в браузерах с Audio Session API. Он не обнаруживает сторонний проигрыватель и не гарантирует поведение всех телефонов. Интервал одиночных событий проверяется также после декодирования, чтобы первая загрузка не давала пачку запоздавших звуков.

Микс шагов и погоды ограничен уровнями событий в каталоге, поэтому действует и для прежних сохранённых регуляторов. Ветер — −36 dB, шаги — −22 dB. Шаги имеют отдельную группу `footsteps` и ползунок «Шаги животных»; миграция из `world` сохраняет ноль и тихие значения с ограничением 25%. Во время дождя отдельный ветер дополнительно плавно уходит примерно к четверти сухого уровня. Все источники, включая потоковую музыку, проходят общий Web Audio-граф; HTMLAudioElement.volume не используется. Тесты проверяют этот путь при неизменяемой громкости медиаэлемента и запас пиков настоящих WAV при максимальных пользовательских уровнях.

Плавный повтор потоковой песни задаёт `runtime/music-loop-envelope.ts`: затухание за 2,5 секунды до конца и такое же нарастание после повтора. Огибающая отделена от громкости сцены и не сбрасывается при обновлении камеры. Проверка реального playhead работает и в неподвижном меню; выход, mute и смена владельца освобождают её таймер вместе с музыкальным потоком.

Обычный рынок и личная лавка друга временно передают музыку контроллеру `ui/market-audio.ts`: прежние дорожки продолжаются тише, пространственные звуки карты затухают. `ui.market-open` один раз при входе даёт короткий звук мешочка и двух монет; фон, повторный рендер, опрос и возвращение к вкладке его не повторяют. Подтверждённые покупки по-прежнему озвучивает единственный обработчик квитанций экономики.
