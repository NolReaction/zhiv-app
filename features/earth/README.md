# Земля и геопозиция

Отдельная вкладка `earth` в основной навигации приложения. Реальная Земля и будущая геосоциальная часть принадлежат этому модулю; игровая полянка остаётся в `features/world/`, самостоятельный движок в `packages/engine/`.

- `earth-view.tsx` и CSS: экран, панели друзей/информации, сведения о геопозиции, переходы через callbacks из AppShell.
- `earth-map.tsx` и CSS: жизненный цикл MapLibre, камера, глобус, элементы управления и маркер пользователя.
- `camera-session.ts`: один снимок камеры и настроек в памяти текущего аккаунта для возврата с полянки и после освобождения Map.
- `earth-loading.tsx` и CSS: непрозрачный экран подготовки, реальные стадии, счётчики и восстановление загрузки.
- `runtime-loader.ts`: установка закреплённого SDK/worker, проверка размеров и SHA-256, повторное использование на странице.
- `resource-cache.ts`: Cache Storage публичных ресурсов, origin-wide writer lock, общие лимиты тела/очереди/RAM/диска, повторы, отмена, возобновление и persistent storage.
- `resource-cache-policy.ts`: адаптивные бюджеты и вытеснение по текущему viewport, ограниченной частоте и давности обращений; история только в RAM, массовых загрузок нет.
- `resource-protocol.ts`: отмена запросов по времени жизни карты и запроса SDK; общая установка SDK живёт отдельно.
- `resource-recovery.ts`: определение повреждённого ресурса по ошибке рендера для точечного исправления кэша.
- `map-style.ts`: поставщик карты, атмосфера, масштаб и геодезический круг точности.
- `cartoon-style.ts` и `data/land-110m.json`: собственная компактная палитра и встроенный силуэт всей Земли; происхождение данных в `data/README.md`.
- `land-material.ts`, `coast-material.ts`: локальная бесшовная фактура суши и мягкая кромка реальных берегов.
- `landmark-catalog.ts`: девять достопримечательностей, географические якоря и ссылки на происхождение координат.
- `landmark-mesh.ts`, `landmark-mesh-layer.ts`: оригинальные low-poly 3D-миниатюры в общем WebGL-контексте карты; одна ограниченная геометрия, без сетевых моделей.
- `globe-landmarks.ts`, CSS и `landmark-layout.ts`: точные геоякоря, доступные подписи, скрытие за глобусом/при сильном отдалении, ограничение числа объектов и очистка.
- `globe-ocean.ts` и CSS: локальная фактура течений, мягкие волны и ограниченные круги от нажатия по воде.
- `globe-clouds.ts` и CSS: восемь декоративных векторных облачков с нативным скрытием за Землёй.
- `globe-lighting.ts`: художественные сумерки, огоньки и режимы «Авто / День / Вечер» без внешних данных.
- `earth-stars.ts` и CSS: статичные звёзды вне проекции Земли, с отсечением по горизонту во время zoom/pitch.
- `weather.ts`: включаемый пользователем прогноз для округлённого центра карты, ограниченный кеш и отмена запросов.
- `earth-weather.ts` и CSS: собственный SVG-маркер прогноза и частицы осадков.
- `tile-loading-overlay.ts` и CSS: облачка над ожидающими тайлами с вычитанием уже загруженных участков.
- `globe-scene.ts`, `scene-clock.ts`: единый ограниченный clock эффектов после первого готового кадра; океан/обзорные облака останавливаются с zoom 4.2, погода может двигаться на улицах. В фоне и reduced motion движение выключено.
- `globe-overview.ts` и `data/physical-110m.json`: озёра, ледники, обзорная сетка и подписи.
- `globe-camera.ts`: совместимая с глобусом анимация double-click/tap и инерции через публичные API камеры.
- `building-style.ts`: ограниченная экструзия зданий на близком масштабе.
- `position-marker.ts`, `marker-motion.ts` и CSS: экранный Мохлик из существующего pixel-sprite, реакция на поворот и короткое приветствие по нажатию.
- `earth-attribution.tsx`: одна видимая строка обязательных источников; сведения о лицензиях в «О карте».
- `tile-base.ts`: небольшая MVT-подложка для загруженных векторных тайлов, сохраняющая точные береговые линии поверх общего силуэта. Дисковые оригиналы не меняются.
- `tile-recovery.ts`: ограниченное восстановление новых участков без пересоздания карты, контроль отсутствия прогресса и повтор при возвращении сети.
- `source-recovery.ts`: повтор конкретных тайлов или пересоздание зависшего источника с сохранением порядка слоёв, камеры и локальной основы.
- `location.ts`: независимый контроллер браузерной геопозиции с явным запуском и отменой.
- `use-earth-location.ts`: привязка контроллера к владельцу и жизненному циклу React.

Геопозиция пользователя существует только в памяти открытого раздела. GPS-координаты не передаются серверу; погода запрашивает отдельно округлённый центр просмотра. Согласие на показ отметки «Я живой» не означает согласия на передачу местоположения друзьям.

После обновления страницы `features/app/earth-navigation-state.ts` восстанавливает только открытый раздел для того же владельца в той же вкладке браузера. Разрешение на запуск геопозиции, координаты и камера между перезагрузками не сохраняются. Картографический кэш содержит изученные участки карты и не используется для хранения GPS-отметок.

`features/app/earth-map-availability.ts` отделяет доступность публичной карты от игрового соединения. `earth-map-retention.ts` и `use-earth-map-retention.ts` сохраняют готовый Map до 120 секунд при переходе в «Профиль»/«Люди»; скрытая панель не принимает фокус, GPS очищается и сам при возврате не включается. Готовая фоновая карта останавливает запросы, восстановление тайлов и анимацию. Начатая первичная подготовка может закончиться в пределах срока удержания. Смена владельца, выход, AFK, запуск игры и истечение срока освобождают карту. Камера и настройки отдельно сохраняются в памяти сессии аккаунта: возврат с полянки восстанавливает вид без нового GPS-наблюдения. Выход, смена владельца и F5 сбрасывают снимок.

Погода выключена по умолчанию и не использует GPS. С zoom 3 запрашивается целочисленный центр просмотра через публичный same-origin GET `/api/v1/earth/weather`; адаптер `lib/server/earth-weather.ts` обращается к MET Norway. Клиент соблюдает срок ответа, абсолютный предел `staleUntil` и ограничение частоты; устаревший прогноз помечается и затем удаляется. Данные MET Norway распространяются по CC BY 4.0; источник, лицензия и отметка об упрощённой визуализации показаны в «О карте».
