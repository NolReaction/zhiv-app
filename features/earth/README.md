# Земля и геопозиция

Отдельная вкладка `earth` в основной навигации приложения. Реальная Земля и будущая геосоциальная часть принадлежат этому модулю; игровая полянка остаётся в `features/world/`, самостоятельный движок в `packages/engine/`.

- `earth-view.tsx` и CSS: экран, сводка геопозиции, список существующих друзей, переходы через callbacks из AppShell.
- `earth-map.tsx` и CSS: жизненный цикл MapLibre, камера, глобус, элементы управления и маркер пользователя.
- `map-style.ts`: поставщик карты, атмосфера, масштаб и геодезический круг точности.
- `location.ts`: независимый контроллер браузерной геопозиции с явным запуском и отменой.
- `use-earth-location.ts`: привязка контроллера к владельцу и жизненному циклу React.

В первом этапе геопозиция существует только в памяти открытого раздела. Серверного обмена координатами пока нет. Согласие на показ отметки «Я живой» не означает согласия на передачу местоположения.
