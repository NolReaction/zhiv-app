# Земля малого масштаба

`land-110m.json` — Natural Earth, слой `ne_110m_land`, масштаб 1:110 млн.
Источник зафиксирован тегом `v5.1.2`:

https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_land.geojson

SHA-256 исходного файла (138 160 байт):
`9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`.

Natural Earth публикует географические данные в общественном достоянии:
https://www.naturalearthdata.com/about/terms-of-use/

Включённые 127 полигонов сохраняют исходную геометрию, включая Антарктиду и
острова. Удалены служебные `name`, `crs`, `bbox` и свойства объектов; координаты
округлены до четырёх знаков после запятой. Воспроизводимое преобразование:

```python
import json

def coordinates(value):
    if isinstance(value, (float, int)):
        return round(value, 4)
    return [coordinates(item) for item in value]

source = json.load(open("ne_110m_land.geojson"))
result = {
    "type": "FeatureCollection",
    "features": [{
        "type": "Feature", "properties": {},
        "geometry": {"type": feature["geometry"]["type"],
                     "coordinates": coordinates(feature["geometry"]["coordinates"])},
    } for feature in source["features"]],
}
with open("land-110m.json", "w") as output:
    output.write(json.dumps(result, separators=(",", ":")) + "\n")
```

Файл входит в код лениво открываемой карты. Это опорный силуэт всей Земли,
а не точная береговая линия для прогулки. Единственный GeoJSON-тайл `maxzoom: 0`
остаётся доступным при вращении, временной потере сети и загрузке нового района.
С масштаба 4 загруженные векторные тайлы OpenStreetMap накрывают его точной
геометрией: локально добавленный MVT-слой подложки и вода рендерятся из одного
тайла. Данные провайдера на диске сохраняются без изменения.

## Ледники и крупные озёра

`physical-110m.json` содержит 11 полигонов ледников и 24 крупных озера из того же
Natural Earth `v5.1.2`; общий размер 27 958 байт. Исходные файлы:

- [ne_110m_glaciated_areas.geojson](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_glaciated_areas.geojson), 21 720 байт; SHA-256 `e61e3f45e22f087f861ac2fda6258fc15c849a216d74c27ccf0164eeafbd950a`.
- [ne_110m_lakes.geojson](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_lakes.geojson), 36 648 байт; SHA-256 `eb02ecc86c82004fccbf979058bfabbbd6c2d07968c7844d38eb1c9152d2ffc9`.

Для воспроизведения примените функцию `coordinates` из примера выше к обоим
файлам, в указанном порядке. В `properties` каждого ледника оставьте только
`{"kind":"ice"}`, каждого озера — `{"kind":"lake"}`. Объедините массивы
`features` и запишите `FeatureCollection` тем же компактным `json.dumps`.
Лицензия этих данных также public domain.

`globe-overview.ts` добавляет редкую сетку меридианов/параллелей и подписи частей
света/океанов. Координаты подписей выбраны для размещения текста и не задают
границы. Весь обзор хранится в одном локальном GeoJSON-тайле `maxzoom: 0`;
сетка и подписи исчезают до масштаба улиц. Локальные ледники и озёра плавно
исчезают между масштабами 4 и 6; точная вода OSM остаётся выше, а точный лёд
сохраняет полную непрозрачность. Упрощённые контуры не накрывают улицы.

## Художественные биомы

`art/earth/biomes/regions.json` — собственные нарисованные контуры 40 регионов:
тропические леса, тайга, тундра, пустыни, саванны и степи. Это художественные
акценты, а не измеренные экологические границы, сезонная карта или климатическая
модель. Материки между акцентами сохраняют основную умеренную зелень.

`npm run earth:biomes:prepare` заранее сглаживает контуры и обрезает их по
Natural Earth 110m с исключением озёр и ледников. В каждой области пять
неперекрывающихся переходных полос. Полученный `biomes-illustrated.json`
содержит 200 MultiPolygon-объектов и 10 673 вершин: около 228 КБ JSON / 61 КБ
gzip. `npm run earth:biomes:check` проверяет воспроизводимость без записи.
`polygon-clipping` используется только при подготовке и в тестах, в браузер
не входит. Округление до четырёх знаков соответствует опорной геометрии суши;
тесты ограничивают остаточные метровые погрешности обрезки.

`../globe-biomes.ts` подключает один локальный источник и один fill-слой,
без сетевых запросов и кадрового построения геометрии. Цвета лежат над базой
загруженных тайлов, но под фактурой, хребтами, водой, льдом и ночным светом.
Они плавно исчезают с масштаба 3,5 до 6, уступая точной растительности OSM.
Под базой тайлов остаются отдельные заливки тех же ледников и озёр: отсутствие
или ошибка тайла не превращает белый лёд и синюю воду в зелёную сушу.

## Художественный обзорный рельеф

`art/earth/relief/ranges.json` содержит собственные приблизительные линии крупных
горных районов, нарисованные для оформления глобуса. Это не сторонний набор координат,
DEM или геодезически точные хребты. Направляющие превращаются в небольшие
светлые и теневые грани; ширина, ответвления и освещение условны. Береговая
проверка использует описанный выше Natural Earth 110m. Геометрия не меняет
положение поверхности, озёр, улиц, маркеров или географические координаты.
`node scripts/prepare-earth-relief.mjs` заранее создаёт `relief-illustrated.json`
из направляющих и Natural Earth; `--check` проверяет воспроизводимость без записи.
Файл содержит 1092 простые грани, около 218 КБ несжатого GeoJSON; 30 треугольников
обозначают редкие условные снежные вершины семи хребтов. Браузер
импортирует готовую геометрию через `../globe-relief.ts`: построение гребней
и проверки берегов при открытии карты не выполняются. Один статичный локальный
слой исчезает к масштабу 4, до точной уличной карты.
