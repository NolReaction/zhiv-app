# Игровой мир

Для изменения видимого окна начните с `ui/<topic>/`; для игрового профиля «Мой Мохлик» — [ui/profile/world-profile-menu.tsx](ui/profile/world-profile-menu.tsx) и соседнего CSS. Общий каркас окон, открытие и фокус принадлежат [world-view.tsx](world-view.tsx). Профиль аккаунта находится отдельно в `features/account/`.

| Папка | Что менять |
|---|---|
| `ui/` | `profile`, `help`, `wardrobe`, `collections`, `characters`, `journeys`, `hud`, `feedback` |
| `scene/` | Текущий Canvas, камера, графика и сборка кадра; вход — `new-map-scene.ts` |
| `simulation/` | Выбор и прерывание действия Мохлика, исполнение движения, жизнь полянки |
| `activities/` | Сад, рыбалка, костёр, готовка, каменоломня и переходы |
| `characters/` | Плёска, Шишколап, занятость жителей и разговоры |
| `navigation/` | Пути, безопасные повороты, проходы и обход жителей |
| `environment/` | Свет, погода, вода и животные |
| `audio/` | Пространственные источники, погода, работа зданий и маркеры действий; воспроизведение принадлежит `features/audio/` |
| `state/` | Общая сессия и наблюдение; `memory/` — память/аренда; `economy/` — отображение экономики в сцене |
| `domain/` | World snapshot, гардероб, книга находок |
| `tiled/` | Контракт разметки, сгенерированные данные и общий renderer |
| `dev/` | Диагностика и тестовые сценарии |
| `legacy/` | Сохранённые части прежней карты и совместимости |

Круг и большая карта читают одну [state/forest-session.ts](state/forest-session.ts). [state/session.ts](state/session.ts) имеет другую задачу: HTTP-контракт гардероба и прежних поездок. Экономические команды живут в `features/economy/`; память полянки и анимации не выдают предметы.

`legacy/` не означает «можно удалить»: часть модулей ещё нужна для совместимости и общих помощников. В `features/mochlik/` также остаются активные графические модули. Карту редактируют в `world/tiled/forest.tmj`; `forest.generated.json` обновляют через `npm run world:export`.
