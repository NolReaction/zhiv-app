- `features/world/new-map-scene.ts`: небольшие жесты на месте, реакция на нажатие, общий серверный отсчёт для атмосферы, остановка в фоне и при паузе, статичный режим reduced motion. Повторное `configure()` не заменяет свежий `setTime()` старым временем.
- `features/world/grounding.ts`: положение ступней измеряется по альфа-каналу спрайта; небольшая контактная тень остаётся под ногами. У зданий слабая тень у основания по прозрачности изображения и footprint; маска кешируется отдельно для каждого изображения/уровня. Оригинальная графика рисуется без фильтра. Общий композитор также применяет это в Tiled-предпросмотре.
- Рабочий цикл прежний: `npm run world:watch` + `npm run dev:local`; сохранение Tiled обновляет JSON, при ошибке остаётся последний корректный экспорт. `world:export` не сжимает изображения. Инструкция: `docs/game/tiled-editor.md`.
