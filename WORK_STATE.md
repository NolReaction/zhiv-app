## Подарки, защита рынка, производство и рыба

- Подарки выбираются сервером по завершённому дому. Монеты за семь получений: 5 500 / 11 000 / 22 000 / 44 000 / 66 000. Материалы своей ступени; время только готовых изделий 250/490/840/1260/1520 минут одиночных рецептов. Жемчуг 225 видимых и одно ядро в неделю фиксированы. Слоты не умножают подарок. Переполнение атомарно сохраняет шаг; receipts прежних выдач неизменны. UI показывает текущий подарок перед календарём.
- Монетный рынок: дома 2–3 / 4–5 в отдельных группах, проверка текущих домов обеих сторон. Отдельный суточный объём покупок/продаж по базовой стоимости: 0/2400/4800/9600/14400 для домов 1–5; цена 1–2×, комиссия новых лотов 5% с округлением вверх. Старые комиссии сохранены, старые цены вне диапазона можно отменить. Бартер: дом 3 отдельно, дома 4–5 вместе; одна успешная сделка в сутки на каждого участника. Квоты не продаются за жемчуг.
- V43 добавляет `economy_market_daily_turnover` и `seller_fee_bps`. Квоты переживают reset экономики, складываются при merge и меняются атомарно с товаром/балансом/receipt. Операторский полный wipe синхронизирован с V43 (61 таблица), не выполнялся.
- Строка мест производства компактная (44px); расширение и выполняющиеся заказы раскрываются отдельно, готовые заказы видны сразу. Рецепты занимают основную часть окна. У максимального уровня убран лишний нижний блок производств.
- «Холодильник» — третья категория общей кладовой для всей рыбы, без увеличения вместимости. Плёска и рынок игроков показывают настоящий товар до покупки; собственная рыба видна в запасах. Покупка по-прежнему не открывает личный улов в книге. Готовка и её рецепты не менялись.
- Жемчуг по-прежнему показывается как raw/2, внутри ×50. Магазин валют остаётся только предварительной витриной; высокий курс золота не утверждён для реальных операций.
