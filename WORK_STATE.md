# Рабочее состояние: earth

## Жизненный цикл, камера, материальность материков и атрибуция

- Работа в `earth` поверх `76b3904`. Master/production, backend, зависимости, миграции, игровой мир и Tiled не менялись.
- Подтверждён дефект старой версии: AppShell передавал activity.active, поэтому hidden/offline уничтожали даже готовую кэшированную карту. `features/app/earth-map-availability.ts` теперь сохраняет экземпляр при hidden/connecting/error/offline. Сам Earth приостанавливает движение/рендер/дедлайн в фоне; геоконтроллер независимо снимает GPS-watch по visibilityState. Уход из раздела, игровой overlay и явная AFK-пауза по-прежнему освобождают Map/WebGL. Правила игрового соединения и экономики не изменены.
- Состояние загрузки при настоящем удалении Map сбрасывается по событию remove без старого activeRef: cleanup React выполняется раньше эффекта, который обновляет ref. Первый показ по-прежнему требует фактического render/loaded/tiles, pending0/failed0 и завершённого восстановления.
- `resource-protocol.ts` связывает запрос с AbortSignal карты и SDK. Уход освобождает активные и ожидающие запросы даже без отмены со стороны SDK; другая карта/потребитель и общая установка SDK продолжаются. Обработчики снимаются после settlement. TileJSON/MVT декорируются только в worker-копии; кэш оригинален. 7 интеграционных тестов используют настоящий resource-cache/runtime-loader.
- `globe-camera.ts`: native double-click/tap и инерция SDK 6.15 вызывают easeTo({around}), не поддерживаемый globe easing. Один экземпляр Map получает адаптацию через публичный calculateAnchoredCameraOptions; комбинированная инерция сохраняет конечную камеру без around. Колесо/pinch не меняются. Исходный метод восстанавливается при cleanup, console/прототипы SDK не трогаются. 6 тестов на реальных классах SDK.
- `land-material.ts`: детерминированная бесшовная RGBA-фактура 128×128 (64 КиБ, pixelRatio 2), генерируется один раз, отдельная копия на Map. Один рисунок на coarse/detail суше, fade к zoom 8. `coast-material.ts`: мягкая тень/светлая кромка реальных берегов из имеющегося Natural Earth, fade к zoom 4, без искусственных линий полюса/антимеридиана. Всего 31 слой. Нет новых сетевых ресурсов, библиотек или анимационного цикла; 3D-здания сохранены.
- `EarthAttribution`: одна постоянная короткая строка ©OpenStreetMap/OpenMapTiles со ссылками. Нативный control и вторая i-кнопка удалены. Условия OpenMapTiles отдельно требуют видимый credit в углу, поэтому OSM-правило 5 с не применяется ко всем источникам. В «О карте» перечислены поставщик/лицензии/изменение оформления, Natural Earth public domain и ссылка на распространяемый LICENSE.txt SDK. OpenFreeMap/Natural Earth не требуют своей видимой подписи. Автономных area packs нет; условия будущих загрузок областей и ограничения поставщика описаны в docs, бюджет пассивного кэша не менялся.
- Проверки: 215/215 целевых Earth/navigation/onboarding/PWA/dev/deploy/gesture тестов; полный TypeScript и ESLint, architecture:check (844 модуля), world:check прошли. Обе production-сборки Next/VPS и Sites прошли; проверка секретов после индексации новых файлов: 0 находок. Первый Next build остановился на повреждённом persistence-кэше Turbopack; после переноса только генерируемого кэша чистая сборка прошла. Полный npm test/API/Compose не запускались: этап разработки без деплоя.
- Chromium/WebGL2: реальное offline/online и hidden/visible сохраняют тот же Map/canvas/камеру; GPS-watch прекращается в фоне и возобновляется только после предыдущего явного запроса. Native double-click/Shift-double-click сохраняют точку привязки (ошибка менее 0.2 px), вращение с инерцией без warning. Два warm F5: 11 cache hits, 0 запросов SDK/провайдера, pending0/failed0, GPS не включается сам. Cold pending4 -> Profile немедленно pending0; быстрые Profile/Map возвраты оставляют один живой экземпляр и готовую карту. Материал/берег просмотрены на 1920×961 и 390×844, без шахматки/missing-image warnings. Полюс, антимеридиан и zoom4.2: pending0/failed0, все текущие тайлы готовы, ошибок и швов фактуры нет. Финальные браузер и сервер остановлены.

Подтверждён и исправлен отдельный дефект уничтожения Map при скрытии/потере сети; протокол дополнительно получил явное время жизни. Не выдавать эти результаты за доказательство каждой причины пользовательского случая.
