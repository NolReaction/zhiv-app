# Сайт и исправления перед master

13 октября пользователь явно разрешил добавить сайт и три исправления в `master`: уступание пути с корзиной, полоса нижнего края, повтор имени в push. Исходный master `9d5e4e7`; релиз подготовлен в `work/site-pwa`, PR https://github.com/NolReaction/zhiv-app/pull/25. Локальная интеграционная ветка `work/site-master-fixes`. Серверный деплой не запрошен.

## Готовые этапы

- Сайт: прямой вход на компьютере, установка по желанию, восстановление зависшей установки и загрузки, превью 800/1600/2560, удаление длинных тире из интерфейса. Всё уже опубликовано в PR #25.
- Навигация: жители сообщают ограниченный ближайший маршрут и точную цель. Ёжик освобождает подход к корзине или меняет рабочую точку, сохраняя заказ. Плёска временно уступает с сохранением очереди и улова; Мохлик уступает во время необязательной прогулки. Приоритет точного поручения выше прогулки, взаимное уступание не зацикливается. Проверка всего отрезка движения сохраняет препятствия и безопасное расстояние. Если безопасного места нет, житель ждёт. Данные намерений временные, формат серверного сохранения не менялся.
- Нижний край: удалён `browserEdge`, который затемнял safe-area карты во вкладке Safari. Отступы кнопок сохранены.
- Push: API формирует заголовок события вместо названия приложения. SW исправляет брендовые заголовки старого API во время обновления. Системная подпись отправителя остаётся; старые доставленные уведомления не меняются. Подписки, manifest identity, владелец и адрес перехода сохранены.
- Исправлены шесть прежних ошибок тестов: изолированная canvas fixture не запускает общий транспорт аудиофайлов; строгие проверки таймеров сохранены. Справка звука сокращена до допустимой длины.

- Ранее для сайта: 53/53 целевых теста, typecheck/lint/architecture/world/security; обе сборки. Полный набор имел 3533/3539 с шестью подтверждёнными baseline-падениями.
- После исправления baseline: 6/6 ранее падавших тестов и 127/127 аудио/справки прошли. Уведомления 42/42, включая SW push 7/7.
- Навигация: 95/95 целевых тестов, включая семь новых регрессий. Полный сбор и возвращение к занятой корзине сохраняют ту же корзину и три ягоды без повторной выдачи; проверены встречные цели, рабочий заказ ёжика и неделимые действия Плёски. Независимое ревью без блокеров.

## Выпуск

Объединение в `master` разрешено пользователем и выполняется через PR #25 после зелёного финального CI. Деплой сервера выполняется отдельно, если пользователь его запросит. На реальном устройстве остаётся проверить Safari safe-area, установку/обновление PWA, прямые ссылки и оформление системных push.

Два неотслеживаемых каталога `public/tiled-watch-*` остались от старых тестов; в коммиты не включать.
