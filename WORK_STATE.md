# Состояние работы

## 0.6.8 — организация кода

Рабочая ветка `work/0.6.8` основана на `master` (`1f1c1d6`, опубликованная 0.6.7 с исправлениями и актуальной документацией). Пользователь поручил сделать архитектуру понятной разработчику, сохранив существующие функции и ресурсы.

Мир разделён на `ui`, `domain`, `scene`, `simulation`, `activities`, `characters`, `environment`, `navigation`, `state` и `legacy`; экономика — на `domain`, `sync`, `integration`, `ui` и `dev`. Оболочка приложения теперь `features/app/app-shell.tsx`. Общее состояние контроллера экономики выделено из UI. Импорты, динамические загрузчики, ссылки тестов, скриптов и документации обновлены. Все 1298 прежних файлов сохранены по текущим или новым адресам; каталоги баланса, API, миграции, карта, графика и CSS не изменены.

Правила и карта поиска: [организация кода](docs/development/code-organization.md), [задача → файл](docs/repository-guide.md), README в крупных модулях. `npm run architecture:check` проверяет границы домена/синхронизации/оболочки, локальные импорты и циклы feature-модулей; подключена к CI и имеет 9 собственных тестов.

- Next dev: новая локальная учётная запись, главная, JS-файлы страницы, API аккаунта/экономики/мира и manifest проверены через HTTP без ошибок компиляции.

Архитектурный коммит `806a852` прошёл весь [CI](https://github.com/NolReaction/zhiv-app/actions/runs/37776318532): 2895 веб-тестов, обе сборки, Ktor/PostgreSQL и production Compose. Крупные координаторы AppShell и WorldView сохраняют прежнее поведение; дальнейшее разделение выполняется по конкретной ответственности. Публикация в `master`, деплой и изменения данных игроков в эту задачу не входят.

## DEV-доступ в рабочей 0.6.8

Пользователь попросил открыть DEV-функции для продолжения разработки. Панель, диагностика и читы уже доступны при `npm run dev:local`/`dev:lan`; отдельного запрета для ветки нет. Локальный launcher теперь явно передаёт `NODE_ENV=development`, чтобы значение `production` или `test` из терминала не скрывало инструменты. Production-запуск и его ограничения не изменены. Инструкция локальной разработки обновлена.

Для этого изменения прошли 86 целевых тестов launcher/DEV-панели/читов/сессии/production-ограничений, typecheck, lint и `architecture:check`. Полный CI архитектурного коммита выше не является проверкой нового изменения. Следующий шаг — дальнейшая разработка на `work/0.6.8`; локальный запуск через `dev:local` или `dev:lan`.
