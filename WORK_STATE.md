# 0.7.2-fishing: режимы G/R/S, компактный инспектор и настройки воды

Ветка `0.7.2-fishing`, база этапа `e469296`. Разработка и Git разрешены; master/deploy вне задачи. `releaseValidated=false`.

## Текущий этап — 4 ноября 2026

- Полоса под лодкой убрана из вида по умолчанию: контактная тень/рябь/пена и полупрозрачное погружение корпуса выключены. «Эффекты у корпуса» позволяет включить их отдельно, настроить интенсивность и Y-смещение декора. Лодка, ватерлиния и физика качки при этом не перемещаются. Исходные PNG сохранены.
- Необязательные `waterPreview.effectsEnabled/effectOpacity/effectOffsetY/immersionEnabled` проходят валидацию и файловое сохранение. Старые файлы не получают новые поля автоматически, их отсутствующие эффекты показываются выключенными. Явные false и нулевая интенсивность сохраняются. Обычный гараж без waterPreview также работает.
- Быстрые режимы: G/V — двигать, R — поворот, S — масштаб, H — холст, P — опора, A — крепление, M — маска. Выбор режима сам не меняет сцену; затем надо тянуть деталь. Клавиши работают после нажатий toolbar и в русской раскладке, сохраняют ввод в полях и Ctrl/⌘ S. R/S действуют вокруг авторской опоры, Shift — шаг 15°/10%; ручки S оставляют свободное растягивание. Сложные affine-родители, отражение, дети и один undo на жест сохранены. Повторный M не сбрасывает незаконченный контур.
- Правый инспектор: «Объект» с основными полями сразу, «Крепления» с родителем/контактами/точками, «Борт» с маской. Верх/вкладки и нижние действия sticky на desktop; панели остаются смонтированы, сохраняя состояние подгонки. Клавиатура вкладок Arrow/Home/End, переключение не dirty/undo. M открывает «Борт», transform-режимы открывают «Объект». На узком экране свойства следуют за холстом перед библиотекой, горизонтального переполнения нет. Ранее созданные сцены и черновики не перезаписывались.
- Проверки этапа: 99/99 garage-тестов; новые случаи G/R/S/Russian/focus/save, pivot-scale с affine/детями, настройки воды/legacy/пределы и настоящий файловый API save/reload/invalid POST. Architecture 1249 модулей прошла. Chromium: полный Editor (режимы, native typing, скрытый за корпусом мотор, pivot/undo, автоматическая вкладка, эффекты off/on, save/reload, повторный M с draft) и независимый Inspector (вкладки/клавиатура/sticky/locked/группы), 0 JS-ошибок. 390×844, 820×1180, 844×390 без горизонтального переполнения. UI API в браузерном стенде тестовый; Node API проверен отдельно. Физический iPhone/Safari/PWA не проверен.
- Итоговые TypeScript, полный ESLint, diffcheck и secret scan (0 находок) прошли. Sites и Next/VPS успешно собраны последовательно. Локальный Next dev-сервер также запущен и остановлен; браузерные сценарии проверены отдельным React/Vite-стендом. Документация: `docs/game/boat-garage-editor.md`, новый снимок `docs/game/assets/boat-garage-inspector-tools.webp`.
