# Earth: локальные 3D-исключения и редактор моделей, 2026-10-19

Ветка `earth`, база `36ad8d8`. Пользователь проверил модель вживую: OSM-дубликат перекрывал башню; нужен редактор размещения. Изменения готовятся для ручного переноса через небольшой инкрементальный bundle. Автоматический push и деплой не выполнялись.

## Сделано

- Локальная маска объёмных OSM-зданий: исходный фильтр сохраняется, отдельные контуры в круге под готовой импортированной моделью исключаются; остальной город и плоский слой остаются. Радиус башни — 110 м; маска снимается при скрытии/ошибке модели.
- Реальные тайлы OpenFreeMap объединяют несвязанные дома в MultiPolygon. Ограниченный MVT-преобразователь разделяет их перед worker-фильтрацией, сохраняя отверстия, свойства, ID и чужие слои. Байты провайдера в кэше не меняются.
- `model-placements.json` задаёт координаты, высоту, поворот, подъём и область исключения. Изменения идут через shader uniforms без пересборки/загрузки LOD. Начальный поворот башни — 45° по визуальной привязке к реальному OSM-контуру.
- DEV 3D на обычной карте и отдельная `/prototype/earth-models` без аккаунта/GPS: установка касанием, перетаскивание, поля/ползунок поворота, размер, подъём, видимая зона, переход с кадрированием, черновик, JSON-импорт/экспорт/сброс.
- «Сохранить в проект» пишет только фиксированный JSON на loopback Next dev; общий валидатор, ревизия/409 и атомарная запись. Production закрывает страницу и API; черновики там не читаются.
- Состояние открытия редактора переживает перезагрузку Next при записи JSON. Нативная кнопка достопримечательности не перехватывает перетаскивание DEV-якоря; при закрытии всё восстанавливается.

JS-ошибок нет. Тестовый небезопасный флаг Chromium, удалявший Origin, исключён; защита API не ослаблялась.

Независимое ревью MVT-кодека пройдено. На этом тайле маска исключает 34 контура и сохраняет остальные 2808, включая удалённые части прежних объединённых features.

## Ограничения / следующий шаг

Исходный GLB и оба LOD не менялись. Импортёр всё ещё регистрирует только Eiffel; редактор — для подключённых моделей, не универсальный загрузчик GLB. Текстуры/PBR, рельеф и динамические тени остаются отдельной задачей. Круг скрывает целый отдельный полигон/тайловый фрагмент при пересечении, а не обрезает дом по окружности; слишком большой радиус затрагивает близкие здания.

Физический телефон, полный `npm test`, CI API/Compose и деплой не выполнялись в этом этапе. Перед выпуском соблюдать `CONTRIBUTING.md`. Локальные протоколы: `/tmp/earth-editor-*.log`, скриншоты — только для внутренней проверки.
