# Рабочее состояние - earth

## Земля и геопозиция: первый этап

- Ветка `earth` создана по прямому запросу пользователя от актуального `work/0.7.1`, `29c9eac`. Master и развёртывание не затрагиваются. Предыдущая история работ сохранена в Git на базовом коммите.
- Четвёртая вкладка «Карта»: ленивый MapLibre GL JS 6.15.0, OpenFreeMap/OSM, вращение глобуса, приближение до улиц, север, собственный маркер и геодезический радиус точности. Ракурс сохраняется при переходе в игровую полянку и обратно. Реальные контакты показаны отдельным списком, без выдуманных координат.
- Модуль `features/earth/` независим от `features/world/` и `packages/engine/`. AppShell только передаёт владельца, текущую активность, друзей и переходы. На вкладке Земли компактная шапка освобождает место карте; остальные разделы сохраняют свою шапку. Мобильная навигация содержит четыре кнопки.
- Геопозиция включается только кнопкой «Где я», работает в видимом разделе, ставится на паузу при скрытии страницы/открытии игры. Выход из раздела, смена аккаунта, отзыв разрешения и «Выключить» очищают координаты. Защищены поздние callbacks; координаты не сохраняются и не отправляются в API приложения.
- Permissions-Policy разрешает геолокацию только self; нужны HTTPS/localhost. Карта обращается к внешнему провайдеру тайлов. Worker и лицензия автоматически готовятся из pinned npm-пакета для Next и Sites; generated vendor assets исключены из Git/ESLint.
- Пройдено на текущих исходниках: 26 профильных Earth-тестов; совместный набор Earth/navigation/onboarding/PWA/dev/deploy/gestures — 113/113, без пропусков. Полный ESLint, TypeScript, architecture:check (826 модулей), world:check и обе сборки (Next/VPS и Sites). Production npm audit и secret scan после добавления новых файлов в индекс — 0 находок.
- Браузер: portable Chromium 153/WebGL2, настоящие глобус, тайлы, шрифты и worker. Проверены экраны 320×568, 390×844, 844×390 и 1440×900 без горизонтального переполнения; геопозиция с синтетической точностью 25 м, выключение/очистка, масштаб, вход/возврат из игры и фокус. Принудительный отказ одного PBF сохраняет доступ к карте с предупреждением; повторная загрузка его убирает. Финальный прогон без ошибок JavaScript. Доверие тестовому proxy-сертификату применялось только к изолированному браузеру, не к приложению.
- Документация и дальнейшие этапы: `docs/development/earth-map.md`. Следующее: отдельное согласие на показ конкретным друзьям, Ktor/PostgreSQL + local API, TTL/отзыв/доступ, затем маркеры друзей и native background location. Существующий SharingMode отметок не разрешает передачу геопозиции; награды по клиентскому GPS не выдаются.
- Полный npm test/CI API/Compose ещё не запускался для earth; backend и миграции на этом этапе не менялись. Production/deploy вне задачи.
