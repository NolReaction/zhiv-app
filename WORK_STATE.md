## Подготовлено

- Аудит неизменности V1–V52 и явный PostgreSQL-тест заполненной V52 → V67: аккаунты, кошелёк, инвентарь, здания, оплаченные работы, рынок и полученные подарки; повтор миграций без повторных наград. B49 предназначен только для новой БД. Обычное обновление никому не сбрасывает прогресс.
- Отдельные ограниченные таймауты миграций вместо восьмисекундного лимита API; API сохраняет короткие таймауты. Добавлен настоящий Flyway-тест длинной SQL-транзакции и повторного запуска.
- Deploy закрывает входящие запросы, останавливает запись, создаёт итоговый backup и проверяет настоящее восстановление в изолированной PostgreSQL. Только после успешной проверки запускает миграции; при сбое сохраняет техработы. CI повторяет реальный deploy и сравнивает сохранённые данные игроков.
- Контейнер web получил исходящую сеть для серверной погоды; входящие порты и изоляция БД сохранены. В CI проверяется маршрут через Caddy.
- Исправлены две проверки web: каталог проверяется по всем четырёхместным страницам, сценарий первого сбора использует воспроизводимый seed сцены. Игровые правила ради тестов не менялись.
- README, новость и описание выпуска обновлены до 0.7.1. ID новости сохранён, дата выпуска — 22 октября.
