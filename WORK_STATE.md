# Текущее состояние работы

- Репозиторий `NolReaction/zhiv-app`, ветка `feature/mochlik-tiled-world`, продолжение `1ad3cb4`. Этап: исправление падения `Illegal invocation` после добавления новостей beta-test. Master/деплой не трогать; пользователь одобрил текущую ночь, графика и игровые пороги сохранены.
- Причина падения: нативные таймеры были скопированы в объект окружения и получали неверный `this`. Все четыре операции в `browserReleaseNotesEnvironment` теперь вызываются через ленивые обёртки `globalThis.*`, безопасные при создании адаптера на сервере. Добавлены регрессии настоящего адаптера с проверкой receiver: запуск, очистка после ответа, отмена при отписке и SSR. Прежние тесты подменяли таймеры обычными функциями и этот браузерный сбой не ловили.
- `features/check-in/beta-info.tsx` и новый CSS: кнопка с наследуемым шрифтом, иконкой, числом непрочитанных записей; сверху окна закреплено прежнее сообщение о сотрудничестве, ниже отдельная прокрутка версий. По открытию читается только последняя раскрытая запись, остальные — по раскрытию. Фокус идёт на заголовок, возвращается к кнопке. Beta/уровень имеют область нажатия 44px.
