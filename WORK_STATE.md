## Сделано

- Ветер снижен с −12 до −36 dB на уровне события, включая существующие устройства с сохранённой громкостью; приближение камеры не усиливает его.
- Шаги животных переведены в отдельную группу `footsteps`: 25% по умолчанию, события −22 вместо −14 dB. Миграция сохраняет выключенные/тихие шаги из прежней группы действий. Добавлен отдельный ползунок; интерфейс по умолчанию 100%, сохранённый выбор не перезаписывается. Игровая справка обновлена.
- Потоковая музыка плавно затухает за 2,5 секунды до конца и нарастает за 2,5 секунды после повтора; для коротких файлов — по четверти длительности. Отдельная Web Audio-огибающая не сбрасывается камерой; контроль позиции работает в статичном меню, учитывает паузу, буферизацию и перемотку. Дополнительные потоки и полная декодировка не нужны.
- `scripts/configure-web-push.mjs` создаёт постоянные VAPID-ключи через встроенный Node crypto. Повторный запуск сохраняет существующую пару; частичная/невалидная конфигурация не перезаписывается. Остальные строки `.env` сохраняются, запись атомарна с 0600, ключи не выводятся. Документация даёт запуск через имеющийся web-образ Docker и подключение телефона.

## Следующий шаг

Установить этот коммит обычным `scripts/deploy-update.sh`. Перед обновлением можно выполнить configure-web-push через уже работающий web-образ, чтобы новые ключи применились при штатном пересоздании API. При отдельной настройке после установки достаточно пересоздать API с `up --no-build --force-recreate`, затем проверить готовность. На телефоне: профиль → шестерёнка → уведомления → «Подключить на устройстве»; на iPhone запускать установленную на экран Домой PWA. Для первой доставки выбрать событие через 5+ минут после закрытия приложения; видимая игра и ещё 2 минуты активности подавляют push.
