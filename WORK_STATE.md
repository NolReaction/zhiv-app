# Рабочее состояние - earth

## Установка карты и восстановление загрузки

- Работа в `earth` поверх `3332540` (первый глобус). Ветка создана от `work/0.7.1`, `29c9eac`; история этапов сохранена в Git. Master и production не менялись.
- В приложении четыре раздела: «Я живой», «Люди», «Карта», «Профиль». `features/earth/` отвечает за MapLibre 6.15.0/OpenFreeMap, собственную геопозицию и список реальных контактов. Геопозиции друзей и серверного обмена пока нет; игровой мир и самостоятельный движок остаются отдельными подсистемами.
- До готовности начального вида canvas скрыт и inert, экран подготовки непрозрачный. Реальные стадии, количество файлов/байтов и попадания в кэш. Условие первого показа: idle + loaded/areTilesLoaded + pending0 + failed0; один MapLibre load не подтверждает успешные тайлы. Прерывание допускает повтор и использование уже полученных файлов.
- `resource-cache.ts`: отдельный Cache Storage, 100 МиБ/512 записей, максимум 4 запроса, ограниченные повторы/таймауты, независимая отмена потребителей. Текущая SDK-группа защищена от FIFO; отказ памяти/записи даёт ограниченный session fallback. Публичные mutable-конфигурации обновляются через 24 часа с offline fallback. Ошибки формата и декодера исправляются точечным удалением затронутых ресурсов, включая отказ cache.delete.
- `runtime-loader.ts`: production SDK/worker/shared/license с собственного origin, manifest с размерами и SHA-256, проверка перед Blob import, общий установщик и worker URL на страницу. Подготовка ассетов автоматически включена в Next/Sites dev/build. Обычный LAN HTTP без WebCrypto использует стандартный импорт со своего origin; полноценная работа геолокации требует HTTPS/localhost.
- Удалён удалённый glyph endpoint: подписи рисуются шрифтами устройства. Устранены массовые запросы диапазонов Noto из пользовательского лога. Атрибуция сохранена. WebGL/worker освобождаются при открытии игры; ракурс остаётся в памяти, возврат использует сохранённые данные.
- После F5 восстанавливается только раздел «Карта» для того же владельца в той же вкладке браузера. Камера и GPS-отметки не сохраняются, геопозиция снова выключена до «Где я». Запрос persistent storage защищает данные только при разрешении браузера; очистка данных сайта удаляет карту. Кэш изученных участков не равен всей Земле со всеми масштабами и не заменяет app shell/авторизацию для запуска приложения без сети.
- На финальных исходниках прошли: 156/156 целевых Earth/navigation/onboarding/PWA/dev/deploy/gesture тестов без пропусков; TypeScript, полный ESLint, architecture:check (831 модуль), world:check, Next/VPS и Sites build. Secret scan после добавления новых файлов в индекс: 0 находок. Полный npm test и CI API/Compose не запускались; backend, зависимости и миграции на этом этапе не менялись.
- Chromium/WebGL2: первый запуск скрывает canvas до готовности; SDK Blob worker работает. Повторный вход/F5 и блокировка всего провайдера: 0 запросов SDK/к провайдеру. Прерванная загрузка получила только недостающие файлы; порча SDK заменила только SDK, семантически повреждённый PBF заменил только этот тайл. Запросов /fonts/ и ошибок JavaScript в завершённых сценариях нет. Экраны 320×568 и 390×844 без document overflow. Доверие proxy-сертификату использовалось только в изолированном тестовом браузере.
- Ограничения QA: Safari/iPhone и реальная точность/расход батареи ещё требуют проверки на устройстве. В программном Chromium лесная сцена тормозила даже с удалённой картой; освобождение canvas проверено, окончательный возврат из игры в этом прогоне не подтверждён. Браузер и dev-сервер после проверки остановлены.
- Подробности и команды: `docs/development/earth-map.md`. Дальнейшая геосоциальная работа: отдельное согласие конкретным друзьям, Ktor/PostgreSQL + local API, TTL/отзыв/доступ, маркеры друзей; native background location отдельным этапом. SharingMode отметок не разрешает передачу геопозиции, клиентский GPS не доказывает присутствие для игровых наград.
