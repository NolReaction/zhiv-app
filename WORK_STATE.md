# 0.7.1: автоматическая геопозиция при входе на карту

22 октября 2026. База — master `b89c532603e64be4a5b07aac87520a2825456047` (PR #30). Пользователь подтвердил исправление ложного отказа, но после полного закрытия PWA точка всё ещё требует прицела. Запрошены автоматическое определение при входе, публикация в master и команда обычного обновления сервера. Доступа к VPS здесь нет; деплой выполняет владелец.

## Причина и решение

Автостарт ждал `Permissions=granted`. WebKit может возвращать `prompt` до обращения к Geolocation после загрузки; ожидание change не гарантирует запуск (WebKit bug 275479, comment 2).

Видимая активная карта запускает один настоящий приватный GPS-запрос после загрузки настроек приватности, если автостарт разрешён и призрак выключен. При первом входе/сбросе разрешения браузер может показать системный запрос. Предварительный Permissions больше не блокирует старт; последующий реальный отзыв и native denied сохраняют защиту. Реальный отказ переводит настройку в ready до ручной попытки. OFF→ON тоже остаётся ready. Недоступное первое чтение настройки не считается ON для автостарта.

Координаты не сохраняются между запусками, передача друзьям не включается. Прицел центрирует вид. Версия 0.7.1, схема V68; без изменений API/БД и повторного сброса.
