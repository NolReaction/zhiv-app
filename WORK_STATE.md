# Earth: объекты, камера и ограниченный кеш, 2026-10-18

Продолжение `a0182c4` только в `earth`. Деплоя и изменений `master` нет.

## Сделано

- Достопримечательности заменены нативными low-poly 3D-моделями в WebGL карты: географические основания, общий depth/projection, ограниченное число объектов, скрытие крошечного глобуса и перед улицами. Уличные OSM-экструзии сохранены. При сильном отдалении также скрыты обзорные облака и портрет.
- Звёзды пересчитывают отсечение по фактическому горизонту прямо во время zoom/pitch; night shade больше не исчезает при приближении к улицам.
- Камера и настройки хранятся отдельным небольшим объектом в AppShell. Возврат с полянки и после освобождения Map восстанавливает центр, zoom, bearing, pitch, включённые эффекты и географический якорь режима «Вечер». Logout/смена владельца/F5 очищают снимок; GPS автоматически не возобновляется.
- Погода: до девяти географических участков облаков/осадков в прогнозной ячейке; ясная погода без дождя. Общий request budget 15 секунд, transient backoff 15→30→60 секунд, Retry-After/TTL/stale соблюдаются. Добавлена кнопка погоды и конкретное время следующей попытки.
- Кеш ресурсов: обычно диск 64 МиБ/384 записи и RAM 16 МиБ/96, при deviceMemory≤4 — 32 МиБ/256 и 8 МиБ/64. Вытеснение учитывает текущий вид, повторное использование, давность и детальность. Ограничены очередь, активные тела, метаданные; межвкладочные writes защищены Web Locks. Без Locks новые данные только в RAM. Геокоординат друзей ещё нет; их предзагрузка не подключена.

## Ограничения

Byte budgets считают тела ресурсов, не весь JS/WebGL heap. Декодированные тайлы SDK ограничены количеством 32/64/96; просмотр не запускает массовую предзагрузку. Геообмен друзей отсутствует. В первом QA проходе локальный DEV telemetry POST вернул 404; финальные повторы без HTTP/page ошибок. Caddy/production Compose и Kotlin/PostgreSQL здесь не запускаются; реальное устройство iPhone/Safari/FPS/батарея требуют отдельной проверки.
