# Кладовая: верхнее улучшение и быстрый выбор рыбы

Ветка `0.6.9-economy`, исходный HEAD `b79f452308867fac305e40232dbcfd309e958bab`. Публикация разрешена, CI не ждать. Каталог, экономика, API/SQL, Tiled/PNG, master и деплой не меняются.

## Сделано

- Убраны общий текст продажи и нижний блок расширения с требованиями. В шапке кладовой есть уровень и кнопка улучшения, как у производств. Активная/готовая стройка открывается той же кнопкой; на максимальном уровне без работы кнопки нет. Используется прежнее окно улучшения, простое открытие ничего не расходует.
- Классы рыб получили собственные изображения 32 px с отметкой I–V и пять мягких цветовых палитр. Карточки остаются 90×84 px, горизонтальные ряды сохранены. Контраст текста проверен, минимум 4.80:1. «Все виды» удалено только из холодильника.
- Одно немодальное окно продажи обслуживает все рыбные карточки через virtual anchor без их перемонтирования. Другая рыба переключает вид и начинает с одной, повторный тап прибавляет до настоящего лимита. Поле и «Всё» используют тот же выбор. Продажа требует отдельной кнопки; сохранены точные виды, неизвестный остаток, цель стройки и ограничения цены/кошелька/запаса.
- Общий feedback для холодильника и Плёски показывает короткий отклик рисунка, +1 и подсветку количества. На пределе показывается «Лимит». Размеры, input и фокус не пересоздаются; reduced motion отключает анимации. Устаревший таймер не снимает новый отклик.
- Клавиатурный фокус остаётся на карточке для повторных Enter/Space; ArrowDown переводит к количеству. Escape сначала закрывает собственную продажу, затем кладовую. Внешний обработчик различает свой popup, чужой popup и карту; другие меню сохраняют обычное закрытие. Смена владельца исключает старый перенос фокуса.
- Окно скрывается при исчерпании выбранного вида и само не открывается после пополнения. Старые callbacks после переключения, закрытия, изменения количества или снимка не могут провести продажу. Подсказки уступают немодальному выбору без сброса прогресса и продолжают учитывать подтверждённую продажу. Справка, четыре документа и `/branch` обновлены.
