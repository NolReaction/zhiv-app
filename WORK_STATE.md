# Состояние работы

Релиз **0.6.7** опубликован в `master` одним коммитом `e4e7c06` поверх 0.6.6 (`97c11e0`). Текущая задача — исправление паузы Мохлика поверх этого master, без переноса рабочей ветки. Пользователь явно разрешил обновление master; сервер обновляется отдельно владельцем.

## Состав

Новый мир и жители, память и занятия Мохлика, хозяйство и стройки, производство, рынок, рыбалка, еда и заказы, коллекции и награды, профиль и справка, админская аналитика, восстановление аккаунта, сеть/AFK, иконки и анимированный запуск. Расширенная пользовательская новость — `public/updates.json`; подробности и границы — `docs/releases/release-0.6.7.md`.

DEV-панель и загрузчик недоступны в production на главном экране и карте; prototype возвращает 404, локальный DEV API закрыт, сервер не принимает DEV-выдачу. AFK сохранён по решению владельца. Схема базы — V45, прежние миграции сохранены.

## Исправление паузы

При чужом праве записи автоматически открывается центральное окно «Полянка на паузе» в круге и на карте, поверх игровых панелей. «Продолжить здесь» явно передаёт управление, на карте доступен выход на главный экран. Причина объясняет также предыдущий запуск игры. Фон, offline и обычные паузы сами по себе это окно не открывают; справка обновлена.

Освобождение аренды в фоне не ждёт замороженного таймера; поздний acquire после размонтирования освобождает свою аренду. Потеря или истечение собственной аренды, включая задержанный успешный ответ, сначала вызывают проверку сервера. Чужое управление не перехватывается автоматически. При недоставленном последнем запросе остаётся серверный TTL 90 секунд.

## Проверки и выпуск

Пройдены **63/63** целевых теста, typecheck, lint, актуальность Tiled и проверка секретов. Регрессии синхронизации воспроизводили ошибки до исправления; проверено сохранение защиты чужой аренды. Браузерная проверка реальной production-сборки подтвердила автоматическое окно и takeover-запрос в круге и на карте. Дополнительно проверены ширины 320/390/1280, landscape, клавиатура, порядок модальных слоёв и reduced motion.

Перед публикацией выполняются `npm test`, `npm run build:vps` и CI точного коммита: Repository secret scan, Web checks, Ktor and PostgreSQL checks, Production Compose smoke test. Результат проверяется перед переводом master; нельзя заменять его результатами другого SHA.

Обновление VPS выполняется из чистого checkout зафиксированного релизного SHA командой `bash scripts/deploy-update.sh`. Скрипт собирает образы, создаёт и проверяет читаемость backup, включает техработы, применяет миграции, обновляет API/web и проверяет готовность. Сброс базы не нужен; перенос Git сам по себе не означает развёртывание сервера.
