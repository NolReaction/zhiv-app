# Независимые зоны деревьев — water

13 октября 2026 пользователь попросил отвязать отклик деревьев от Occluders и подготовить удобную папку для ручной разметки. Основа — `c8ec56a1d71491bade51d4495ac056f0254a3452`. Обычный новый коммит в `water`, версия 0.6.9.

## Сделано

- В `world/tiled/forest.tmj` добавлена незаблокированная папка `TreeInteractions` → фиолетовый объектный слой `Crowns`. 15 стартовых полигонов — самостоятельные копии прежних контуров с новыми ID/именами. Все исходные слои, включая Occluders, сохранены без изменений.
- Экспортёр записывает независимый `treeInteractions`; поддерживает вложенные слои, Polygon + уникальный Name, необязательный Class/Type `TreeInteraction`. Свойства `frontY` (локальное Y-смещение, по умолчанию нижний Y), `siteId` + `level` необязательны. Ошибки геометрии/имён/свойств/условий объясняются при экспорте.
- Эффекты используют только `scene.treeInteractions`, без запасного чтения Occluders и без требования суффикса имени. Условные зоны фильтруются по визуальному уровню здания. Пустая папка отключает отклик. Аудио, жесты, анимация и пределы частиц сохранены.
- В документации есть инструкции для добавления, перемещения, правки вершин, удаления и экспорта зон. Для нового дерева достаточно выбрать Crowns, обвести крону и задать имя вроде `river-oak`; role не нужен.

Проверены независимость от Occluders, добавление/движение/удаление, отсутствие fallback и условная видимость.
- `typecheck`, `architecture:check` (588 модулей), `lint`, относительные ссылки/якоря изменённых документов и `git diff --check` прошли. Полный набор, production-сборки и CI не повторялись.

## Следующий шаг

После подтягивания water открыть `world/tiled/forest.tiled-project` → `forest.tmj`, редактировать `TreeInteractions/Crowns`, сохранить и выполнить `npm run world:export && npm run world:check`. Вместе с картой сохранять `forest.generated.json`. Глазик Tiled скрывает разметку только в редакторе; отключение эффекта — удаление зоны. Физический телефон и интерфейс установленного Tiled в этой среде не проверялись.
