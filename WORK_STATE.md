## Реализовано

- Отдельный opt-in для выбранных активных DIRECT-друзей, независимый от SharingMode отметок и групп. По умолчанию OFF, примерный район, срок 1 час (также 8 часов / до ручного выключения). Частная GPS-кнопка сама не публикует координаты.
- Тихий GHOST сохраняет выбор друзей, отзывает publicationEpoch и удаляет точку; OFF дополнительно очищает разрешения. Нет уведомлений или причины исчезновения для получателя. Offline hide сохраняет только намерение; UI не выдаёт его за серверное подтверждение.
- Только latest point с TTL 120 секунд, новые fix не чаще 30 секунд, feed каждые 15 секунд. Эпоха привязана к auth-сессии; CAS, sequence/свежесть, scoped stop, owner/late-response fences. Приблизительная точность применяется до отправки и повторно на сервере. Скрытая карта не ведёт GPS/poll/upload.
- Контроллер в AppShell и панель доступа; friend feed до 100 записей / DOM до 24 маркеров с геоякорями, группировкой и monotonic expiry. Координаты только в RAM клиента, без offline-очереди и истории.
- Dev API и production Ktor/JDBC/V62; latest locations UNLOGGED с периодической очисткой, backup исключает точки. Reset/version fences и миграционные тесты обновлены. Документ: `docs/development/earth-sharing.md`.
