## Реализовано

- «О карте → Вид карты → Карта / Спутник». По умолчанию обычная карта. Выбор не перемещает камеру, снимки загружаются только после явного включения с zoom10. Настройка живёт в RAM экрана, без browser storage.
- `satellite.ts` устанавливает отдельный raster перед `earth-roads-edge` в том же Map. Дороги, подписи, здания, освещение, GPS и друзья остаются сверху. Нет setStyle, перестройки карты, prefetch, прокси или persistent cache спутника. Внешние запросы service worker не перехватывает.
- Ключ проверен живым API: TileJSON `satellite-v2` HTTP200; JPEG HTTP200, 64583байта, 512×512. Контроллер принял реальную metadata и установил слой. Endpoint satellite-v4 из примера документации отвечал404. Raw v2/JPEG без tileSize использует подтверждённые512px; явный размер имеет приоритет. URL без расширения, minzoom0/maxzoom22 и provider attribution поддержаны. Изображения не уменьшаются.
- `NEXT_PUBLIC_MAPTILER_KEY` опционален и встраивается во время Next/Sites build. VPS: Compose build arg → Docker build stage. Без ключа обычная карта работает, спутниковая кнопка недоступна. Реальное значение только в игнорируемом локальном env; в Git пустые примеры. На другом компьютере/сервере ключ необходимо задать в его окружении и пересобрать приложение.
- Предоставленный ключ разрешает localhost/127.0.0.1. Для LAN или `im-alive.ru` нужно отдельно разрешить соответствующий hostname в MapTiler; аккаунт и сервер не меняли. Полные URL и ключ не попадают в интерфейс, диагностику или отчёты.
- Metadata ограничена64КиБ/15секундами, неподвижный viewport ждёт тайлы20секунд. URL, zoom, bounds и credits валидируются. Hidden/offline/editor/отдаление/off отменяют загрузки и удаляют source/layer; поздние metadata не воскрешают слой. Ошибки/403/429/timeout возвращают обычную карту, повтор только явный. Optional source исключён из общей готовности/recovery, его errors изолированы до основного обработчика.
- При установленном растре видны официальный Free-logo, ©MapTiler, OSM/OMT и дополнительные provider credits. HTML преобразуется в ограниченные React текст/HTTPS-ссылки. До включения нет запроса логотипа. На320px атрибуция37px, на368+20px. Действия карты и info подняты статически на18px во всех режимах; общий app dock не меняется. Подсказки не перекрывают base recovery/progress.
