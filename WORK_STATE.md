# Сеть, сохранённое производство и длительная шахта

Ветка `0.6.9-economy`, исходный HEAD `de953d04e6f7f99ebc572a14f85ef8c80ab2a5a8`. Пользователь разрешил изменения сети/локального сохранения и полный пересчёт шахты с 2–4 вариантами ресурса. Обычный коммит/push разрешены, CI не ждать. Master, grid-world/3D engine, Tiled/графика и деплой не меняются. Реликвии/жемчужные выплаты не перебалансируются.

## Сделано

- Вместо замены приложения AFK-экраном удерживается тот же мир и меню; компактный semantic modal поверх него. Отдельный suspended прекращает сцену без смены open/камеры, Escape уступает верхней паузе. Сетевая проблема в загруженном мире оставляет навигацию и безопасные локальные запуски производства, показывает небольшой индикатор.
- У экономики bounded localStorage очередь до 12 nonfish start_production. Материалы и ячейки резервируются только в отдельной productionSnapshot; реальные награды и canonical snapshot подтверждает сервер. Ячейка сразу показывает «Сохранено», не готовый результат/ложный таймер. UUID+тело отправленного запроса неизменяемы, unsent проверяется заново после ACK. Web Lock исключает двух владельцев журнала; ошибка записи не выдаётся за сохранение. Время до доставки не считается временем производства.
- Cached snapshot не считается подтверждённым; серверная версия заменяет его даже при более низкой revision. Отдельные direct/local/delivery gates не позволяют покупать/получать награды между presence и завершением reconcile. Мировой контроллер тоже получил direct gate для новых writes, старые квитанции можно сверять.
- Сетевые ошибки мира, экономики, рынка и обмена идут только в индикатор; ошибки игровых правил остаются рядом с действием. Единственный DOM-host значка и подробностей переходит в верхний диалог, сохраняя его focus/pointer scope. Клики по значку/возврату не закрывают кладовую; быстрый ACK не мигает значком.
- Активность учитывает реальный ввод офлайн до AFK-границы, sticky resumeRequired держит явный возврат до успешной сверки. Повтор связи автоматический с backoff, singleflight и сохранением Retry-After.
- Шахта: по 3 focused варианта камня/глины/песка и 4 руды, один шахтёр. Короткие старты сохранены; есть 1ч и 8ч партии, руда ещё16ч. Новые 8ч mixed смены дают1920/2140/2360NPC-стоимости по уровням; abandoned_quarry=48руды/16ч без платы. Цены сырья и маржа рецептов не меняются. Старые jobs получают/возвращают сохранённую стоимость. UI группирует ресурс в одну карточку с кнопками времени/выхода, mixed свёрнуты. Отмена шахты теперь честно обещает возврат припасов.

- Root: API/шахта/catalog/UI 128/128; финальные activity/routing/upgrade/help 58/58. Расширенные regression-пакеты выявили только устаревшие ожидания текста справки и двух новых часовых маршрутов; исправленные файлы отдельно прошли 28/28 и 8/8. Остальные случаи этих пакетов прошли.

Retained-world 44/44; индикатор/AFK/forest UI 23/23. Сценарии экономики и /branch сверяют реальные количества без платных слотов и расширенной кладовой.
