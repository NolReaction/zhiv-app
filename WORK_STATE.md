# Состояние работы

Ветка `work/0.6.7-building-levels`, основа `fe2229f` (последняя аналитика админки). Пользователь поручил пункты 2/3: закреплённую цель улучшения и возврат из кладовой к подарку; commit/push разрешены без ожидания CI. Сюжетные подсказки оставлены для отдельной работы.

## Сделано

- Одна цель на конкретный следующий уровень: закрепление в улучшении, текущий дефицит на карте, в производстве, вылазках и кладовой, переходы к улучшению и источникам. Хранение отдельно для аккаунта в localStorage; подтверждённая оплата/завершение снимает цель. Устаревший снимок другой вкладки не удаляет более новую цель.
- Кладовая помечает нужные запасы. Продажа излишка сохраняет прямые материалы и сырьё для недостающих изделий, учитывает общие ингредиенты и целые партии. Количество обновляется вместе с запасами; снятие цели блокирует выбранную продажу излишка. Ручная продажа остаётся доступной с предупреждением.
- При нехватке места подарок ведёт в кладовую с кнопкой возврата. Диалог сохраняет контроллер и квитанцию; получение заблокировано до освобождения места. Переходы и открытие ничего не начисляют. Добавлены проверки навигации, продаж, хранения цели и двух вкладок; обновлены тематические документы и справка.

## Проверки

- TypeScript, полный ESLint, world:check, security:check (включая новые файлы) и git diff --check — успешно.
- 143 целевых веб-теста — успешно, без пропусков. Проверены цель, расчёт сырья, продажа, подарки, навигация, производство, улучшения и справка.
- Свежие сборки Sites и Next/VPS выполнены последовательно — успешно.
- Chromium с настоящим локальным API и отдельным временным аккаунтом: полный путь подарка через продажу в кладовой, сохранение цели после перезагрузки, продажа 160 из 192 единиц древесины с сохранением 32 для цели, блокировка повторной продажи без излишка, возврат фокуса. На 320/390/1280 px нет горизонтального переполнения; на 320 px выбранный рецепт прокручивается внутри меню, без сдвига страницы. Ошибок JS нет. Физические устройства и Safari не проверялись.

## Ограничения и следующий шаг

Цель локальна этому браузеру, между устройствами не синхронизируется. Расчёт не резервирует товары на сервере, не учитывает будущие побочные продукты, неполученные заказы и стройматериалы зависимых зданий; при цикле/переполнении расчёта запасы сохраняются консервативно. Экономические правила и серверные команды не менялись.

Локальные проверки завершены, этап готов к обычному commit/push в согласованную ветку. CI не ждать по указанию пользователя. Master и деплой не входят в задачу.
