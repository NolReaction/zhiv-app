# Состояние работы

Релиз **0.6.7**, подготовленный одним коммитом поверх `master` 0.6.6 (`97c11e0`). Исходный снимок — `work/0.6.7-building-levels` на `31d7ade`: все итоговые изменения включены, 164 промежуточных коммита не становятся историей master. Пользователь явно разрешил публикацию master; сервер обновляется отдельно владельцем.

## Состав

Новый мир и жители, память и занятия Мохлика, хозяйство и стройки, производство, рынок, рыбалка, еда и заказы, коллекции и награды, профиль и справка, админская аналитика, восстановление аккаунта, сеть/AFK, иконки и анимированный запуск. Расширенная пользовательская новость — `public/updates.json`; подробности и границы — `docs/releases/release-0.6.7.md`.

Игровой код и ресурсы релизного снимка совпадают с исходной веткой; при подготовке обновлены только этот файл и вводная релизного документа. DEV-панель и загрузчик недоступны в production на главном экране и карте; prototype возвращает 404, локальный DEV API закрыт, сервер не принимает DEV-выдачу. AFK сохранён по решению владельца. Схема базы — V45, прежние миграции сохранены.

## Проверки и выпуск

Дополнительно пройдены **41/41** целевых проверок DEV API, читов и отключённого состояния панели. Для публикации используется CI точного релизного SHA: Repository secret scan, Web checks, Ktor and PostgreSQL checks, Production Compose smoke test. Результат проверяется перед переводом master; при повторной подготовке нельзя заменять его результатами другого SHA.

Обновление VPS выполняется из чистого checkout зафиксированного релизного SHA командой `bash scripts/deploy-update.sh`. Скрипт собирает образы, создаёт и проверяет читаемость backup, включает техработы, применяет миграции, обновляет API/web и проверяет готовность. Сброс базы не нужен; перенос Git сам по себе не означает развёртывание сервера.
