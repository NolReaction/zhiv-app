# Торговый корабль: наклон и двухэтапный отход · 0.7.2

26.10.2026. Изменения для `work/0.7.2-ship`, продолжение снимка `b744040`. Пользователь уточнил поворот изображения и последовательность отхода. Передача через Git bundle; публикация в GitHub не выполняется.

## Готово

- Подход справа снизу за 18 активных секунд: добавочный наклон PNG по часовой стрелке начинается с `+0.28` радиана и плавно становится нулевым у причала. Базовая калибровка рисунка `0.12` радиана сохранена для ровной стоянки.
- Отход длится 22 секунды. Первые 6 секунд — только вправо на 111.6 мирового пикселя (`0.36 × width`), без изменения `y` и угла. Затем 16 секунд — вниз с небольшим сдвигом влево на 99.2 пикселя от крайнего правого положения. В первые 6 секунд второго этапа PNG плавно поворачивается против часовой стрелки до `−0.60` радиана; начальный спуск пологий, поэтому поворот виден до ухода за карту.
- Стоянка `705/1102/310` сдвинута на 12 пикселей к морю для нового манёвра. Painter допускает добавочный угол до ±π/3. Это поворот одного PNG в плоскости экрана; дополнительные объёмные ракурсы не добавлялись.
- Исходный прозрачный PNG 1774 × 887 сохранён без перекодирования. Дверь входит в PNG; пар и вода рисуются отдельно. Экспорт PNG со стенда сохраняет ровный вид, без наклона текущего рейса.
- **DEV → Сцена → Погода**: «Приплыть», «Отойти», «У причала», «К кораблю». Общий временный рейс сохраняется при переходе круг/карта; его двигает один активный владелец после загрузки PNG. Пауза, скрытие и reduced motion не накапливают время. Переключатель по умолчанию выключен; сброс DEV сбрасывает корабль, чужая полянка исключена, прогресс аккаунта не меняется.
- Версия HMR-кэша обновлена, чтобы старый контроллер рейса не переживал замену манёвра. Архивы `*.bundle` исключены из Git; после успешного импорта и проверки ветки архив можно удалить.
