# Текущее состояние работы

- Репозиторий `NolReaction/zhiv-app`, ветка `feature/mochlik-tiled-world`. Получен пользовательский коммит `93c6e9f` с водной разметкой; исходник `world/tiled/forest.tmj` и графика сохранены без изменений. Master/деплой не трогать.
- Текущий этап: подключение существующих эффектов к Tiled. `Water` задаёт поверхности, `WaterExclusions` — исключения; оба поддерживают объектные слои и вложенные группы. Назначение определяется именем корневого слоя, `role` не нужен. `Top Down`/`Manual` разрешены для водной разметки.
- Экспорт содержит `water.surfaces` и `water.exclusions` в координатах мира. Проверены 863 вершины реки и 53 исключения; самопересечений/выходов за карту нет. `world:watch` переносит сохранения и оставляет последний корректный экспорт при ошибке.
- `forest-water.ts` читает только экспорт Tiled; прежняя ручная `forest-water-layout.json` удалена. Поверхности объединяются, пересекающиеся исключения вычитаются; направление обхода не влияет. Маска обновляется с новой сценой. Без водной разметки речных эффектов нет.
- Рисование дождя/всплесков/луж и параметры речной анимации не менялись; изменены только геометрия и размещение эффектов. Точки посадки птиц по-прежнему привязаны к версии фона `fedcfbd622df`.
- Проверки: полный набор 526/526 веб-тестов; после правок маски повторены целевые тесты, typecheck, lint, world:check и обе сборки (Sites и Next/VPS). Просмотрены дневной/ночной Canvas-рендеры; независимая проверка обрезки на 200 000 пикселях при 1×/2× пройдена. Пользовательская разметка и код дождя/луж не изменены.
- Ограничение проверки: браузерный предпросмотр ранее недоступен; скорость на телефоне не измерена. В native CPU Canvas подробная векторная маска даёт ~16 мс для воды при 700 px против ~3.6 мс прежней упрощённой; это не измерение браузера. Экспериментальное ускорение через промежуточный растр не включено: точная обрезка важнее, визуальные эффекты сохранены.
- Далее: обычный просмотр пользователем после pull через DEV; для редактирования контуров — `npm run world:watch`. Подробности — `docs/game/tiled-editor.md`.
