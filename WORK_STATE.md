# Студия света — руководство и организация объектов

14 октября 2026. Ветка `work/lighting-studio`, исходный коммит `4d01094`. Публикация в этой ветке разрешена; master, серверный API/БД и деплой не входят в задачу.

## Сделано

- Практическое руководство `docs/game/world-lighting-studio.md`, ссылки из документации. Объяснены контуры, высоты, источники, клавиши, сохранение, JSON и конфликты. Широкая земля через дом допустима для первого предпросмотра; ночная маска накладывается на готовую сцену, поэтому для аккуратного результата видимую землю размечают несколькими полигонами вокруг силуэта. Внутренние отверстия не поддерживаются.
- Общие поля имени и папки для объёмов, поверхностей и ламп. Enter/blur сохраняют имя, Escape отменяет; технический ID остаётся прежним. Папку можно выбрать в свойствах, создать вложенный пользовательский путь или перетащить элемент на папку мышью. Назначение раскрывается, выбранный объект остаётся видимым. На телефоне доступен select; сохранённый предпросмотр блокирует правки.
- Необязательные `studioName`/`studioFolder` проходят через Undo/Redo, localStorage, backup, patch v3, Tiled Custom Properties и generated JSON. Очистка возвращает автоматические имя/папку. Сохранение/ACK, повтор операции и конфликты учитывают metadata; геометрия, when и физические слои не меняются. На карте показывается пользовательское имя. Старые файлы без metadata поддерживаются.
- Исправлена потеря набранного имени при выборе другого объекта на canvas до blur. Выключенные источники остаются в системной папке до восстановления. Пустые пользовательские папки исчезают; папки упорядочивают список, а не задают условия уровня здания.

## Проверки

- Целевые store 50/50, CLI 25/25, writer files 8/8, UI 16/16 и canvas-map 21/21 прошли. Метаданные проверены до реальной записи пары .tmj/generated и повторного чтения, включая очистку, конфликт, ACK и Undo.
- Typecheck, полный ESLint, architecture (615 модулей), world:check, audio:check и security (0 находок) прошли. Независимый обзор кода и руководства завершён.
- Native Chromium: настоящий React-компонент студии в изолированном Vite harness; Enter/blur/Escape, select, вложенная папка, Undo/Redo, native drag/drop, запрет правок в saved, восстановление localStorage после reload. Экраны 1440×900, 390×844, 320×844 визуально проверены, горизонтального переполнения и page errors нет. Harness не запускал игру/живые аккаунты и не подменяет проверку реального Next HMR или физического телефона.
- Полный `NODE_OPTIONS=--max-old-space-size=6144 npm test`: 3971/3971, ошибок, отменённых и пропущенных сценариев нет; весь new-map-scene прошёл единым прогоном. Итоговые Sites и Next/VPS сборки прошли. Первый VPS-запуск отклонил внешний symlink node_modules; после физического размещения тех же зависимостей повторная сборка успешна.

## Границы

Реальная разметка карты и её generated JSON в этом изменении не меняются. Имя элемента не переименовывает PNG/ID/файл экспорта. Клавиши и общий lifecycle студии сохраняют прежнее поведение. Для физического света стен и крыш нужен отдельный этап рендера; текущая разметка этого не реализует. Реальный Next HMR этой задачей заново не проверялся; его предыдущая реализация и автоматические регрессии сохранены.
