# 0.7.2-fishing: маска переднего борта в студии

Ветка `0.7.2-fishing`, база этапа `78b96bd`. Разработка и Git разрешены; master/deploy вне задачи. `releaseValidated=false`.

## Текущий этап — 4 ноября 2026

- В `/prototype/boat-garage` добавлен инструмент «Борт / маска». Изображение корпуса владеет контуром; отмеченные целые бак/ящик/группа с потомками скрываются за ним без изменения PNG. Используются исходная альфа и мировой affine: прозрачные места корпуса не перекрывают предмет, контур следует повороту/скосу/отражению/растяжению.
- В инспекторе: создать/править/перерисовать контур, включить/удалить, явный выбор целей. «Поднять детали над корпусом» одним undo поднимает отмеченные незакреплённые ветви над его zIndex; locked-слои остаются прежними. Корпус и его предки не могут стать собственными целями.
- Ручки точек, вставка по ребру, Delete/Backspace при минимуме 3 и максимуме 64 точек; вогнутые контуры допустимы, самопересечения и вырожденная геометрия отклоняются. Один drag — один undo. Новый рисунок остаётся локальным до Enter/двойного клика/замыкания; Escape/выход отменяет его. Ctrl/⌘ Z/Y работает с точками draft. Save/JSON и toolbar history защищены во время рисунка. Delete не удаляет корпус даже после отмены создания маски.
- Необязательное `node.occlusion={enabled,points,targetIds}` сохраняется в JSON/API/черновике; points нормированы 0..1. Старый JSON без поля не изменён. Удаление цели чистит ссылки, copy глубокий; смена картинки корпуса требует проверки контура. Переход к группе очищает её маску.
- Выбор/ручки предмета остаются поверх борта. В водном предпросмотре маски движутся вместе со сборкой; скрытые владельцы, их скрытые предки и владельцы вне water subtree не перекрывают детали. Работают большой холст и макеты устройств.
- Проверки: 91/91 garage-тестов, включая настоящий локальный файловый API save/reload и отказ invalid POST без перезаписи. TypeScript, architecture (1249 модулей), полный ESLint и diffcheck прошли; итоговые Sites и Next/VPS собраны последовательно. Secret scan: 0 находок. Независимый Chromium QA: 19 pixel-проверок alpha/нескольких масок/групп/отрицательных координат/affine/воды; overlay и keyboard edgecases; реальный React Editor — create/targets/zIndex/точки/undo/draft/save/reload/водный режим, 390×844/820×1180/844×390 без горизонтального переполнения, 0 JS-ошибок. UI-стенд использует тестовый файловый API; настоящий Node API проверен HTTP-тестом. Физический iPhone/Safari/PWA не проверен.
- Документация: `docs/game/boat-garage-editor.md`, снимок `docs/game/assets/boat-garage-occlusion-editor.webp`. Пользовательская сцена и файлы изображений не перезаписывались; прежние вырезки не получают отсутствующие пиксели. Игровая мастерская/рыбалка/экономика не переключены.
