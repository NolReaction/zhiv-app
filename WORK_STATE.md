- Пользователь одобрил основу живого леса (`docs/game/living-world-plan.md`): непрерывная жизнь насекомых, настоящие встречи, свободная полянка, выбор занятий, Tiled и DEV. Камера принята; дорисовка сверху/снизу отложена. Новые путешествия/рыбалка/стройка/крафт закрыты через `presentation.ts`.
- Источник разметки — `world/tiled/forest.tmj`; экспорт только `npm run world:export`, проверка `npm run world:check`. В этом этапе источник и generated JSON не изменены. Памятка редактора — `docs/game/tiled-quickstart.md`, полный справочник — `docs/game/tiled-editor.md`; вершины редактируются клавишей O. Скрытые слои/объекты экспортёр не принимает, блокировки безопасны.
- `navigation.ts`: кешированная сетка, ограниченный A*, проверка движущегося круга опоры, запрет срезать углы/воду/коллизии, безопасное сокращение пути. `forest-behavior.ts` выбирает точки интереса и свободную траву с учётом погоды, отдыха, повторов. Радиус опоры = 0.1 размера, текущий шаг сетки 6. Поверх поиска работает `steering.ts`: проверенные короткие отрезки квадратичных дуг, уменьшение закругления у препятствий и возврат к исходному углу, если дуга не помещается.
- Подходы к интерактивным объектам: `interaction-navigation.ts` готовит локальные входы дома/кустов независимо от Routes. В авто-режиме подход начинается с текущего положения; после посещения герой остаётся у куста или на доступной земле перед дверью. На текущей карте home-entry чуть вне WalkAreas: короткий соединительный участок наружу по оси doorway→entry (не более 0.24 размера) связывает его с полноценной опорой. Только собственная коллизия дома разрешена в локальном переходе; вода, Obstacles и другие здания запрещены. Прыжок в куст отдельно проверяет entry/hide/листву/препятствия.
- `clearing-activity.ts` владеет всей ходьбой/порогом/прыжком: динамический подход, безопасный короткий выход, прерывания, очередь следующего посещения. Тап перед входом останавливает на текущей безопасной земле; из узкого порога сначала выводит наружу. 180 секунд видимого неактива ведут домой с текущего места. Входы, прыжки, пробуждение и ягоды сохранены. Новая команда во время выхода не телепортирует и не сбрасывает прыжок.
- `forest-director.ts` связывает обитателей, предметы и движения. Запрошенный гриб/насекомое после выхода получает реальные координаты героя, не ждёт spawn. Короткий обязательный выход продолжает работать при выключенных автосценках. `requestClearingOutside` заканчивает переход поблизости; `returnClearingHome` остаётся для явного возврата/смены DEV-режима.
- Routes необязателен для текущего свободного мира: проверен экспорт исходной карты без всего слоя, остальное содержимое совпадает. Слой сохранён для старых карт, прототипа и DEV «Прежние маршруты». Его можно оставить заблокированным; скрытие глазом запрещено экспортёром. Смена контроллера по-прежнему происходит после физического возврата к spawn. В DEV добавлены «Входы дома и кустов» с причинами отказов; готовность локального входа не обещает связность полного пути.
- `forest-fauna.ts` и `hero-anchors.ts`: постоянные ID/облик/координаты, растения, подлёт к реальной лапе, физический отлёт. Бабочки только днём, светлячки только ночью, включая DEV/паузу/reduced motion. `excludeHabitatId` вычитает clearing из forest; `forest-habitats.ts` обходит исключение, не меняя воду/землю.
- `forest-session.ts` хранит координатор, обитателей и птиц. Круг и карта используют одну сессию/позицию/позу; рендер не двигает симуляцию. Background/pause/reduced motion останавливают новые движения. DEV только development, серверную экономику не меняет.
- Локально: `npm ci`, `npm run dev:local`, отдельно `npm run world:watch`. Локальный memory API может очиститься после перезапуска.
- Steering: `prepareSteeringPath` один раз готовит безопасную ломаную и ограничения скорости по кривизне. `desiredSteeringSpeed` кеширует консервативный тормозной профиль, обычный кадр ищет свой сегмент бинарно. `clearing-activity.ts` дополнительно проверяет реальную хорду между кадрами, не срезает несколько вершин дуги за редкий кадр и отдельно проходит точный участок крыльца. Четыре направления спрайта имеют гистерезис 10° вокруг диагоналей. Нулевые подходы, точные входы/прыжки, пауза и смена камер сохранены; новой разметки Tiled нет.
