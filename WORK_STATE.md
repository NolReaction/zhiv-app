# Состояние работы

## Unity: первая объёмная поляна

Ветка `work/0.6.8-unity` создана от рабочей `work/0.6.8` на `347e260`. Phaser и обучение новичка остаются отдельными ветками. Пользователь выбрал Unity, настоящие 3D-здания и фиксированную камеру без вращения; разрешил Git-операции. `master`, деплой и данные игроков не менялись.

Добавлен отдельный проект `apps/unity/`, Unity **6000.3.26f1**, URP **17.3.0**. Через меню `Zhiv/Create or Open 3D Clearing` Editor создаёт обычную редактируемую сцену и persistent модели/материалы/prefab: дом-пень, мастерскую с отдельным молотом, деревья, камни, пруд и временного 3D-Мохлика. Повторное открытие не пересоздаёт сцену и не перезаписывает авторские правки. Сгенерированные `.unity/.asset/.prefab/.mat` появятся при первом запуске Editor; сохранять их в Git нужно с `.meta`. Исходный коммит содержит генератор, конфигурацию и код, а не уже проверенную Editor-сцену.

Есть ортографическая камера 45°/45°, drag/pinch/wheel, распознавание короткого нажатия, safe-area панели и блокировка нажатий сквозь HUD. Герой ищет путь по плоской сетке с запасом под тело; реальные collider/capsule-проверки не дают резать углы и проходить сквозь здания. День/вечер меняет солнце и Trilight, мастерская запускает/останавливает молот. Небольшой участок использует логику старой карты как ориентир; полной конвертации Tiled нет.

Runtime отделён от Editor через asmdef. Добавлены Web build-команда, Editor-проверка связей/материалов и маршрута вокруг мастерской, метаданные и игнорирование Unity-кешей. Подробный запуск, управление, ручные проверки и границы: [apps/unity/README.md](apps/unity/README.md).

## Следующий шаг

В Unity Hub открыть `apps/unity`, дождаться импорта, создать сцену через меню Zhiv, выбрать Game 9:16 и нажать Play. Выполнить `Zhiv/Validate Open Clearing`, прислать первую ошибку Console при наличии и скриншот Game. Затем подогнать размер зданий, ракурс и расстояние камеры, проверить Web/iPhone. После первой успешной генерации закоммитить созданные Editor ассеты, настройки и package lock.

Это прототип внешнего вида и управления, не готовая миграция игры. Экономика, аккаунт, сохранение мира и прежний TypeScript-аудиодвижок в Unity пока не подключены. Конфигурация модели (метры, XZ, Y-вверх, опора у земли) задокументирована для следующей замены одного здания на модель из Blender. Навигация по высотам, строительная сетка игрока, финальный UI и интеграция API — дальнейшие этапы.
