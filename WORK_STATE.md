## DEV: тестовые друзья

2026-10-19. Дима попросил создание бота и управление им для проверки настоящих визитов и торговли. Продолжение опубликованного `3824741113a1a14440b5c776427a0cd3b0ab1439`. Публикация рабочей ветки разрешена; master, earth, деплой и production DB вне задачи.

- На главном экране и своей карте появилась вкладка **DEV → Боты**. До пяти отдельных локальных аккаунтов с автоматически принятой дружбой. Собственные уровни/кошелёк игрока автоматически не меняются.
- Управление выбранным ботом: имя/видимость, поселение с домом 1–5, отдельные здания, цвет/головной убор/шарф/удочка, валюта/предметы, обычные задания и таймеры, получение результатов.
- Личная лавка использует общую рыночную транзакцию. «Выдать недостающее для партии» пополняет только запасы бота; выставление/снятие и покупка сохраняют реальные игровые ограничения. «В гости» обновляет обычный список друзей и проверяет актуальную принятую связь перед входом.
- Только локальный NODE_ENV=development. GET/POST `/api/v1/dev/bots`: origin/body/auth/presence, owner binding, private server credentials, управление только собственными помеченными ботами. Токены не передаются клиенту. Production API Ktor и миграции не менялись.
- Каждая команда имеет requestId и owner-scoped receipt; потерянный ответ восстанавливается тем же запросом после закрытия/перезагрузки. Новые команды до проверки заблокированы. Late/cross-account ответы игнорируются.
- Удаление с подтверждением очищает выбранного бота, его дружбу, мир, экономику и лоты; посторонние пользователи сохраняются. Боты живут в памяти локального API и могут исчезнуть при его перезапуске.
- Инструкции: `docs/development/local-development.md#тестовые-друзья-и-их-лавки`; основные файлы: `features/world/dev/{dev-bot-*,use-dev-bots,world-dev-bots}`, `lib/dev/bot-store.ts`, `app/api/v1/dev/bots/route.ts`.
