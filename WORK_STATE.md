# Рабочее состояние: earth

## Достопримечательности на своих географических местах

- Работа в `earth` поверх `e2f0dbd`. Прежний ступенчатый природный декор заменён девятью узнаваемыми достопримечательностями. Удалены его модуль, источник и два слоя; стиль теперь содержит 37 слоёв.
- `landmark-catalog.ts`: пирамиды Гизы, Эйфелева башня, Колизей, храм Василия Блаженного, Тадж-Махал, Великая стена у Бадалина, Статуя Свободы, Христос-Искупитель и Сиднейская опера. Якоря памятников/комплексов проверены по UNESCO Maps, официальным картам владельцев и туристических офисов; St Basil использует Wikidata P625 отдельно от страницы ГИМ. Для каждого сохранены sourceUrl, coordinateSourceUrl и точное примечание происхождения/приближённости.
- `landmark-art-europe.ts`, `landmark-art-world.ts`: оригинальные компактные SVG с изометрическими гранями; иллюстрации, не точные 3D-модели. Нет сторонних картинок, шрифтов, моделей или сетевых ассетов. Предпросмотр 48/64 px проверен.
- `globe-landmarks.ts` и CSS: девять native Marker с фиксированными координатами, опора рисунка y=112/120 совмещена с геоякорем. SDK управляет внешними transform/opacity и горизонтом; наша CSS действует внутри. `landmark-layout.ts` учитывает реальные inkBounds рисунков (измеренные SVG, запас под штрих), зазор 4 px, экран/covered; геоякоря не сдвигаются. На телефоне это оставляет пять моделей вместо двух; соседние раскрываются при zoom. Fade 3.8→5.2. Название по нажатию/фокусу, одна актуальная подпись; Escape/движение/нажатие по карте закрывает. Скрытые объекты disabled/tabIndex=-1/aria-hidden. Lifecycle принадлежит общему globe-scene, собственных таймеров нет.
- 262/262 целевых Earth/navigation/onboarding/PWA/dev/deploy/gesture теста прошли. Полный TypeScript/ESLint, целевой ESLint после inkBounds-полировки, architecture:check (855 модулей), world:check прошли. Секреты после индексации новых файлов: 0 находок. Чистый Chromium QA завершён. Обе production-сборки Next/VPS и Sites прошли; полный npm test/API/Compose не запускались, это этап фронтенд-разработки без деплоя.

Backend/мир/Tiled/зависимости не менялись, деплоя нет. Природные зоны больше не используются; облака/океан/вечерний свет/Мохлик сохранены. Реальные iPhone/Safari/FPS/батарея требуют устройства.
