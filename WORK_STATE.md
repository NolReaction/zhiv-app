# Текущее состояние работы

- Репозиторий: `NolReaction/zhiv-app`; ветка `feature/mochlik-tiled-world`. `master` не менять, не деплоить.
- База этапа: `80aa6af` — чистая сцена новой карты. Текущий этап: связать Tiled с основным приложением и быстрым предпросмотром.
- Источник геометрии: `world/tiled/forest.tmj` → `features/world/tiled/forest.generated.json`. Основной мир, круг и прототип используют один экспорт: фон, начальные состояния зданий, квадрат `clearing-focus`, точку `mochlik-spawn` и её `size`. Координаты больше не дублируются в `presentation.ts`; границы камеры берутся из размеров сцены.
- В Tiled: `role=focus` — квадрат круглой камеры; `role=spawn` — точка под ногами Мохлика, `size` типа float — размер героя; `role=path` — полилиния с уникальным именем. Исходные настройки: focus 455/480/350/350, spawn 630/660, size 36. Менять их можно в редакторе.
- Рабочий цикл: открыть `world/tiled/forest.tiled-project`; отдельно `npm run world:watch` и `npm run dev:local`; сохранить карту, проверить `/prototype/tiled-world` и основной экран. Watch не переписывает TMJ, сохраняет последний корректный JSON при ошибке, восстанавливается после следующего сохранения. Разовый экспорт: `world:export`; перед коммитом: `world:check`.
- Маршруты проигрываются только в прототипе: выбор линии, старт, разворот, возврат к spawn. Автоматических соединений маршрутов и игровых походов нет. Здания показываются в initialLevel; покупки и игровой прогресс улучшений ещё не подключены.
- Изображения этого этапа не менялись: PNG в `art/world/prototype/`, WebP в `public/world/prototype/`. После изменения изображения вручную подготовить WebP и выполнить `world:export`. Инструкция: `docs/game/tiled-editor.md`.
- Режим перестройки остаётся включён: старые эффекты/декор и новое строительство/путешествия/крафт отключены. Данные игроков, награды и получение наград за ранее начатые путешествия сохранены. `grid-world`, backend, миграции, инфраструктура не менялись.
- Проверки этапа: Sites build + 420 веб-тестов; Next/VPS build; после финальных исправлений — typecheck, lint, world:check и 92 целевых теста. Проверены изменения фокуса/героя/размеров мира, общий рендер, маршруты, коллизии, reduced motion, очистка ресурсов, атомарное сохранение и восстановление watch. Тесты разметки не фиксируют конкретные координаты пользовательской карты.
- Ограничение проверки: браузерный доступ к локальному стенду ранее блокировался; реального Tiled 1.12.2 в текущей среде нет. Сохранение из редактора и внешний вид на телефоне проверить локально. Проверки не выдаются за визуальную проверку.
- Следующий этап: пользователь правит камеру и точку Мохлика, рисует маршруты; после проверки отдельно согласовать игровые действия и разметку зданий. Не начинать автоматическую переделку игровых систем.
