# Engine — проекты v6 и диагностика

Ветка engine, база этапа 75d4d07. Пользователь уточнил: развиваем существующий /engine по предложенному плану. Рендер — Canvas 2D; полноценное 3D не входит в этот этап. master и деплой не меняются.

## Сделано

- Универсальный SceneDocument v6: ID/имя, обе размерности, шаблон/версия и сохранённый baseObjects. Исходные предметы фиксируются при создании; обычное открытие не запускает генератор повторно. Смена seed явно создаёт новую базу и доступна Undo. Прежние v1–v5 мигрируют через сохранённый валидатор.
- Каталог управляет палитрой, именами, вариантами, папками и размещением. Шаблоны forest-v5 и независимый empty-v1 с ящиком/маячком/PNG. Общий контроллер работает с произвольной высотой; legacy createForestController сохраняет v5 API и синхронный storage.
- Менеджер проектов: создать, открыть, переименовать с Undo, скопировать, удалить с подтверждением, импортировать JSON под новым ID, экспортировать полный документ и восстановить сохранённую версию после конфликта. Модальное окно и панели адаптированы для клавиатуры и узких экранов. JSON получает имя проекта; импорт и legacy-перенос проверяют полный PNG до записи. Повторное открытие активного ID сохраняет актуальный документ.
- IndexedDB хранит manifest отдельно от точных PNG Blob. Запись/ресурсы/GC атомарны. SHA-256 дедупликация, ограниченный ресурсный кэш, revision CAS и сохраняемые версии после удаления защищают от устаревшей записи/удаления другой вкладкой.
- Асинхронная сессия объединяет правки и отмечает «сохранено» после записи последней ревизии. Переключение ждёт запись; ошибки сохраняют доступный для экспорта документ. Одноразовая миграция localStorage записывает метку атомарно и оставляет исходный JSON; при недоступной БД прежняя сцена остаётся открытой в памяти.
- Опциональная диагностика: последние/медиана/p95 paint, commit, undo, save, export; ограниченное окно и оценка кэшей с дедупликацией поверхностей. Это не FPS и не полная память браузера. Самостоятельная точка входа использует StrictMode.
- Добавлены [проекты и формат](docs/engine/projects.md), [диагностика](docs/engine/diagnostics.md); обновлены запуск, архитектура и руководства. fake-indexeddb 6.2.5 — только devDependency для transaction-тестов.

## Дальше и ограничения

Этап завершён и сохраняется отдельным коммитом в engine. Хранение локальное для одного origin; перенос между портами/доменами — JSON. Для хеширования PNG нужен Web Crypto (HTTPS или localhost). Закрытие страницы не гарантирует async-запись: индикатор и JSON-копия остаются значимыми. Список/GC читают manifests; полный бюджет кэшей и большие операции будем оптимизировать по замерам.

Следующие этапы — разделение подготовки сцены/overlay/команд, динамические объекты и анимации, коллизии, игровой адаптер. Админ-доступ, пароль, серверные проекты, публикация и объединение с master — отдельные этапы. Узкий viewport Chromium не является замером физического iPhone.
