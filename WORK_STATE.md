# Состояние работы

В `master` опубликованы **0.6.7** (`e4e7c06`, один снимок поверх 0.6.6), исправление паузы полянки (`c6a3820`) и исправление ширины интерфейса на iPhone (`846d734`). Полный CI каждого SHA прошёл; ссылки на результаты — в [описании выпуска](docs/releases/release-0.6.7.md). DEV в production закрыт, схема БД — V45. Публикация в GitHub и обновление VPS — отдельные действия.

## Последние исправления

Конфликт управления полянкой показывает центральное окно с явным «Продолжить здесь». Исправлены сохранение и освобождение аренды в фоне, запоздалое получение аренды и перепроверка собственной просроченной аренды.

Длинные имена и теги больше не расширяют общую колонку за экран; длинный тег переносится в профиле. Для `846d734` прошли 2886 тестов, проверки типов, lint, проверка мира и секретов, сборка VPS и браузерные сценарии узких/широких экранов. Данные игроков не менялись.

## Обновление документации

README и связанные инструкции сверены с опубликованной 0.6.7: функции игры, каталог v3, схема V45, уровни и цены зданий, покупки одежды, серверный сбор ягод, авторизация, DEV и обновление сервера. Исторические исследования и аудиты сохранены с датой и ссылками на действующие правила. Проверены относительные ссылки и якоря, синтаксис Bash-команд, имена npm-скриптов и отсутствие изменений приложения. Для правок только Markdown повторная сборка приложения не требуется по CONTRIBUTING.md.

Публикация в `master` ранее разрешена пользователем; документация выпускается отдельным коммитом поверх `846d734`, без переноса рабочей ветки. Деплой кода выполняется из чистого checkout закреплённого SHA через `scripts/deploy-update.sh`. Повторный сброс прогресса не нужен.
