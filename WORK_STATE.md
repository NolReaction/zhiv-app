Ветка `experiment/native-mobile` создана от `master` `493d399`. Основной выпуск остаётся 0.7.2; сервер, экономика, существующий web-клиент и пользовательские данные не менялись. Развёртывание не выполнялось. [План всех этапов и проверки телефонов](docs/development/native-mobile.md).

## Сделано

- `apps/mobile` — отдельный React/Vite + Capacitor 8.6.2 стенд, локальный bundle, проекты iOS/SPM и Android. ID `ru.zhiv.mochlik.lab`, версия 0.1.0. Это ещё не перенесённая игра.
- Плагины Geolocation, App и Preferences; системные описания доступа iOS, Privacy Manifest и Android-разрешения. Фоновые возможности не включены.
- `features/earth/native-location.ts` подключает нативный GPS к существующему Earth-контроллеру без изменения браузерной реализации. Учитываются отложенная выдача watch ID, отмена во время запроса разрешения, поздние callbacks, foreground lifecycle, отказ и приблизительный доступ Android без повторных запросов точного.
- Настройка стенда хранится в UserDefaults/SharedPreferences. Чтение начинается с OFF; записи сериализованы; OFF действует немедленно. Координаты только в RAM, без серверной отправки и истории.
- Команды `mobile:build`, `mobile:sync`, `mobile:ios`, `mobile:android`, `mobile:dev`, `test:mobile`. CI `mobile.yml` предназначен для Android debug APK/lint и iOS simulator build без подписи.

## Ограничения и следующий шаг

В первом CI-прогоне Android остановился до установки npm-зависимостей: setup-android по умолчанию пытался установить удалённый SDK-пакет `tools`. В workflow перечислены используемые platform-tools, SDK 36 и build-tools 36.0.0; push/PR одного branch разделяют concurrency group. После исправления на `1e618f8` успешно прошли Android assembleDebug/lintDebug и iOS simulator build; [CI с APK](https://github.com/NolReaction/zhiv-app/actions/runs/43409469939). Последняя правка прекращает запуск watch при неуспешной обязательной проверке служб геолокации; информационная ошибка уже работающего наблюдения не отменяет его. Для неё повторены 128 профильных тестов; актуальные проверки доступны в [draft PR №41](https://github.com/NolReaction/zhiv-app/pull/41).

Xcode/Android SDK и физические телефоны в этой среде отсутствуют: нативная компиляция, установка, реальные системные диалоги и GPS здесь не проверены. Результат CI нужно смотреть у конкретного коммита. Визуальный браузерный проход не выполнен: локальный Chromium ограничен средой, облачный браузер не видит локальный preview. Успешная web-сборка не заменяет эти проверки.

Первый ручной шаг: `npm ci && npm run mobile:sync`, затем `mobile:ios` на Mac / `mobile:android`. В стенде включить поиск, проверить получение точки, OFF, фон/возврат, полный перезапуск, отказ и приблизительную точность. Матрица — в плане.

Далее: мобильный сеанс и транспорт без ослабления cookie/CSRF защиты → общий интерфейс игры → owner-bound сохранения → нативная фоновая публикация. У текущего сервера lease принадлежит сеансу; точки старше 60 секунд не принимаются. React и нативный сервис не должны одновременно управлять публикацией. Выход, смена аккаунта, OFF и призрак обязаны останавливать её.
