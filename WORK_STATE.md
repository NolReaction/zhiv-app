## Реализовано

- При реально установленном raster скрываются плоские/объёмные здания, декоративные модели с DOM-подписями и художественная вечерняя тень. Дороги, географические подписи, GPS и игровые маркеры остаются. `satellite-visuals.ts` восстанавливает актуальные paint expressions/transitions по identity слоя. `imageryVisible` связывает фактический raster со сценой; saved buildings preference не переписывается. Off/error/отдаление/hidden/editor возвращают обычный вид; ожидание metadata ничего не скрывает. Изображения и качество не менялись.
- Новая админская вкладка «Расход API», endpoint `/api/v1/admin/api-usage`. Точные завершённые Ktor HTTP requests/5xx/429 с начала текущего процесса; счётчики согласованы под коротким lock. Без Prometheus, без сохранения пользовательских идентификаторов и без смешивания с платными API.
- MapTiler: официальная account-wide Analytics API, current billing/30/90дней, fixed URL, private token только из серверного файла и Authorization. Не берём public-key analytics, browser telemetry или предположения о списании. Факт завершённых дней отдельно от estimated_data; request/session/export раздельно, estimate-only total=null. Нет выдуманных цены/остатка. Фиксированные ошибки, bounded body/deadline, redirectNEVER, cache5min success/1min error. Нет служебного токена для live-проверки; реальные цифры появятся после настройки серверного секрета.
- Admin auth проверяется до провайдера и повторно перед ответом; клиент actor+period scoped, отменяет hidden/pending, очищает данные при потере доступа/смене периода/аккаунта. Local Next/Sites по-прежнему не симулируют админские данные. Документация настройки/панели/карты обновлена.
