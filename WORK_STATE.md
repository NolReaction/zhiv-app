# Рабочее состояние — earth

## Мультяшная Земля, полноэкранная карта и восстановление тайлов

- Работа в `earth` поверх `bad6eb9` (установка/кэш), ранее `3332540` (глобус/геопозиция). Ветка основана на `work/0.7.1`, `29c9eac`; master и production не менялись. Backend, зависимости, миграции и Tiled-данные не менялись.
- Карта занимает viewport, шапка/геопозиция/друзья плавают над ней, нижний бар сохранён. Убраны рамки вложенных окон. Safe areas, короткий landscape, прокрутка друзей, Escape, атрибуция; на 320/390 px двухстрочная атрибуция имеет зазор 8px под панелью.
- `cartoon-style.ts`: 21 слой, мягкая зелень/бирюза, тёплые улицы/здания, локальные шрифты и русские названия с fallback. Raster, sprite, glyph endpoints и 3D-экструзия исключены. `data/land-110m.json`: 106 КБ Natural Earth 110m public domain, версия/SHA/воспроизводимое преобразование в соседнем README; один локальный GeoJSON-тайл всей Земли, включая Антарктиду.
- `tile-base.ts` добавляет маленькую MVT-подложку только в копию успешно полученного OpenFreeMap planet-тайла для worker и объявляет её в копии TileJSON.vector_layers. Так точные берега загруженного участка накрывают общий силуэт, а отсутствующие тайлы не оставляют пустые клинья на глобусе. Исходные файлы в кэше не меняются; MVT независимо декодируется в тесте.
- `resource-cache.ts`: отдельный Cache Storage 100 МиБ/512 записей и защищённый SDK сохранены. Добавлены дедлайны 3с для дисковых операций/очереди записи, честный session fallback, RAM LRU 32 МиБ/128 записей, чтение индекса пакетами16. Сетевой повтор освобождает слот; закрыта гонка синхронной отмены из progress listener и учёт ошибок отменённого запроса. Сохранение либо явный fallback предшествуют готовности.
- `tile-recovery.ts`: до двух фоновых проходов на сбой, группировка по source/canonical tile, контроль отсутствия прогресса 20с, пауза при движении/hidden/offline, новый бюджет по действию/online. `source-recovery.ts`: точечные refreshTiles либо пересоздание только зависшего источника и его слоёв; исправляет случай MapLibre6.15, когда общий refresh оставляет loading/reloadPromise. Карта, WebGL, камера, локальная основа и GPS-слой сохраняются. Внутренний кэш MapLibre96 тайлов/источник, ограниченный LOD горизонта, родительские тайлы при zoom.
- Первый показ по-прежнему после idle/loaded/tiles/pending0/failed0, с непрозрачной загрузкой и проверенным SDK Blob worker. F5 восстанавливает раздел для того же владельца; GPS включается только явным действием, хранится в памяти, не передаётся друзьям/серверу. Источники видят выбранные тайлы/IP. Кэш изученных областей не равен всей Земле на всех масштабах и не заменяет app shell/сессию. Persistent storage решает браузер; очистка данных сайта удаляет карту.
- Проверено на текущем этапе: 185/185 целевых Earth/navigation/onboarding/PWA/dev/deploy/gesture тестов; полный TypeScript и ESLint; architecture:check (835 модулей), world:check. Обе production-сборки Next/VPS и Sites прошли; secret scan после индексации новых файлов: 0 находок. Полный npm test/API/Compose не запускались, это этап разработки без деплоя.
- Chromium/WebGL2: холодный старт; 12 быстрых переходов к полюсам/линии дат/городам с окончанием всех тайлов; два HTTP503 одного тайла автоматически исправились; общий сбой источника заменил только улицы. F5 и заблокированный провайдер дали 0 запросов SDK/карты, включая повторно открытые сохранённые улицы. Canvas точно соответствует 320×568, 390×844, 844×390, 1280×900, document overflow нет. Друзья открываются/прокручиваются/Escape. Нет запросов шрифтов/спрайтов/растра и неожиданных ошибок JavaScript. Браузер/сервер остановлены. Промежуточный Next HMR после неудачной компиляции терял CSS; полный перезапуск устранил это, финальная чистая загрузка проверена.
- Ограничения: реальный Safari/iPhone, GPS/батарея ещё требуют устройства. Игра не изменялась; прежний программный Chromium тормозил лесную сцену, полный цикл полянки на этом этапе не проверялся. Подробности: `docs/development/earth-map.md`. Дальше — отдельное согласие на обмен временной геопозицией, серверный доступ/TTL/отзыв и маркеры друзей; native background location отдельным этапом.
