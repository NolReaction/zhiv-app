# 0.7.2-fishing: большой холст и посадка лодки

Ветка `0.7.2-fishing`, база этапа `9b583d5`. Разработка и Git разрешены; master/deploy вне задачи. `releaseValidated=false`.

## Текущий завершённый этап — студия, 4 ноября 2026

- `/prototype/boat-garage` по умолчанию открывает большой холст «Сборка» без рамки телефона и игрового меню. «Устройства» сохраняет прежний PWA-макет. «На весь экран» скрывает панели, Esc возвращает. Есть зум к курсору, ±/100%/«Вписать»/«К детали», пробел или средняя кнопка + drag, инструмент «Холст».
- Рабочие зум/панорамирование не изменяют scene JSON, камеры устройств, dirty/history. Инструмент камеры в предпросмотре устройств сохраняет прежний смысл. Undo/redo и RU-физические клавиши сохранены.
- Добавлены совместимые необязательные scaleX/scaleY/flipX/flipY/skewX. Матрицы/перепривязка/перенос pivot сохраняют полный мировой вид при неравномерных и отражённых родителях. Инспектор умеет раздельную форму, отражение, точное совмещение контакта без родительства, подгонку по двум точкам. Крепления/маркеры не искажаются.
- Причина старой посадки — фронтальная широкая U-стойка против бокового корпуса и неверная опора на прозрачный край PNG. Создана отдельная боковая винтовая опора, прежняя не удалена. Мастера нового корпуса/мотора/стойки находятся в art/world/boat-garage; WebP и полный альфа-кадр соответствуют мастерам.
- `garage-scene-example.json` — отдельный отменяемый «Пример посадки», не автозамена пользовательской сцены/черновика/диска. Обе подошвы на y700, верхние контакты под днищем с перекрытием5px, высоты независимы. Мотор прикреплён к транцу за корпусом. Новые изображения доступны в библиотеке без загрузки всего примера.
- Пустой шаблон и art/world/boat-garage/scene.json не перезаписывались. Галерея документации обновлена, `modular-parts.json` фиксирует ракурс/контакты/ограничение перекрытий. Для обхватывающих зажимов нужны front/back-слои либо маска; одна картинка/zIndex и анкеры не исправляют различный 3D-ракурс.
- Проверки:53/53целевых garage-теста, включая сохранность старого JSON, полные affine-преобразования, независимые контакты/две точки, зум и реальную посадку/альфу мастеров. TypeScript, architecture1239модулей, полный lint и diffcheck. Sites и Next/VPS успешно собраны последовательно; новый прогон Next использовал чистый Turbopack cache (старый сохранён внутри игнорируемого .next/cache/).
- Браузерный QA реального React-редактора через изолированный Vite-стенд: большой1920×1080холст, пример→undo/redo, точка под курсором при зуме, панорамирование без dirty, fullscreen→Esc, высота с неподвижной подошвой, отражение→undo, точный контакт через UI без перепривязки, неизменные камеры;390×844/820×1180/844×390 без горизонтального переполнения/JS-ошибок. Файловый endpoint в браузерном QA заменён тестовым обработчиком; настоящий Node API покрыт HTTP-тестами. Физический iPhone/Safari/PWA не проверен.
