Первая поляна — `e48c79c`, Terrain — `f596af2`. 10 октября пользователь подтвердил первый запуск и прислал обновлённую землю с мягкими тропами, без красных ошибок Console. Ручная сцена пользователя пока не опубликована в Git. PWA/API, master, Phaser и параллельное обучение новичка не менялись.

По разрешению пользователя подготовлен следующий этап по мотивам `v12-с`: **Zhiv/Create or Open Forest Layout** создаёт отдельную `Assets/_Project/Scenes/ForestLayout.unity`. Clearing и её ассеты не заменяются. Если ForestLayout существует, команда только открывает её. Генерация однократная в Editor, без автоматического Bake/пересоздания при import/Play. Настроенный URP переиспользуется без сброса качества.

- Terrain 48×56 м, 4 прежних процедурных покрытия, разрешения высот/покраски 257²/512². Семь мест (дом, мастерская, руины, лагерь, рынок, мыс, берег), шесть связанных троп, основания и чаша озера.
- Группы редактируемых prefab-деревьев (цель 175), кусты/камни, простые заготовки мест. Расстановка учитывает поляны, тропы и кроны. Вода подогнана к исходному контуру рельефа, имеет сохранённый mesh и замкнутый obstacle volume.
- ForestLandmark хранит ID/название и дочерний Arrival. Названия видны в Scene; точки используются проверкой проходов. Перенос места не меняет GroundRecipe автоматически.
- Реальный uGUI Canvas с шапкой, кнопками Дом/Мастерская/Обзор, окном пробной работы, справкой, днём/вечером и переходом камеры к воде. UI сохраняется в сцене с UnityEvent, учитывает safe area; видимые панели блокируют ввод карты. Старая Clearing сохраняет OnGUI.
- Добавлен `com.unity.ugui:2.0.0`, ссылки asmdef `UnityEngine.UI` сверены с официальной веткой 6000.3. Pointer-only input module использует mouse/touch без отсутствующих Horizontal/Submit axes; клавиатурная/контроллерная навигация UI не реализована.
- Камера ограничивается всем viewport на опорной плоскости, адаптирует максимально допустимое отдаление к пропорциям. Отступ новой сцены покрывает текущий мягкий рельеф.
- `Zhiv/Validate Forest Layout`: сохранённые ассеты/системы/UI, все центры нарисованных троп через SegmentClear, маршруты до семи Arrival, запрет воды/выхода за мир. `Zhiv/Build Forest Layout Web` собирает новую сцену в `Builds/ForestWeb`; прежняя Web-команда собирает Clearing.

## Следующий шаг и ограничения

Пользователь сохраняет работу, получает ветку, выполняет Create or Open Forest Layout, смотрит Game 9:16 и Play, затем запускает Validate Forest Layout с остановленным Play. Далее общий кадр «Обзор», дом/тропа крупнее и Console при ошибках. Инструкция: [apps/unity/FOREST_LAYOUT.md](apps/unity/FOREST_LAYOUT.md), кисти и Bake: [GROUND.md](apps/unity/GROUND.md).

После генерации нужно публиковать `.unity`, `ForestGenerated/` и связанные `.meta` вместе, чтобы продолжать работу с реальной расстановкой. Ассеты создаёт Unity Editor пользователя; в этом этапе публикуются генераторы/код/инструкции.

Bake покраски заменяет ручные мазки, Bake рельефа — ручные высоты; сначала Snapshot. Деревья, вода, коллайдер озера и здания не следуют последующей скульптуре автоматически. UI рассчитан прежде всего на телефонный портрет; очень низкое окно может потребовать компактной компоновки. Лес, свет и текстуры — заготовки; предстоит художественная доводка одного участка и модели Blender. Производительность длинных маршрутов/леса на телефоне не измерена. Навигация по одному Terrain без мостов, лестниц и дыр. Аккаунты, экономика, сохранение игрока и TypeScript-аудиодвижок в Unity не подключены.
