# Стабильные слоты, двойная мастерская и реальный улов

Ветка `0.6.9-economy`, исходный HEAD `7ba69d21183f92701e118545523f702185bdff7d`. Пользователь разрешил коммит и публикацию; CI не ждать. `master`, SQL/БД и деплой не меняются.

## Сделано

- Обычные производственные слоты сохраняют 118 px во всех состояниях, включая уголь, длинное название и пятисекундное подтверждение отмены. Рисунок/название/таймер/действие/прогресс имеют фиксированные строки. Полное название доступно вспомогательным технологиям; блокирующие сообщения и переход в кладовую остаются читаемыми. Отмена, возврат, сбор ягод и цены слотов не менялись.
- Плашка мастерской показывает отдельные секции «Верстак»/«Печь», когда обе очереди заняты. У каждой свой рисунок, таймер, прогресс, число остальных заданий и переход к оборудованию. Одна очередь сохраняет 44 px; двойная занимает 88 px. Приоритет стройки сохранён. Привязки и столкновения учитывают высоту и верхний HUD, обновляются при смене размера даже без анимации/движения персонажей.
- У Плёски пять компактных строк шансов; для изменившихся классов видны прежний/новый проценты. Убраны повторные описания и технические предупреждения про удочку. Реальные покупки, совместимость и нулевые шансы сохранены.
- Публичное задание раскрывает сохранённые виды только по серверному `now >= finishesAt`. Незавершённый улов остаётся скрытым. Необязательный `fishing.catchRevealed` отличает реальный речной улов от прежнего маскированного снимка; Kotlin `EncodeDefault(NEVER)` сохраняет прежнюю форму приватного JSON. Проекция не выдаёт награду и не открывает коллекцию. Все реальные API проекции получают захваченное серверное время.
- Готовая карточка рыбалки показывает рисунок, название, редкость и количество каждого вида, включая дополнительные находки; строка про крючок убрана. До раскрытия показан только общий «Улов». На локальном дедлайне выполняется один защищённый read-only refresh, без получения или цикла запросов против старого сервера. Сетка подстраивается под ширину самой панели.
- Подтверждённое уведомление использует отдельные `InventoryGain.displayItems`; экономические `items` остаются классами. Виды берутся из раскрытой сохранённой награды либо подтверждённого прироста коллекции в пределах фактического прироста класса. Неизвестный остаток остаётся классом, насыщенный счётчик и повторы не создают фиктивных поимок.
- Рисунок класса запаса выбирается из действительно пойманных видов той же редкости. Название, количество и продажа остаются классовыми; рисунок не утверждает видовой состав холодильника. Купленная рыба не открывает коллекцию. Все двенадцать рисунков используют прежний общий мастер SVG/Canvas.
- Сцена принимает раскрытый вид того же задания без повторного заброса: меняются лишь виды существующих окон/рыбы в руках/корзины. Число окон, сроки, фазы, уборка и ноги сохраняются; позднее раскрытие не подставляет следующий вид, отмена возвращает героя без улова.
- Справка, обучение, `/branch`, тематические документы и путеводитель обновлены. Каталоги, веса/шансы, награды, цены, рецепты, заказы, миграции, изображения и Tiled не менялись.
