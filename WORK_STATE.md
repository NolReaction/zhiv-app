## Сделано

- Подготовка owner/VAPID/service worker перенесена до нажатия. `PushManager.subscribe()` вызывается прямо из жеста, без отдельного requestPermission и сетевого ожидания перед запросом разрешения. Подготовка только читает; активация service worker и браузерные операции имеют ограниченное ожидание.
- Разрешение, созданная браузерная подписка и подтверждённая регистрация API разделены. Этапы и ошибки видны у кнопки; после разрешения без регистрации предлагается «Завершить подключение». При запрете или неподдерживаемом режиме показывается инструкция, сохранённую подписку можно отключить.
- Статус сверяется после focus/pageshow/возврата из фона/online. Форма сохраняет несохранённый выбор; параллельная сверка приостановлена на время сохранения предпочтений. Панель пересоздаётся для другого владельца, запоздалые операции не обновляют новый профиль.
- Перед серверной привязкой повторно проверяются владелец, ключ и актуальный endpoint. Ошибка сохранения оставляет native-подписку для явной повторной попытки, не удаляя общую подписку другой вкладки. Поздний subscribe после таймаута не привязывает аккаунт.
- Подсказки iPhone/iPad ведут в Safari → «Поделиться» → экран «Домой» → запуск с иконки. Яндекс проверяется по API; для запрета добавлен путь к разрешениям Android/desktop. Apple/FCM уже разрешены на сервере; неизвестные домены в allowlist не добавлялись.
- Обновлена [документация Web Push](docs/operations/web-push.md). Точную исходную ошибку устройства без её текста подтвердить нельзя; серверный аудит не нашёл ошибки сохранения Apple-подписок. Разрешение само по себе не доказывает успешную регистрацию.

## Следующий шаг

Установить новый коммит через `scripts/deploy-update.sh`. Ключи повторно создавать не нужно. На iPhone открыть игру с экрана «Домой», затем профиль → шестерёнка → уведомления → подключить/завершить подключение. При сбое теперь видна ошибка рядом с кнопкой. Для проверки доставки выбрать событие через 5+ минут после закрытия игры и отключить тихие часы; видимая игра и ещё 2 минуты активности подавляют push.
