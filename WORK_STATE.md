# Пароход из кода · 0.7.2

Дата: 25.10.2026. Ветка `work/0.7.2-ship`. База этого этапа: `68adac83b7f54efa2441b79181bde7feebb73501` с первым концептом. Пользователь попросил нарисовать пароход кодом и публиковать изменения в этой ветке для просмотра.

## Готово

- Процедурный Canvas 2D-пароход: обшивка корпуса, палуба, зелёная изогнутая крыша, закрытая дверь каюты, окна, медная труба, кран, бочка, тюк, канаты, кранцы и тёплый фонарь. Сам корабль не использует PNG и DOM.
- Отдельные геометрические калитка и трап: створка поворачивается вокруг неподвижной вертикальной оси, трап выдвигается; есть 0–3 грузовых ящика, начальная палуба пустая. Текстура повторяемая, без шума между кадрами.
- DEV-стенд `/prototype/trade-ship`, ссылка из DEV → «Приложение и тесты». Крупный вид / примерка в южной бухте, день / ночь, пауза, ползунки и экспорт прозрачного PNG 1600 × 1000. Учтены hidden tab, reduced motion, DPR, размонтирование и поздний callback экспорта. Ручные настройки доступны на паузе.
- Страница закрыта вне development. Экономика, игровые данные, Tiled и её экспорт не менялись. Автоматический заголовок служебного блока Next в AGENTS сохранён как сгенерировал `next dev`.
- [Устройство и просмотр](docs/game/trade-ship-prototype.md), [исходный концепт](docs/game/trade-ship-concept.md).
