# 0.7.1v2 — геопозиция, боты и возврат на глобус

2026-10-20. Продолжение от опубликованного `69ec5b55e6a6e8d6fe49bbe43bc23bd1bdb02a16` в `0.7.1v2`. Пользователь ранее разрешил коммиты и push этой ветки; master и сервер не меняются.

## Изменения текущего этапа

- Ошибка WebGL/загрузки больше не оставляет отменённый экземпляр при Люди → Карта. Возврат и foreground context restore начинают одну свежую попытку с прежней камерой/кэшем; поздний style.load не оживляет аварийный экземпляр. На постоянно открытом экране нет бесконечных повторов; начальный показ по-прежнему ждёт готовых тайлов и первого кадра.
- GPS: один high-accuracy повтор после unavailable/timeout, запрет разрешения не повторяется. При временной ошибке старая частная точка сохраняет timestamp, явно помечена как последняя и не публикуется как новая. Отзыв разрешения/выход очищает её. localhost уже разрешён secure-context политикой; реальную службу ОС/браузера в контейнере проверить нельзя.
- DEV «Поставить в центр карты»/«Поставить рядом со мной» атомарно включает точный показ выбранного синтетического бота только владельцу и фокусирует карту. Ручные координаты/стрелки сохраняют OFF/призрак; cadence и command receipts сохранены. Реальный GPS владельца не меняется.
- В «Людях» две горизонтальные кнопки «Статус»/«Геопозиция» со значками, подсветкой и текстом подтверждённого состояния. Общие действия приватности с картой, пауза/призрак/отзыв сохранены. Обучение и документация обновлены без смены ID шагов и прогресса.
- Обзорные художественные горные пояса и спокойнее зерно суши. Один статичный source/fill, fade zoom 3–4, без DEM/сети/изменения высоты маркеров. Геометрия заранее подготовлена из art/earth/relief/ranges.json через scripts/prepare-earth-relief.mjs; браузер только читает JSON (~23 КБ gzip), без береговых вычислений.
- DEV-диагностика дополнена только whitelist-состоянием GPS, наличием точки и secure/API flags. Координаты, URL, ID, raw errors и автоматическая отправка исключены.
