# Engine — самостоятельное приложение и ядро

Ветка `engine`, исходный коммит этапа `807c3ac7`. Работа выполняется в отдельной копии `zhiv-engine`; `master` и деплой не входят в этот этап.

## Текущий этап

- Код выделен в три владельца: `packages/engine/src` — библиотека Canvas 2D; `apps/engine/src/editor` — документ, контроллер, история, сохранение в браузере и React-интерфейс; `apps/engine/examples/forest` — конкретная карта, рисунки и настройки лесного примера.
- Добавлены workspaces `@zhiv/engine` и `@zhiv/engine-lab` версии 0.1.0, оба private. Команды `dev:engine` (localhost:5174), `typecheck:engine`, `test:engine`, `build:engine` и `preview:engine` (localhost:4174). Результаты сборки — `packages/engine/dist` и `apps/engine/dist`; npm registry release не выполняется.
- Публичный контракт — `createScenePainter(makeCanvas, preset, onAssetsChanged?, loadImage?)`, текущая сцена и размеры передаются через `SceneRenderOptions`. Ядро получает каталог предметов и землю из preset, не импортирует React/Next/API/игровой мир. Лесной адаптер сохраняет прежнее поведение редактора.
- Самостоятельная точка входа запускает редактор без основного приложения. `/engine` и `/prototype/procedural-forest` остаются тонкими хостами общего компонента с параметрами ссылки назад и примером PNG. Интерфейс использует собственные изолированные стили.
- Формат v5 и миграция JSON v1–v4, исходные PNG, импорт/экспорт и браузерное сохранение сохраняются. На другом origin прежний localStorage не доступен; перенос в standalone/preview выполняется через JSON. Storage/key/Canvas можно передать контроллеру явно; автоматической миграции между origin нет.
- Обновлены [запуск и перенос сохранений](docs/engine/README.md), [архитектура/API](docs/engine/architecture.md), руководство редактора и ссылки в документации. Прежние замеры и результаты 192 тестов помечены как относящиеся к базе до отделения.

## Проверки

- `typecheck:engine`, общий typecheck, полный ESLint и architecture:check (620 модулей) прошли; тесты архитектурных правил — 17/17.
- Общий `npm test` — 3772/3772, включая 201 engine-сценарий и Sites build. После финальной правки расширений импортов повторены `test:engine` — 201/201, оба typecheck и ESLint; поведение не менялось.
- Финальные `build:engine`, Sites `npm run build` и Next/VPS `build:vps` прошли. Исходные относительные `.ts`-импорты совместимы с Turbopack; `rewriteRelativeImportExtensions` преобразует их в `.js` при сборке библиотеки.
- Собранное ядро скопировано в отдельный временный проект без исходников: обычный Node-потребитель работал без DOM, Vite, React, игры и редактора. Его декларации проверены TypeScript 5.9.3 с NodeNext, strict и `skipLibCheck: false`, без `allowImportingTsExtensions`.
- Настоящий standalone в браузере: загрузка/размещение/дублирование PNG дома, Ctrl+D и Undo/Redo в русской раскладке, ночь и местная лампа с отменой, JSON v5 с точными исходными байтами PNG, экспорт/импорт/reload. Экраны 1440×1000, 390×844 и 320×844 — без переполнения, ошибок и отказов ресурсов.
- Собранный редактор проверен через Vite preview на 4174: собственные compiled chunks и PNG загружаются, запросов к игре, API и PWA нет. `world:check` и `audio:check` прошли: 47 сигналов, 13 профилей, 102 аудиоассета. Документация проверена независимо; ссылки и `git diff --check` проходят.

## Следующий шаг и границы

Отделение подготовлено и проверено для ветки `engine`. Основная Tiled-игра пока не использует новое ядро; персонажи, навигация, экономика и аккаунт продолжают работать через игровые модули. Вход, пароль, админка, серверное сохранение и интеграция с `master` — следующий отдельный этап. Локальный standalone build не является согласованной публичной публикацией. Браузерные проверки не подтверждают производительность физического телефона; прежние замеры до отделения остаются историческими.
