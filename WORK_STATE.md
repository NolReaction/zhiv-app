- DEV-панель на главном экране и карте загружается по кнопке. Отклонённый импорт и ошибка отрисовки остаются внутри DEV, без автоматического reload. Уже загруженная панель сохраняет состояние при временном скрытии.
- Next DEV-запуск проверяет pinned Next/React/ReactDOM и использует webpack. Аргументы, сигналы и exit status передаются; production bundler сохранён. Кэши и профиль автоматически не удаляются.
- SW учитывает запреты кэширования при записи, чтении старых записей и staging shell; Next static сохраняет только при immutable. Production offline shell и версионированные картинки остаются.
- HTTP smoke использует тот же запуск и проверяет реальные входные JS-чанки и их заголовки. Инструкция запуска/восстановления обновлена.
