- Engine и студия освещения совмещены. Версия приложения 0.7.0 сохранена вместе с workspaces/зависимостями engine.
- Конфликты economy согласованы с уведомлениями, admin-аналитикой, справкой, CI и процедурами сброса. Наборы обязательных PostgreSQL-проверок объединены.
- SQL master V1–V52 сохранены побайтно; V1–V49 находятся в history/. Экономические V50–V52 перенесены без изменения SQL в V53–V55. B49 сохранена. V56 корректирует занятость Мохлика для уведомлений при независимой работе шахтёра.
