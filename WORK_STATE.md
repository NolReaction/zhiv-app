В `6068cac` добавлены 1–3 одновременных заказа на пяти производствах (дом 2/4 для покупок), витрина жемчуга/золота без транзакций, DEV с точными шансами рыбалки и требование легендарных удочки и крючка для легендарной рыбы. Шахта остаётся одной вылазкой, без автономной добычи.

Все восемь зданий 5 — 658–670 / 366–379 / 276–288 дней. Это модель без ускорений, рынка и жемчуга достижений; текущая правка отображения её результаты не меняет.
