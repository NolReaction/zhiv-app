## Подтверждено / сделано

- Этот экран означает, что профиль, активность, мир, хозяйство, прогресс и код сцены уже готовы; ждём рисунки. Прежнее предположение про IP-квоты API не объясняет показанное состояние. Конкретный сетевой источник сбоя без трассировки VPN не доказан; Selectel не объявляется причиной.
- Текущий начальный набор сцены — около 11.87 MiB, включая фон 3.69 MiB. Основные картинки обрывались через 15 секунд; сцена через 25. Теперь картинки получают 60 секунд, terrarium/карта 90, кодовые модули сохраняют25. Таймауты правильно классифицируются; состояние готовности не подменяется.
- Крупный предварительный звук (песня, ветер, лес, река) начинается после готовности первого экрана, чтобы не конкурировать с рисунками. Короткая подпись логотипа сохраняет прежний ограниченный бюджет.
- Caddy write увеличен30s→2m: это срок полного ответа, он не должен обрывать допустимую передачу изображения раньше клиента. Пределы чтения заголовков/тела сохранены.
- Исправлен PWA-кэш: версионные PNG, независимая запись кэша и ограничение зависшего общего запроса. Раньше cache.put задерживал доставку ответа и мог удерживать одну вечную попытку для всех повторов.
