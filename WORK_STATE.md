# 0.7.1v2 — подготовка выпуска

2026-10-20. Работа начата от `642073f11bcf1e640dd128e092fff87bb2de8a0b` — объединения work/0.7.1 и earth. На старте ветка включала master и опережала его на 147 коммитов. Master, сервер и данные пользователей не менялись. **20 октября в 16:22 МСК пользователь явно разрешил публикацию подготовленных изменений в 0.7.1v2.**

## Изменения

- Призрак и обычная остановка GPS сохраняют последнюю опубликованную точку максимум на 24 часа от обновления, в пределах исходного срока доступа и прежнего allowlist. Время точки не меняется, публичного статуса призрака нет. OFF удаляет точку и разрешения. Поздние upload/stop, повторные команды, удаление дружбы и отзыв исходной сессии не восстанавливают доступ.
- Новая V66 сохраняет исходную сессию последней точки; V65 и прежние миграции не менялись. Обновлены baseline/upgrade/reset-контракты: свежая БД B49 + V50–V66, 18 записей. Частный маркер при призраке остаётся в памяти аккаунта, GPS и поздние callbacks остановлены.
- В «Людях» и Earth → «Близкие» появились кнопки игрового профиля и посещения полянки через существующие контроллеры. Цель проверяется по текущему владельцу, circle и publicId. «Моя полянка» очищает прошлый выбор друга.
- Исправлена инициализация Hikari: внутренний SET больше не оставляет новую pooled connection внутри транзакции. Добавлена регрессия роста пула и сохранения SQL timeout; исправлены устаревшие Kotlin fixtures.
- Исправлен выбор еды до личного приготовления обязательного рецепта; подаренные готовые порции остаются доступны. Веб-тесты рынка учитывают ручной сбор выручки и актуальные вкладки/каталог.
- Устаревшие fixtures снастей, вечерних посетителей Плёски, координат дров и ручной выручки актуализированы с сохранением security/геометрических assertions. Scoped UI harness поддерживает новые market/audio hooks; навигационные проверки больше не падают из-за отсутствующего React dispatcher. Production smoke учитывает приветственное письмо и проверяет, что чтение не получает подарок.
- PWA теперь кеширует версионированные PNG/WebP новых зданий из `/world/buildings/<building>/`; реальные Tiled assets проверяются offline-сценарием. Лимит web CI увеличен с 30 до 60 минут без отключения тестов.

## Перед выпуском

1. После разрешённой пользователем публикации получить зелёный CI, включая API/PostgreSQL и production Compose. CLI git не имеет write-авторизации; публикация выполняется через подключённый GitHub с проверкой совпадения деревьев. SHA коммитов может отличаться из-за метаданных GitHub.
2. Репетировать master → V66 на изолированной копии серверной БД с проверкой сохранения аккаунтов, кошельков, незавершённых работ, писем, подарков и выручки. БД с прежней отдельной Earth V62 несовместима с обычным обновлением; нужен отдельный согласованный перенос истории, без автоматического изменения flyway_schema_history.
3. Добавить геолокацию/призрака и профили в production smoke через Caddy; проверить двумя тестовыми аккаунтами.
4. Принять iPhone/Android PWA: GPS/фон/F5/offline/отзыв доступа, обновление старой установленной версии, новые здания и переходы Земля ↔ лес с погодой и 3D. Актуализировать инструкцию выпуска 0.7.1 перед деплоем.
