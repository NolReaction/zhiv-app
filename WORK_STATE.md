# Earth: свет, погода и начальная геопозиция, 2026-10-18

Текущий этап продолжает геошеринг `481fea5` / передачу `0c512fd` в ветке `earth`. Master и живой сервер не менялись. Скриншоты пользователя 19:49–19:58 просмотрены; задача этого этапа — визуальные исправления карты и приватный начальный GPS-маркер.

## Что изменено

- Вечернее затемнение: один географический custom GPU-слой вместо перекрывающихся GeoJSON-полигонов. Публичный projection prelude MapLibre сохраняет слой при переходе globe → Mercator и дальнейшем приближении; alpha не зависит от zoom, максимум 0,36 вместо прежних ~0,74. Земля и улицы светлее, подписи остаются читаемыми. Режимы День / Вечер / Авто сохранены.
- Звёзды перерисовываются по готовому кадру SDK при изменении камеры, без исчезновения до moveend. Undefined unproject над горизонтом обработан. Canvas ограничен 2 Mi pixels / 8 MiB RGBA.
- При уже выданном browser permission `granted` своя позиция появляется автоматически, приватно и без перемещения камеры. Состояние sharing сначала должно загрузиться; GHOST / pendingGhost подавляют автостарт. При prompt/denied/неизвестном Permissions API остаётся явная кнопка, без автоматического запроса разрешения. Ручной поиск работает и в GHOST. F5 не возобновляет публикацию близким; приватный granted lookup допустим. Координаты не записываются на диск.
- Погода: единый мягкий слой облачности с непрерывным world-noise полем, ограниченные дождь / снег вместо сетки огромных иконок. Новая карта по умолчанию включает погоду, явное выключение в текущей сессии сохраняется. Clear / unknown не рисуют выдуманные осадки. Источник MET Norway, TTL/stale и coarse viewport query не менялись.
- Погодные буферы ограничены: canvas ≤1 Mi pixels (~4 MiB RGBA), максимум четыре 256×256 RGBA cloud textures (~1 MiB); это размеры удерживаемых backing-буферов; временная генерация и копии браузера/GPU в число не входят. До 56 дождевых / 42 снежных частиц, общий clock сцены, static reduced motion и остановка вне видимой карты. Native projection guards сохраняют наземный footprint при наклоне, не закрашивая небо/обратную сторону глобуса.
- Декоративные облака глобуса: пять мягких оригинальных процедурных облачных масс. Загрузка тайлов: прозрачная общая дымка вместо плотных плашек, не более двух разнесённых значков; маски уже загруженной земли/проверенного океана сохранены.
- Лицензии OSM/OpenMapTiles постоянно видны внизу под «Близкие»; кнопки и панели подняты для отступа на мобильных/desktop.
- Эйфелева башня: правильные пропорции, четыре изогнутые опоры, арки, решётка и три площадки. Два уровня детализации используют один GPU-буфер; весь каталог 361 440 байт. Геоякоря, ограничения размера и скрытие при отдалении/обратной стороне сохранены. Остальные здания в этом этапе не заменены внешними моделями.
- Подготовлен `docs/development/earth-models.md`: контракт будущих glTF 2.0 / GLB моделей, оси, масштаб, бюджеты и необходимый адаптер. Текущий runtime GLB пока не загружает; импорт моделей — отдельный следующий этап.

## Приватность геошеринга

Контракт предыдущего этапа сохранён: OFF по умолчанию, доступ только выбранным DIRECT-друзьям, отдельное явное согласие на публикацию, session-bound epoch, GHOST с отзывом доступа, latest point без истории, TTL 120 секунд. Ни начальный приватный GPS, ни F5, ни возврат на карту не создают новую publication epoch. Память камеры при переходах и ограниченный resource cache продолжают работать.

Подробности API, согласия и аналогов: `docs/development/earth-sharing.md`. Общая карта: `docs/development/earth-map.md`, обзор: `features/earth/README.md`.
