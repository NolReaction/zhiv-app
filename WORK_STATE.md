## Сделано в этом проходе

- Beta-новости: до восстановления памяти счётчик не объявляет старые записи новыми. Возврат из фона, `pageshow` и фокус сверяют прочитанные ID даже при ограничении частоты проверки ленты; временно неудачная запись в localStorage повторяется. Состояние разных аккаунтов изолировано.
- Основное обучение и знакомство с картой: явное сворачивание/закрытие сохраняется в отдельном ключе аккаунта. Перезаход не открывает закрытый курс; ручное продолжение сохраняет шаг и выбранную учебную работу. Исправлено наблюдение устаревшего снимка после восстановления в StrictMode. Пауза разделов уже была постоянной.
- Старые завершения/пропуски и v1-сохранения карты сохраняются. У игрока без локального прогресса появится добровольное приглашение. Обучение не сбрасывает игру и не совершает экономические команды без нажатия. Память локальна для браузера; прежнюю RAM-only паузу восстановить задним числом нельзя.
- На заставке убрана кратковременная кнопка звука. Автоматический сигнал сохраняет mute/громкости и правила autoplay; после ухода/скрытия заставки просроченный сигнал не воспроизводится. Реальное размонтирование закрывает ожидание, StrictMode не дублирует звук.
- В `smoke-player.mjs` актуализированы строгие ожидания стартового кошелька, припасов и кладовой; 23 HTTP-сценария local memory API прошли после остановки браузерного DEV, scoped ESLint также проходит.
- Исправлены два падения полного web CI на базе `bd232c6`: проверки еды свободного строителя и полной кладовой ещё ожидали прежние UI/вместимость. Добавлена проверка доступной еды из запасов.
- JDBC-набор учебной экономики включён в обязательный CI guard. V1–V45 неизменны, V46–V49 сохраняют старую экономику; reset fixture соответствует V49 и 69 таблицам.
- Версии web/API — 0.6.8. README, индексы, документация запуска/звука/обучения/новостей и релизная инструкция обновлены. В `public/updates.json` готов патчноут «Лес зазвучал, а первые шаги стали проще»; все прежние новости сохранены.

Полный повтор файла с `--max-old-space-size=4096`: 112/112 passed; все 3404 уникальные веб-проверки выполнены без падений утверждений. Сборка VPS успешно завершена после тестов, при остановленном DEV.

Прерванный первоначальный DEV оставил неполный webpack chunk; чистая пересборка DEV устранила артефакт без изменения кода.
