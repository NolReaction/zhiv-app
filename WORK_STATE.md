# Рабочее состояние - work/0.7.1

## Текущая задача

Продолжаем от c1a08c1: исправить существующий CI, перенести сетевой индикатор в центр, упорядочить студию света, строительство и журнал заказов. Пользователь разрешил новый коммит в `work/0.7.1`; новый CI не ожидаем. Деплой не выполняем.

- CI №512 (38826653212): Web, engine и secret scan прошли; Ktor скомпилировался, но шесть тестов упали. Три SQL-ошибки вызваны несовместимым ограничением контекста общего сбора ягод; ещё три - устаревшими фикстурами отмены производства и публичного улова.
- V57 разрешает строго ограниченный публичный контекст корзины только двум garden action: UUIDv4 корзины, 1–3 UUID заданий, столько же recipeIds, закрытый список полей и прежний предел 512 байт. B49/V1–V56 не изменены. Allowlist мигратора, schema/reset guards, тесты и текущая документация согласованы; reset не запускался. Добавлен интеграционный тест обоих путей Flyway и отказа на повреждённый контекст.
- Сетевой значок полупрозрачный, мягко мерцает в центре экрана. Native Popover API держит его поверх преобразованных/обрезанных окон, DOM остаётся в активной модальной области фокуса. Общий aria-live не позволяет Radix скрыть кнопку от скринридера. Без Popover API отображается пассивный body-индикатор без внешних фокусируемых элементов; автоматическое восстановление связи сохраняется. Reduced motion отключает мерцание.
- Студия: компактные группы инструментов и правый инспектор, отдельные вкладки на телефоне, сворачивание. Поиск по словам/синонимам, нескольким словам в любом порядке и е/ё; Ctrl/Cmd+K в RU/EN. Переходы к полям раскрывают нужные разделы и фокусируют ввод; поиск создания использует прежнее размещение. Store, карта, autosave и HMR не менялись.
- Стройка: отдельные строки условий с рисунком, названием и уровнями. Использованы существующие изображения зданий; «Как продолжить?» находится после условий. Карточки будущих возможностей компактнее, полные требования выбранной возможности вынесены под карусель с явным заголовком. Свайп, стрелки и Home/End сохранены.
- Журнал оформлен как лесная почта: письма, марки наград, портреты, штамп готовности, поля/переплёт, компактные действия. Правила замен свёрнуты. Экономика, выбранные виды рыб, подтверждения и обучение сохранены.

## Проверки

Стройка и журнал отрисованы при 320/390/900 px; студия при 390/900/1920 px. Карусель, фильтры, подтверждение замены и переход поиска к настоящему полю проверяются в браузере. Общий npm test: сборка Sites прошла; 4 898 из 4 900 тестов прошли, без пропусков. Один неизменённый файл сцены упёрся в локальный V8 heap около 2 ГБ: повтор с NODE_OPTIONS=--max-old-space-size=4096 прошёл, 145/145. Полный набор целиком после этого не повторялся. Дополнительно актуализированы прежние текстовые ожидания отдельных условий шахты и восстановления; world-object-menu 37/37.
