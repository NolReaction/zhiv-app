# Сайт приложения и персональная установка PWA

Ветка `work/site-pwa`, исходный опубликованный коммит `5c43ad4`, draft PR https://github.com/NolReaction/zhiv-app/pull/25 в `master` (`9d5e4e7`). Пользователь попросил продолжить визуальное улучшение, адаптивные инструкции, убрать плохой ролик; коммиты и публикация ветки разрешены. Серверный деплой — отдельный этап.

## Сделано

- Новая композиция `/site`: большой лесной hero, ivory-раздел заботы, интерактивные отметка/карта с 3 местами и вечером, ясная установка, FAQ. Сохранены настоящий арт и доступные игровые возможности.
- Лёгкая Canvas-атмосфера: 18/30 частиц, 20/24fps, DPR ≤1.5, ≤1.5млн пикселей, кешированный свет. Пауза вне экрана/при скрытой вкладке, cleanup событий/кадров; ни аккаунта, ни игрового runtime. Глубина от указателя, появления разделов, прогресс чтения; без перехвата прокрутки. Кнопки «Спокойный режим» и reduced motion отключают эффекты, весь контент доступен без JS.
- Один способ установки по умолчанию: actual native prompt или 3 шага текущего браузера. UA + low entropy UA-CH, iPad touch fallback, встроенные браузеры, отдельные Safari/Chrome iOS инструкции. Остальные варианты спрятаны; manual override сохраняется и не смешивается с native CTA другого устройства. SSR нейтрален, noscript fallback и восстановление фокуса.
- Плохой MP4 удалён; честный статичный слот будущего видео без Play/загрузки. `media.json.video=null`; скрипт готовит только три картинки, авторский ролик не создаёт. Обновлены тематическая документация и инструкции медиа.
- Manifest identity и вход игры сохранены; PWA входит сразу, browser session choice/auth/invite/recovery/push продолжают работать. Общая install-панель доступна также из настроек.

## Проверки

- 15 PWA и 10 product tests, 9 motion lifecycle tests прошли отдельно. Review помог исправить manual/native контекст, frozen-opacity night map, pinch ancestors, планшетный layout, контраст и keyboard reveal.
- Typecheck, architecture (573 модуля), world:check прошли. Подготовка трёх изображений повторена, hashes не изменились; никакой ролик не создаётся.
- Общий lint, security (0 находок), diff-check и обе сборки Sites/Next-VPS прошли. Настоящий HTML Sites проверен в полном наборе; Next `/site` статичен, содержит контент/заглушку/нейтральную установку, не содержит video или URL роликов и разрешает zoom 5.
- Полный npm test: 3524 проверки, 3518 pass / 6 fail, без skipped/cancelled. Все шесть имён, locations, сообщений, actual/expected/operator совпадают с ранее снятым baseline `9d5e4e7`: пять таймерных ожиданий `new-map-scene.test.mjs`, одна длина sound-шагов справки. Новых падений нет; полный набор не зелёный.
- Браузерный UI и реальные окна установки не проверены: managed окружение без control-browser. Код/a11y аудит и runtime tests не заменяют ручной iPhone/Android/desktop проход. API/Compose проверки не выполнялись.
