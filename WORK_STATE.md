# Торговый корабль: выдвижной мостик · 0.7.2

26.10.2026. Ветка `work/0.7.2-ship`, продолжение `4191985`. Работа и передача изменений через Git.

## Готово

- Отдельный деревянный мостик шириной 14 мировых пикселей соединяет проход в дальнем борту PNG с травяным берегом. Шарнир — native `1008/353`, берег — world `850/1138` при стоянке `705/1102/310`; длина около 36.5 пикселя. Береговая опора неподвижна, шарнир следует качанию. Мостик рисуется до PNG, порожек скрывает стык. Исходный PNG не менялся.
- Последовательность: `arriving → deploying → docked → retracting → departing → departed`. После остановки мостик выдвигается за 2.4 активной секунды; команда отхода сначала полностью убирает его за 2 секунды. В обоих переходах положение, угол и скорость корабля постоянны. При движении мостик полностью убран.
- Прежние 18 секунд подхода с наклоном по часовой и выравниванием сохранены. После уборки мостика прежний отход занимает 22 секунды: 6 секунд строго вправо, затем вниз с небольшим сдвигом влево и поворотом против часовой.
- Общие часы круга/карты, загрузка PNG, пауза, скрытая вкладка и reduced motion сохранены; остаток времени переносится между фазами. Повторные команды не прерывают мостик. HMR-кэш обновлён.
- **DEV → Сцена → Погода → Приплыть / Отойти / У причала / К кораблю**. «У причала» сразу показывает готовый мостик. Стенд `/prototype/trade-ship`: мостик в режимах карты/рейса, ползунок охватывает весь этап (20.4/24 секунды) и остаётся на 100% после завершения. Крупный вид и PNG-экспорт сохраняют только корабль.
- [Устройство и проверка](docs/game/trade-ship-prototype.md).
