# 0.7.2 — единый интерфейс шахты и цельный мостик

27.10.2026. Продолжение `2f098ba`: пользователь просит шахту в общем виде производств с одним местом, убрать неудачную палубную плашку корабля и предложить интересный контент. Публикация GitHub разрешена. Основная ветка `work/0.7.2`; после проверки синхронизировать `work/0.7.2-ship` без переписывания истории. `master` и деплой не входят в этап.

## Сделано

- Новый `WorldMiningProduction`: одно реальное место сверху, карточки ресурсов в две колонки снизу, общие стили производств. Покупаемых мест/новой очереди нет. Сохранены `start_exploration`/`claim_job`/`cancel_exploration`, таймер, полный склад, подтверждение отмены, старые оплаченные работы и переходы из справки/кладовой. Перед командой повторно проверяются владелец, ревизия, актуальность задания и доступность; повторный клик блокируется. Фокус и сообщения следуют подтверждённому состоянию.
- Chromium выявил перекрытие подтверждения отмены карточками: исправлена специфичность CSS, место растёт вместе с подтверждением/объяснением полного склада. Обычный клик и клавиатура перепроверены.
- Мостик — одна поверхность с общими контуром/градиентом/шагом досок через проём. Отдельная плашка, торец-накладка и металлические ремешки убраны. Два прохода делят поверхность маской, двойной отрисовки при fade нет. Исходный PNG, стоянка, траектория, свет и Tiled сохранены.
- [Проект контента](docs/game/ship-economy-proposal.md): маленькие берега, личные проекты жителей, следопытские дела, реставрация именованных артефактов. Первый срез — «Компас первого капитана». Это предложения; экономические правила, каталог, цены, Ktor и миграции не менялись.
