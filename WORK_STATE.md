# Рабочее состояние: earth

## Живой обзорный глобус

- Работа в `earth` поверх `771114d`. Добавлены природные миниатюры, характер океана, облачка, реакции Мохлика и вечерний свет. Новых сетевых ассетов и зависимостей нет. Геопозиция, backend, игровой мир и Tiled не менялись.
- `globe-biomes.ts`: 14 условных природных зон, 156 объёмных ярусов и 42 тени, один локальный источник и два слоя. Footprint увеличен после мобильного preview, все вершины проверены по суше; высота художественная, до 350 км. Миниатюры исчезают к zoom 3.8. Это не точный рельеф или данные о растительности.
- `globe-ocean.ts`: бесшовная RGBA-фактура 128×128, обновление существующего изображения максимум 4 раза/с без перезагрузки тайлов. До трёх колец на 1.6 с только по видимой воде. `globe-clouds.ts`: восемь оригинальных SVG Marker, нативное скрытие за Землёй, fade 2.5→4.2, без собственного таймера.
- `globe-lighting.ts`: 48 мягких геодезических зон сумерек и до 44 условных огней. «Авто» приблизительно следует UTC, «Вечер» фиксирует солнце относительно выбранного вида, «День» убирает ночь. Первые резкие полосы смягчены до alpha 1.2–1.6%. Только автоматический режим обновляет геометрию раз в минуту; освещение исчезает до улиц. Выбор живёт в открытом разделе.
- `globe-scene.ts` и `scene-clock.ts`: один таймер с шагом 125 мс после первого готового кадра, пауза при hidden/reduced motion/zoom ≥4.2, полная очистка при уходе. В reduced motion декор статичен. `marker-motion.ts` реагирует на события камеры, учитывает wrap углов; нажатие/Enter/Space запускает короткое приветствие. Внешние transform/opacity SDK сохраняются.
- Проверки: 246/246 целевых Earth/navigation/onboarding/PWA/dev/deploy/gesture тестов; полный TypeScript и ESLint, architecture:check (851 модуль), world:check прошли. Обе production-сборки Next/VPS и Sites прошли. Проверка секретов после индексации новых файлов: 0 находок. Полный npm test/API/Compose не запускались: фронтенд-этап без деплоя.
- Чистый Chromium/WebGL2: desktop 1920×961 и 390×844, day/evening и объём просмотрены. 40 с idle: loaded/tiles=true во всех 40 выборках, pending/failed=0, без recovery и новых cache reads; океан ≈3.88 обновления/с. Controlled visibilitychange и reduced motion: 0 imageUpdates/cloudMoves/renders; возврат возобновляет эффекты. Zoom 4.3: анимация остановлена, облака скрыты, биомов нет. Мохлик сохраняет 48×60 px, приветствие не двигает камеру. Два F5: по 11 cache hits, 0 сетевых байтов/запросов карты, 8 облаков, один Map, GPS не запущен. Offline сохраняет Map. Dispose оставляет 0 маркеров/обновлений/кадров и pending=0; два возврата дают 8 облаков и один живой Map. Ошибок приложения/SDK warnings нет. Сервер и браузер остановлены.
- Ограничения: новые зоны освещения у полюсов/антимеридиана покрыты геометрическими тестами, отдельного браузерного прохода там в этом этапе не было. Реальные Safari/iPhone/GPS/FPS/батарея требуют устройства. Next dev при HMR теряет lazy Earth CSS: финальный QA выполнен после чистого restart без инъекции CSS в продукт. Детали: `docs/development/earth-map.md`, `features/earth/README.md`.
