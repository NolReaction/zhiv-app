# Выпуск 0.7.1 и общий новый старт

22 октября 2026. Исходная ветка `0.7.1v2` объединена squash-коммитом `df671b7f2b96b4d85787640e16a0f2f54abbd0c0` в `master` (PR #26); версия приложения 0.7.1. Для этого коммита два полных CI прогона были успешны, включая PostgreSQL и Production Compose. VPS из этой среды не обновлялся.

## Новое указание владельца

Сохранить авторизацию, аккаунты, друзей и необходимые настройки; очистить игру, историю отметок, рекорды, обучение и подарки. Из достижений сохранить только связанные с авторизацией/защитой аккаунта. Решения по остальной границе очистки делегированы исполнителю. Прежний reset этому не соответствовал: он сохранял подарки, историю отметок и локальное обучение.

## Текущий этап: fix/0.7.1-fresh-start

- Добавляется V68: поколение прогресса и журнал сбросов. Сама миграция никого не сбрасывает; фиксированный reset ID `0.7.1` делает повтор команды безопасным для новой игры.
- Сервер отвергает игровые запросы и отметки старого поколения. Клиент проверяет поколение перед запуском игровых подсистем, использует отдельные локальные ключи и перезагружается при сбросе; cookies входа остаются.
- Reset очищает игровой и check-in прогресс, оставляет только достижения защиты аккаунта и их квитанции; создаёт начальное хозяйство, новые приветственное письмо/семь подарков. Друзья и аккаунты проверяются на сохранность.
- Явный deploy-флаг `--reset-game-progress-0.7.1` выполняет сброс в окне обслуживания после миграций. Резервная копия, настоящее восстановление и репетиция reset обязательны. Standalone reset использует общую блокировку с deploy.
- Новость `public/updates.json` сообщает об общем старте, сохранении входа/друзей и повторном обучении. Новый ID новости покажет исправление уже прочитавшим прежний текст. Версия остаётся 0.7.1.
