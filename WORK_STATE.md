# Состояние работы

Рабочая ветка: `work/0.6.7-building-levels`. Текущий этап от `bc653e8`, 2026-10-03: прямая кладовая и читы локального хозяйства. Версии web/API остаются 0.6.6 до выпуска 0.6.7.

## Текущий этап

- На карте постоянно видна кнопка «Кладовая» с заполнением, включая резерв рынка. Она открывает запасы напрямую; прежний вход через дом сохранён. Полная кладовая выделяется цветом. Dock адаптирован под четыре кнопки на телефоне.
- Для маленьких экранов меню резервирует минимум 280 px в пределах доступной области: шапка и улучшение не вытесняют товары. Положение по-прежнему не зависит от выбранного рецепта и открытия улучшения.
- В DEV на главном экране и карте добавлена вкладка «Читы»: монеты, жемчуг, любой товар и количество, мгновенная установка уровня здания, выдача только дефицита следующего улучшения, снятие таймеров стройки/производства/разведки. Готовые задания получаются обычной командой. Платные задания перед прямой сменой уровня нужно получить.
- Читы меняют настоящий профиль локального API через отдельный `/api/v1/economy/dev`. Проверяются development, сеанс, origin, владелец, ревизия, повтор запроса и числовые лимиты с рыночным резервом. Обычный API читы не принимает; production route закрыт.
- Клиент использует общий механизм ожидающей команды, повтора после потери ответа и смены аккаунта. Выдачи могут переполнить кладовую; интерфейс объясняет, как продолжить получение товаров. Визуальная примерка зданий отделена от реальных уровней; есть кнопка её снятия.
- Старый неработающий блок выдачи искр/дерева/камня убран из «Отладки». Справка и инструкции локального запуска обновлены. `/branch` не менялся: каталог и связи развития прежние.
