# 0.7.1v2 — компактные люди и управление геопозицией

2026-10-21. Этап поверх опубликованного `a664780ec51b8dfc1ffc366449ebda1ccf09fa24`, ветка `0.7.1v2`. Master и сервер не менялись.

## Сделано

- «Близкие» на Земле — компактный список участников без игровых действий. Одиночный маркер открывает встречу; групповой — выбор участника, затем встречу, включая совпадающие координаты. Обычный список только фокусирует карту.
- «Пешком» сначала раскрывает выбор Яндекс / 2ГИС / Google / Apple. Ссылки передают только назначение и пеший режим; точность до 200 м, возраст до 5 минут и TTL проверяются при клике. Установленные приложения не перечисляются; HTTPS оставляет выбор приложения/сайта устройству. Apple использует исторический daddr/dirflg для совместимости, требует ручной проверки на iPhone.
- В «Людях» нет отдельных кнопок профиля, посещения и нижней строки действий. Имя/аватар открывает компактный профиль с вкладками «Обзор / Находки / Связь». Посещение внутри обзора; подпись, ID, удаление и отзыв геодоступа — во связи. Переход в гости закрывает модальное окно и сохраняет устойчивую кнопку возврата.
- Кнопки «Статус / Геопозиция» имеют одинаковую постоянную высоту 48px, не расширяют карточку при активации. Подсветка и доступные подписи сохраняют подтверждённое состояние. При общем OFF геокнопка недоступна, отзыв остаётся возможен.
- Профиль → настройки → «Геопозиция»: полный выключатель на устройстве и явная проверка места/точности. OFF синхронно останавливает watches/публикацию, очищает частную точку, блокирует поздние callbacks и сохраняет серверный OFF intent для offline retry. UI не обещает удаление до подтверждения сервера. ON не возобновляет поиск/передачу; нужен новый явный поиск. Сохраняется только owner-scoped enum off/ready/active, без координат. Ошибка/недоступность Storage не теряет последний OFF.
- Обновлены обучение, описание запросов браузерной геопозиции и документация. Новых визуальных слоёв глобуса на этом этапе нет; следующий художественный шаг обсуждается с пользователем.
