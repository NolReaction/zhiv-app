# Состояние работы

## Эксперимент 0.6.8 — Phaser

Ветка `work/0.6.8-phaser` создана от `origin/work/0.6.8` (`347e260`, звуковой движок). Выпущенная версия остаётся 0.6.7. Основная ветка, обучение новичка, production-рендер и серверные данные этим этапом не меняются. Деплой и слияние не выполнялись.

Добавлен отдельный модуль `features/world/phaser/` на Phaser 4.2.1. Стенд `/prototype/phaser-world` без аккаунта использует текущий экспорт Tiled, отдельные изображения зданий и Мохлика. Камера поддерживает мышь, touch/pinch, клавиатуру и DPR ≤ 2. Есть дневной/вечерний режим, контактные тени, авторское перекрытие героя кронами и прогулка по существующей навигации. Собственное аудио Phaser отключено; звуковой модуль 0.6.8 сохранён.

Примерка переносит и масштабирует рисунок каждого уровня вокруг опоры вместе с входом, коллизией и связанной разметкой. 21 подложка земли связана с владельцами по группам Tiled; тест сверяет таблицу с исходной картой. Сетка помогает измерять и привязывать опору; система занятости строительных клеток пока не вводилась. Черновики сохраняются только локально, экспортируются в JSON и проверяют отпечаток карты. Несовместимый сохранённый черновик не затирается, его можно скачать.

Phaser загружается динамически. Подготовка текстур уменьшает GPU-размер крупных PNG объектов без изменения исходных изображений. Основная игра не получает зависимость на лабораторию. Production-маршрут закрыт без `PHASER_LAB_ENABLED=1`; в CI добавлена проверка 404.

Подробно: [запуск, проверка и работа с картой](docs/game/phaser-lab.md). Источник сцены по-прежнему `world/tiled/forest.tmj`; сгенерированный JSON не меняли вручную. [Звуковая система](docs/game/audio-system.md) и [подбор записей](docs/game/sound-search.md) из базовой ветки остаются актуальны; реальных записей пока нет.

## Границы и продолжение

Это рабочая лаборатория переноса сцены, а не замена всей игры. Utility AI, NPC, производство, погода, награды и звук здесь пока не перенесены. Рельефное освещение по normal maps и физическое перекрытие света не реализованы. Запечённые деревья остаются частью фона. Отдельные источники `Lights` пока имеют мировые координаты: для следования за зданием нужна явная авторская связь.

Утром: запустить ветку, открыть стенд на настоящем телефоне, сравнить дом и мастерскую, проверить жесты/нагрев/сворачивание. Затем выбрать одну полянку и мастерскую как эталон: согласовать основание, ракурс, масштаб героя и дневной свет. Удачный JSON примерки можно прислать для переноса в Tiled. Реальный iPhone и серверный Compose этим этапом локально не проверялись.
