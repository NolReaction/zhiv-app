# 0.7.2-fishing: ручки преобразования и студия на воде

Ветка `0.7.2-fishing`, база этапа `a460aa2`. Разработка и Git разрешены; master/deploy вне задачи. `releaseValidated=false`.

## Текущий завершённый этап — 4 ноября 2026

- В `/prototype/boat-garage` добавлены8ручек рамки: края/углы свободно растягивают выбранную деталь, Shift сохраняет пропорции. Круглая ручка вращает вокруг авторского pivot, Shift задаёт15°. Противоположная сторона неподвижна; учитываются неравномерный/отражённый/скошенный родитель, дети следуют. Жест — один undo.
- Выбранная незакреплённая деталь перетаскивается поверх перекрывающего корпуса через верхний interaction-overlay: выбор не перескакивает на верхний слой. Alt+клик/список слоёв позволяют сменить предмет. Закреплённый фон не удерживает выбор. Добавлен публичный setGarageNodeWorldMatrix с полной affine-геометрией и валидацией.
- Новый предпросмотр «На воде» скрывает гараж/стойки только в редакторе. Плавает выбранная иерархия целиком; исходные картинки остаются прежними. Есть вода карты, маска погружения, контактная тень/пена/рябь. Настраиваются уровеньводыY/ширина плавучейчасти/силаволн.
- «Проверить плавучесть» запускает демпфированные heave/roll по двум отсчётам волны, фиксированные шаги1/120с. Это визуальная2Dмодель без массы/объёма отдельных предметов, не полноценная гидродинамика. Пауза возвращает точную редактируемую позу; при hidden/reducedmotion RAF/CSS останавливаются. Авто-качка не меняет сцену, dirty, историю и черновик.
- Необязательный waterPreview={rootId,waterlineY,beam,amplitude} сохраняет только авторские настройки, отсутствующее поле старого JSON не добавляется. Удаление группы очищает её настройки. Само переключение окружения/запуск качки — только состояние UI.
- Для старых сцен с раздельными корпусом/мотором добавлены явные чекбоксы «Добавить отдельные детали в сборку». Мировой вид и zIndex сохраняются; один undo отменяет весь пакет. Предки/locked/невидимые/уже входящие детали исключены; выбранная вместе ветка переносится один раз. Нет автоматического угадывания состава по именам.
- Полноразмерный холст/зум/панорамирование и макеты устройств сохранены. Узкий альбомный fullscreen теперь прячет второстепенные панели и даёт место холсту. Текущая игровая мастерская/экономика/рыбалка не переключены.
- Проверки:77/77garage-тестов (геометрия, все ручки, отражение/поворот, конфиг/группы воды, фиксированная физика, старый JSON/API), TypeScript, architecture1245модулей, полный ESLint и diffcheck. Итоговые Sites/Next сборки успешно выполнены последовательно; старый Turbopack cache сохранён в игнорируемой .next/cache перед чистой сборкой.
- Браузерный QA реального React-сборщика через изолированный Vite: задний мотор→drag/resize/rotate/undo/Alt; вода→редактирование с дочерним мотором, сохранение/перезагрузка настроек, общая качка без dirty, пауза→точный pose/0RAF, reducedmotion;390×844/820×1180/844×390 без горизонтального переполнения. Отдельно старые независимые модули→пакетное присоединение без скачка→один undo→сохранение.0JS-ошибок. Файловый API в UI-стенде тестовый; настоящий Node API покрыт HTTP-тестами. Физический iPhone/Safari/PWA не проверен.

## Сохранённая основа студии

Большой холст «Сборка», fullscreen/Esc, колесо/±/100%/«Вписать»/«К детали», пробел/средняякнопка и макеты «Устройства» доступны. Зум/панорамирование не изменяют камеры/JSON. Старые PNG-мастера и пустой шаблон сохранены. Отдельный отменяемый `garage-scene-example.json` содержит корпус/мотор/боковые стойки; файлы пользователя/черновик не перезаписываются автоматически. art/world/boat-garage и public/world/boat-garage хранят картинки, `modular-parts.json` — ракурс/контакты. Обхватывающие детали по-прежнему требуют front/back-слоёв или маски; анкеры не исправляют несовпадающую нарисованную перспективу.
