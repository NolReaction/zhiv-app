# originals-v1 — первый звуковой набор

Программно синтезированные музыка и эффекты для «Я живой». Набор заполняет все 84 варианта существующего каталога; новые игровые правила и разметка Tiled для его подключения не нужны. Звук включается через **Профиль → Настройки → Звук** на главном экране и на карте; по умолчанию он выключен.

| Материал | Вариантов | Назначение |
|---|---:|---|
| Инструментальная музыка | 2 | Дневная и ночная темы |
| Петли окружения и работы | 9 | Лес днём/ночью, дождь, река, костёр, мастерская, печь, каменоломня, стройка |
| Интерфейс | 13 | Нажатие, открытие, закрытие, подтверждение, ошибка, награда |
| Реакции героев | 36 | Мохлик, Плёск и строитель: приветствие, радость, усилие, сон, по три варианта |
| Действия | 24 | Шаги и предметные действия; точные ID перечислены в manifest |

Реакции героев созданы синтезом без слов и записей человеческого голоса. Реакции усилия всех трёх героев, сон Плёска и строителя и деревянные шаги пока доступны только через DEV: игровые маркеры и определение поверхности для них ещё нужно подключить. Две темы — самостоятельные инструментальные композиции; синхронизации музыкальных слоёв по тактам движок пока не делает.

Три обычных тапа обновлены в редакции `soft-v2`: мягкий деревянный/пузырьковый отклик длительностью 145–155 мс, плавная атака и приглушённый верх. Событие `ui.click` и три ID сохранены; WAV получили версионные имена `ui.click.01.soft-v2.wav` и аналогичные. Остальные записи не менялись.

## Где что лежит

- [`scripts/audio_originals/`](../../../scripts/audio_originals/) — исходный код синтеза и партитуры: `music.py`, `ambience.py`, `effects.py`, сборщик `render.py`.
- [`public/audio/originals-v1/`](../../../public/audio/originals-v1/) — поставляемые с игрой файлы: `loop/` и `effect/` в WAV, `music/` в Opus с запасным AAC/M4A.
- [`manifest.json`](manifest.json) — точные длительности, характеристики, хеши и происхождение результатов сборки.
- [`PROVENANCE.md`](PROVENANCE.md) — способ создания и сведения для карточек каталога.
- [`audio-catalog.json`](../../../features/audio/catalog/audio-catalog.json) — связи файлов с событиями, профили и уровни микшера.

Отдельных внешних WAV-мастеров у этого набора нет: исходником служат сохранённые алгоритмы, ноты и параметры. Несжатые WAV-мастера можно снова получить сборкой.

## Пересобрать

Для генерации нужны Python 3.11+ с `numpy` и `scipy`, а также `ffmpeg` в `PATH`. Версии численных библиотек зафиксированы в `scripts/audio_originals/requirements.txt`; установи их в отдельное Python-окружение. Для обычного запуска игры эти инструменты не нужны: браузер получает готовые файлы.

```bash
python3 -m venv work/audio-venv
source work/audio-venv/bin/activate
python -m pip install -r scripts/audio_originals/requirements.txt
npm run audio:compose
npm run audio:check -- --require-ready
```

Для повторного рендера выбери новую папку: `npm run audio:compose -- --output-dir work/audio-revision-2`. Генератор отказывается перезаписывать уже созданные результаты. Один звук: добавь `--asset river.01`.

По умолчанию генератор пишет мастера WAV, экспорты и `manifest.json` в `work/audio-originals-v1/`. Это отдельная рабочая сборка: проверка `audio:check` читает поставляемые файлы из `public/audio/` и каталог. После изменения генератора сравните результаты, прослушайте их и обновите публикуемый набор вместе с manifest и путями каталога. Для уже выпущенной новой редакции используйте новый путь набора, чтобы избежать старого браузерного кеша.

Генерация использует фиксированные последовательности и параметры. Пересборка сохраняет композицию, но версии численных библиотек и кодеков могут влиять на побитовый результат; для конкретного опубликованного экспорта ориентируйтесь на хеши manifest.

Для будущих записей с микрофона или из библиотеки продолжает работать отдельный `npm run audio:prepare`: [монтаж и экспорт](../README.md).

## Первая проверка на слух

1. Включите звук, оставьте только музыку и послушайте дневную/ночную тему в игре. DEV даёт короткое прослушивание до 4 секунд; для всей композиции можно открыть URL соответствующего `.m4a` из manifest на локальном сайте. Затем зайдите на полную карту и отдельно включите окружение, действия и голоса; в меню доступен только музыкальный фон и UI.
2. Запустите работу мастерской и перемещайте камеру: звук работы должен усиливаться у здания, музыка — немного затихать. Проверьте также реку и зажжённый костёр.
3. Послушайте несколько повторов каждой петли: стык и ритм не должны отвлекать. Отметьте ID слишком резких, тихих или часто повторяющихся звуков.
4. Проверьте переход круг ↔ карта, уход в фон, блокировку экрана и возврат в Safari/PWA на iPhone. После запроса браузера возобновите звук нажатием.

Это начальный микс для совместной оценки. Проверки файлов, пиков и структуры не подтверждают художественное качество или поведение настоящего телефона; итоговые тембры и громкости корректируются после прослушивания.
