# Происхождение originals-v1

- **Проект:** «Я живой» / `NolReaction/zhiv-app`.
- **Владелец проекта:** NolReaction (Дима).
- **Дата создания набора:** 11 октября 2026 года.
- **Способ создания:** программный синтез; код, музыкальные последовательности и параметры подготовлены Codex по заданию владельца проекта.
- **Исходники:** [`scripts/audio_originals/`](../../../scripts/audio_originals/) — `music.py`, `ambience.py`, `effects.py`, `render.py`.
- **Результаты и контрольные суммы:** [`manifest.json`](manifest.json), готовые медиа — [`public/audio/originals-v1/`](../../../public/audio/originals-v1/).

Музыкальные темы собраны из заданных в коде нот и синтезированных инструментальных тембров. Окружение, предметные звуки, интерфейс и реакции персонажей получены из осцилляторов, шума, огибающих, фильтров и временных последовательностей. Для вычислений используются NumPy/SciPy, для экспорта — ffmpeg. Это генерация файлов при подготовке проекта; во время игры браузер воспроизводит готовые медиа.

В набор не включались внешние аудиозаписи, семплы, soundfont, чужие песни или записанные голоса людей. Реакции персонажей — условные синтезированные звуки существ, без имитации конкретного человека. Заимствованных фонограмм, требующих указания внешнего автора, этим набором не добавлено.

Несжатые мастера воспроизводятся командой `npm run audio:compose` из сохранённого кода; отдельной исходной полевой или студийной записи нет. Manifest фиксирует характеристики и хеши конкретной сборки. Изменение версий численных библиотек или кодеков может изменить двоичный результат при сохранении музыкальных последовательностей.
