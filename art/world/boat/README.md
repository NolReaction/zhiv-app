# Модульная графика рыбацкой лодки

Исходные PNG созданы встроенным ImageGen для проекта 2 ноября 2026. Это оригинальные изображения; графика Earn to Die не используется. Его гараж служил только референсом расположения сцены и полосы улучшений. Промпты корпуса и деталей: [modular-assets.json](modular-assets.json); схем и мастерской: [blueprint-workshop-prompts.json](blueprint-workshop-prompts.json).

В этой папке находятся PNG-мастера. `public/world/boat/*.webp` — версии для приложения с исходными размерами и сохранённой прозрачностью, кодирование quality 88–90. В public нет дублирующих PNG. Девять WebP занимают около 3 МБ; карта загружает только корпус и установленные детали, а не фон мастерской или чертежи.

| Изображение | Назначение |
| --- | --- |
| `hull`, `hull-broken` | Исправный и разбитый корпус в одной геометрии |
| `module-oars` | Улучшенные вёсла |
| `module-crate` | Ящик для дополнительного улова |
| `module-landing-net` | Подсак из собранного чертежа |
| `module-telescope` | Подзорная труба из собранного чертежа |
| `blueprint-landing-net`, `blueprint-telescope` | Цельные рисунки, открываемые тремя фрагментами |
| `garage-background` | Пустая сцена мастерской; лодка не вшита в фон |

## Сборка изображения

Единый манифест: `features/world/objects/fishing-boat/fishing-boat-artwork.ts`. Он задаёт исходный размер, прямоугольник видимого предмета (`crop`) и положение в сборке 1000×650 (`box`). PNG не разрезаются и не перерисовываются кодом. SVG в меню является только контейнером растровых изображений; карта использует те же прямоугольники в Canvas `drawImage`. Передняя часть корпуса повторно накладывается для перекрытия ног пассажира. Вода и мостик остаются частью рендера мира.

Чтобы заменить рисунок, сохраните его PNG-мастер и WebP, затем скорректируйте размер/границы/точку крепления в манифесте. Для нового типа детали отдельно нужны правила каталога и сохранения; один файл картинки не создаёт покупаемое улучшение. Например, мотор можно добавить как отдельный слой после определения его игрового действия.

Чертежи используют цельный рисунок 1536×1024. Три CSS-полигона с общими неровными краями открывают части одной картинки без изменения её масштаба. Ненайденные фрагменты не получают фонового изображения. Пороги получения и изготовление остаются в каталоге экономики.

## Проверка

Проверяйте разобранный корпус, установленное снаряжение и примерку на узком/широком экране; на карте — исходящий и обратный курс, единственного пассажира, ночь и reduced motion. Загрузка частей асинхронная с повтором после ошибки и перерисовкой неподвижной сцены. Она не блокирует загрузку леса.
