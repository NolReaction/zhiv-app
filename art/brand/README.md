# Иконка и загрузочный логотип

`mochlik-icon.png` и `zhiv-logo.png` — присланные владельцем исходники, оба 1254 × 1254. Иконка непрозрачная, логотип сохраняет прозрачный фон. Художественную композицию меняйте в мастерах.

Из корня репозитория выполните:

```bash
node scripts/prepare-brand-assets.mjs
```

Скрипт создаёт PNG 32/192/512 px, Apple touch icon 180 px, maskable-иконку 512 px, favicon 16/32/48 px и совместимый `public/icon.svg`. В maskable используется исходный непрозрачный фон до краёв: лицо помещается в центральную безопасную область, кончики ушей могут обрезаться маской лаунчера. Прозрачный логотип 1024 px экспортируется в `public/brand/zhiv-logo.webp`.

`lib/brand-assets.ts` содержит URL с SHA-256 версией файла. Его импортируют manifest, метаданные страницы и заставка. Сохраняйте обновлённые мастера, экспорты и реестр вместе. Service worker подхватывает версию логотипа из preload страницы, а версионные изображения сохраняет для повторного открытия без сети; старые URL иконок остаются совместимыми.

После замены проверяйте иконки в маленьком размере, круговую маску, прозрачный логотип на тёмном фоне и `node --test tests/pwa-contract.test.mjs`. Установленная ОС может применить новую иконку после собственного обновления приложения/ярлыка.
