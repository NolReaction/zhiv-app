# Изображения: что редактировать

Основной источник новой карты — **`art/world/prototype/forest-ground.png`**, 2560 × 2560 пикселей. Основная игра и `/prototype/tiled-world` используют один полный экспорт **`public/world/prototype/forest-ground.webp`**. Отдельных уменьшенных карт, детальных полян и участков со старыми постройками нет.

## Обновление карты

Редактируйте PNG целиком, сохраняя квадратный холст. Для экспорта без потерь:

```bash
node scripts/prepare-world-assets.mjs
npm run world:export
npm run world:check
npm run dev:local
```

`prepare-world-assets.mjs` создаёт WebP в полном разрешении, проверяет точное совпадение декодированных пикселей с PNG и обновляет `features/world/runtime-art.json`. Скрипт не обрезает карту, не уменьшает её и не меняет исходный PNG. Четыре совместимых поля реестра — `map`, `mapPreview`, `homePreview`, `homeDetail` — указывают на один файл с версией содержимого в `?v=`.

`world:export` читает готовый WebP, обновляет его физические размеры в Tiled и версию URL в данных сцены. Он **не перекодирует изображения и не меняет логические координаты**. `world:check` только проверяет файлы. После обновления метаданных закройте и снова откройте карту в Tiled, чтобы не сохранить поверх неё старую копию из редактора.

Проверяйте большую карту и круглый вид на узком и широком экране. В Git сохраняются изменённые PNG, WebP, `features/world/runtime-art.json`, `world/tiled/forest.tmj` и `features/world/tiled/forest.generated.json`.

## Пиксели изображения и координаты мира

Полное изображение имеет размер **2560 × 2560 пикселей**, логический мир — **1254 × 1254**. Увеличение разрешения изображения не меняет масштаб мира. Круглая камера показывает центральную поляну, размеченную прямоугольником `focus` в `world/tiled/forest.tmj`; отдельный рисунок для неё не нужен.

На первом этапе в Tiled остаются только общий рисунок леса и область фокуса. Постройки, их состояния, входы и маршруты ещё не размечены. Старые слои и ссылки на удалённую графику не используются.

| `public/world/runtime/boat-wreck-lowquality.webp` | Прежний уменьшенный экспорт лодки; чистая сцена карты его не рисует |
| `public/world/routes/trail.webp` | Иллюстрация лесной прогулки |
| `public/achievements/` | Семь медалей, выбираемых по ID достижения |
| `public/icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Иконки сайта и PWA |
| `docs/game/concepts/`, `docs/game/images/` | Концепты и снимки прежнего прототипа для документации |

Лодка не перекодируется при подготовке карты. Прежние изображения домов и мастерских доступны в истории Git; не восстанавливайте их поверх нового рисунка.
