## Что реализовано

- Нажатие на дом или его ромбик будит спящего/входящего Мохлика и открывает улучшение. Drag/pinch/cancel не будят.
- В Tiled добавлены 3 Paths и 5 WalkAreas: дом, мастерская, шахта, рыбацкий берег. Навигационная ячейка 4 вместо 6 для узкой северной тропы. PNG, здания, вода и старые препятствия сохранены.
- Два маленьких декоративных жителя ходят по тропинкам с паузами, общим таймером, кэшем спрайтов и отсечением за экраном.
- Для новых `shore`/`shore_camp` герой выходит по тропинке к берегу и возвращается после таймера. Остальные вылазки сохраняют прежнюю визуальную модель. Загруженное старое задание не повторяет выход.
- Ягоды на кусте теперь отражают реальное производство. После созревания игрок нажимает «Собрать»: герой берёт корзинку, идёт к кусту, собирает, возвращает и ставит корзинку; только затем клиент получает награду в кладовую.
- В TS и Kotlin добавлены `collection` в JSONB job и команда `start_collection`, минимум 8 секунд на сервере. Старые job без поля совместимы. Новая SQL-миграция не нужна. Проверяются склад/escrow/герой; повторные запросы защищены receipt/revision/транзакцией.
- Контроллер сбора защищает повторную выдачу, смену аккаунта и запоздалые события; восстанавливается после reload/hidden/reduced motion. При полном складе урожай сохраняется.
- Круг показывает иконку занятия, прогресс и готовность. «В путь» отмечает завершённую вылазку. Для маленького круга добавлен компактный бейдж; сбор имеет статический индикатор занятости без ложного 8-секундного ETA.
- Обновлены DEV-подсказки, игровая справка, `/branch` и тематическая документация.

## Обязательные следующие действия

1. Прочитать `AGENTS.md`, `WORK_STATE.md`, `CONTRIBUTING.md`; проверить Git и CI именно нового checkpoint.
2. Выполнить `npm run typecheck`, `npm run lint`, `npm run world:check`, `npm run economy:check`.
3. Последовательно выполнить `npm test`, затем `npm run build:vps`. Сборки и тесты, читающие `dist/`, не запускать параллельно. После тестов проверить временные `public/tiled-watch-*` fixtures; не коммитить их. Next dev добавляет свой блок в AGENTS.md — исключить его из предметного diff.
4. Проверить JVM CI: Ktor, PostgreSQL integration и Production Compose. При ошибке исправить обычным новым коммитом в рабочей ветке.
5. Повторить focused `tests/forest-memory-sync.test.mjs` и `tests/new-map-scene.test.mjs`: live camera handoff с настоящим snapshot сохраняет garden/feet; changed/expired/foreign lease и conflict должны гидратировать; hidden/reload не сохраняют старую активную routine. Посмотреть последние изменения `preserveLiveScene` в `forest-memory-sync.ts`.
6. В браузере быстро проверить последнюю компактную CSS-правку: круг на 320px, «Готово» без обрезания, полный доступный текст, индикатор сбора без ложного countdown. Проверить день/ночь и reduced motion. Если после guards остаются сомнения, повторить один сбор с живым lease и circle↔map: stock=0 до deposit, затем ровно одна награда, никаких осиротевших take-basket после claim.
