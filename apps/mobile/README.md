# Мохлик · Лаборатория

Отдельное приложение для проверки нативной геолокации и настроек на iOS и Android. Внутри локальная React-сборка, Capacitor 8 и существующий контроллер геолокации Земли. Это первый этап: входа в аккаунт, самой игры и фоновой публикации здесь пока нет.

Из корня репозитория:

```sh
npm ci
npm run mobile:sync
npm run mobile:ios
# или
npm run mobile:android
```

`mobile:sync` собирает web assets и подключает плагины к обоим нативным проектам. Для iOS нужен Mac с Xcode; выберите свою Team в Signing & Capabilities и подключённый iPhone. Для Android установите SDK, указанный в `android/variables.gradle`, и запустите приложение из Android Studio. Отдельный идентификатор `ru.zhiv.mochlik.lab` позволяет установить стенд рядом с основным приложением. Ключи подписи и аккаунты разработчика не добавляются в Git.

`npm run mobile:dev` открывает только предпросмотр интерфейса в браузере. Он не запрашивает GPS и не доказывает работу нативного модуля. Для проверки поведения используйте установленную сборку; каталог `dist` и синхронизированные копии web assets генерируются локально.

Переключатель хранится через Preferences (UserDefaults / SharedPreferences), а координаты — только в памяти. При сворачивании поиск прекращается. После возврата ранее запрошенный поиск может возобновиться; после полного запуска нужно нажать кнопку. OFF немедленно останавливает поиск. Фоновое разрешение и фоновая служба не включены.
