# Я живой · im-alive

[im-alive.ru](https://im-alive.ru/) — PWA для отметок близким и лесного мира с Мохликом. Кнопка **«Я ЖИВОЙ»** отправляет отметку; игровые тапы, коллекции и наряды дополняют её.

**Версия 0.6.6:** Мохлик сам выбирает занятия на полянке, обходит препятствия, плавно поворачивает, прячется в кусте и уходит спать домой. Бабочки и светлячки живут в лесу и встречаются с ним; камера удобнее на телефоне. [Описание релиза и обновление с 0.6.5](docs/releases/release-0.6.6.md). Новые путешествия, строительство и крафт временно отключены на время переноса мира; сохранённый прогресс остаётся. Ограничения задаёт [`presentation.ts`](features/world/presentation.ts).

## Запустить локально

Рекомендуется **Node.js 24**, как в CI; минимальная версия — 22.13. Из корня репозитория:

```bash
npm ci
npm run dev:local
```

Откройте [localhost:3000](http://localhost:3000). Локальный API хранит данные **в памяти**; перезапуск может их удалить. Постоянная БД и полноценная авторизация работают через Ktor.

Для телефона, переменных окружения, настоящего API и диагностики запуска — [локальная разработка](docs/development/local-development.md). Только при локальной разработке: для проверки карты без аккаунта — `/prototype/tiled-world`; для автоматического обновления разметки запустите `npm run world:watch` во втором терминале.

## Проверить изменения

Из корня, последовательно:

```bash
npm run typecheck
npm run lint
npm test
npm run build:vps
```

`npm test` собирает Sites и запускает веб-тесты. Сборки и тесты, читающие `dist/`, нельзя запускать параллельно. После изменения Tiled дополнительно: `npm run world:export` и `npm run world:check`. Проверки API требуют **JDK 25 и Docker**: `cd apps/api` → `./gradlew --no-daemon clean test`; пропущенные PostgreSQL-тесты не подтверждают работоспособность сервера.

## Контуры приложения

| Контур | Запуск / сборка | Хранилище |
|---|---|---|
| Локальный Next.js | `dev:local` | API в памяти для разработки |
| Sites, Vite/Vinext/Workers | `dev` / `build` | Совместимый отдельный контур |
| VPS: Caddy → Next.js + Ktor | `deploy/compose.yml` | PostgreSQL 18, авторизация, админка |

В production DEV-панели и стенд карты отключены, локальный API-имитатор закрыт. Административные операции доступны только через Ktor после проверки сессии и `ADMIN_PUBLIC_IDS`. Локальная разработка продолжается в `work/0.6.7`, созданной от `master` после релиза 0.6.6. `work/0.6.6` и `feature/mochlik-tiled-world` сохранены как история предыдущих этапов. Для DEV-панели запускайте `npm run dev:local`.

Схема основной БД — [миграции Ktor](apps/api/src/main/resources/db/migration/), а не `db/schema.ts`. Поддержка Sites остаётся частью проекта.

Развёртывание — отдельный этап: [первый сервер](docs/operations/server-setup.md), [обновление и восстановление](docs/operations/operations.md). Обычное обновление не требует сброса БД; изменения в рабочей ветке сами по себе не обновляют production.
