# Я живой · im-alive

[im-alive.ru](https://im-alive.ru/) — PWA для ежедневных отметок близким и уютного лесного мира с Мохликом. Кнопка **«Я ЖИВОЙ»** сообщает, что у вас всё хорошо; рядом развивается игра с живыми персонажами, хозяйством, рыбалкой и торговлей.

Текущая версия в **`master` — 0.6.7**. [Состав выпуска и проверки](docs/releases/release-0.6.7.md) · [Новости для игроков](public/updates.json) · [Документация](docs/README.md).

## Что умеет приложение

- **Связь с близкими:** отметки, календарь и серии дней, личные статусы, друзья и группы с настройками видимости. Вход через ВК или почту, привязка аккаунтов и код восстановления.
- **Живой лес:** круг на главном экране и большая карта используют одну Tiled-сцену. Мохлик выбирает занятия с учётом потребностей; Плёска и строитель Шишколап занимаются своими делами. Персонажи обходят препятствия и соседей, разговаривают и взаимодействуют. Поведение задаётся локальной логикой Utility AI.
- **Окружение и оформление:** день и ночь, дождь, вода, освещение, птицы, бабочки и светлячки; анимированный запуск с загрузкой рисунков мира и восстановлением после сетевой ошибки.
- **Хозяйство:** монеты, жемчуг, ресурсы, восемь типов построек, один строитель и цепочки производства. У кладовой десять уровней, у остальных построек — пять. Доступны дополнительные места производства и исследования Мохлика.
- **Рыбалка и торговля:** удочки, крючки и прикормки, разные виды и редкость рыбы, обновляемая лавка Плёски, продажа товаров и личная витрина на рынке игроков.
- **Развитие:** шесть блюд с бонусами, доска трёх заказов жителей, ежедневные подарки, уровни и достижения, книга находок, коллекции и гардероб. Справка ищет ответы по ситуации и помогает перейти к нужному действию.
- **Сохранение и поддержка:** память полянки в аккаунте, серверное подтверждение операций, защита от одновременной записи разных устройств, пауза при потере связи и AFK. При конфликте управления центральное окно предлагает явно продолжить игру здесь. В админке доступны обращения, модерация и аналитика хозяйства и активности.

Правила и цены — в [экономической основе](docs/game/economy-foundation.md), [рыбалке](docs/game/fishing.md), [еде и заказах](docs/game/food-and-orders.md), [коллекциях](docs/game/collections-and-achievements.md). Некоторые уровни зданий используют ближайший доступный рисунок. Платежи, восстановление моста и маяка, интерьер шахты и посещение чужой полянки остаются следующими этапами; границы версии перечислены в [описании выпуска](docs/releases/release-0.6.7.md#границы-выпуска).

## Технологии и контуры

| Часть | Основа |
|---|---|
| Web/PWA на VPS | Next.js 16, React 19, TypeScript |
| Сервер и данные | Kotlin, Ktor, PostgreSQL 18, Flyway |
| Мир | Tiled, общий TypeScript-рендер и логика персонажей |
| Развёртывание | Docker Compose, Caddy, HTTPS, мониторинг |
| Совместимый контур Sites | Vite, Vinext, Cloudflare Workers |

Точные зависимости — в [package.json](package.json) и [сборке API](apps/api/build.gradle.kts). Основная схема PostgreSQL задаётся [миграциями Ktor V1–V45](apps/api/src/main/resources/db/migration/). У двух контуров сборки общие игровые компоненты; их границы описаны в [архитектуре](docs/architecture.md).

## Где искать код

Проект разделён по функциям (`features/`), крупные модули — по ответственности. Общая сборка приложения находится в [`features/app/app-shell.tsx`](features/app/app-shell.tsx). Игровые окна — в [`features/world/ui/`](features/world/ui/), сцена — в `features/world/scene/`, поведение — в `features/world/simulation/`. Экономика отделяет [`domain/`](features/economy/domain/) (правила), `sync/` (команды и состояние) и `ui/` (экраны по темам).

Для профиля «Мой Мохлик» откройте [`features/world/ui/profile/`](features/world/ui/profile/); профиль аккаунта находится в `features/account/`. [Правила размещения кода](docs/development/code-organization.md) · [Задача → конкретный файл](docs/repository-guide.md) · [Владельцы состояния и API](docs/architecture.md).

## Локальный запуск

Рекомендуется **Node.js 24**, как в CI; минимум — **22.13.0**. Из корня репозитория:

```bash
npm ci
npm run dev:local
```

Откройте [localhost:3000](http://localhost:3000). Локальный API-имитатор хранит данные в памяти процесса. Для постоянного хранения и полноценной авторизации подключите Ktor по [инструкции локальной разработки](docs/development/local-development.md).

Для телефона используйте `npm run dev:lan`. Для DEV-проверки карты без аккаунта откройте `/prototype/tiled-world`; `npm run world:watch` во втором терминале обновляет экспорт после сохранения Tiled. DEV-панели, стенд карты и API-имитатор закрыты в production. Серверная админка использует отдельную проверку сессии и `ADMIN_PUBLIC_IDS`.

## Проверки

Для изменений приложения выполняйте из корня, последовательно:

```bash
npm run typecheck
npm run architecture:check
npm run lint
npm run world:check
npm run security:check
npm test
npm run build:vps
```

`npm test` собирает Sites и запускает веб-тесты; сборки и тесты, читающие `dist/`, выполняются последовательно. API проверяется командой `./gradlew --no-daemon clean test` из `apps/api` и требует **JDK 25 и Docker** для PostgreSQL-тестов. [CI](.github/workflows/ci.yml) проверяет секреты, обе web-сборки, Ktor/PostgreSQL и полный production Compose.

Для изменений только документации достаточно сверить факты, команды и ссылки. Порядок работы и проверки перед публикацией — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Работа с картой

Разметка — [world/tiled/forest.tmj](world/tiled/forest.tmj). Мастер фона — `art/world/prototype/forest-ground.png`, браузерный файл — `public/world/prototype/forest-ground.webp`.

```bash
node scripts/prepare-world-assets.mjs
npm run world:export
npm run world:check
```

Подготовка фона и экспорт Tiled — разные шаги. Для изменения только разметки достаточно `world:watch` или `world:export`. [Памятка Tiled](docs/game/tiled-quickstart.md) · [Каталог изображений и порядок экспорта](art/README.md) · [Рисунки и уровни зданий](docs/game/building-workbench.md).
