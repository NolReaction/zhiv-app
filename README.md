# Я живой · Мохлик

Приложение для ежедневной связи с близкими и уютная лесная игра. Кнопка **«Я ЖИВОЙ»** сообщает, что у вас всё хорошо; рядом развивается мир с персонажами, хозяйством, рыбалкой и торговлей. Веб/PWA и установленный клиент iOS/Android используют общий аккаунт и серверный прогресс.

**[Открыть приложение](https://im-alive.ru/) · [Презентация и установка PWA](https://im-alive.ru/site) · [Обзор проекта и инженерных решений](docs/project-overview.md) · [Сборка iOS/Android](docs/development/native-mobile.md)**

**Автор — Дмитрий Сломов ([NolReaction](https://github.com/NolReaction)).** Проект охватывает клиент, Kotlin API, данные, мобильные интеграции и эксплуатацию собственного сервера. Разработка ведётся с использованием ИИ-инструментов; принятые решения, проверки и ограничения описаны в репозитории.

- **Продукт:** отметки, друзья, группы, карта с добровольной передачей геопозиции; лесная симуляция, строительство, производство, мини-игра рыбалки, рынок и прогрессия.
- **Общий интерфейс:** React, TypeScript, Canvas/WebGL; Next.js для веба и Capacitor для установленного приложения. Собственные модули Swift/Kotlin обеспечивают вход, HTTP, защищённое хранение сеанса, SQLite и геопозицию.
- **Надёжность:** серверное подтверждение экономических операций, повтор с прежним `requestId`, восстановление неподтверждённых действий и проверка владельца при смене аккаунта.
- **Сервер и выпуск:** Ktor, PostgreSQL, Flyway, Docker Compose, Caddy и GitHub Actions с веб-, серверными и нативными проверками.

## Новое в 0.7.2

- В **«В путь» → «Лодочная рыбалка»** можно бесплатно восстановить корпус и выйти на реку. При первом выходе короткий курс знакомит с забросом, подсечкой и вываживанием. Удерживайте кнопку на экране, воду или пробел для замаха. Отпустите в зелёной зоне, подсеките при нырке поплавка и чередуйте удержание с отпусканием. У причала можно разгрузить лодку или продать улов с надбавкой за вес. [Руководство рыбака](docs/game/boat-fishing.md) · [Лодка и улучшения](docs/game/boat-fishing-economy.md).
- У костра видны ингредиенты закрытых рецептов и доступны три новых кулинарных опыта. В профиле друга можно посмотреть оснащение лодки и три самых тяжёлых улова разных видов. В админке, в карточке хозяйства, видны работа мастерской, попытки в рейсе, улов на борту и свободные места для разгрузки. [Книга рецептов](docs/game/cooking.md) · [Админка](docs/operations/admin-panel.md).
- После восстановления маяка у причала швартуется корабль. Три личных заказа можно загружать по частям в течение суток. Полный рейс приносит ещё 10 жемчужин; следующий корабль приходит через шесть часов после отплытия. [Порт и грузы](docs/game/trade-ship-prototype.md).
- У Береста есть своя полянка и ежедневная поставка. Сосед может покупать товары из лавок игроков. В профилях друзей видны их уровень, находки и доступные предложения. [Берест](docs/game/economy-v15-neighbor.md) · [Профили друзей](docs/game/friend-profiles.md).
- Жители предлагают большие поручения из трёх этапов. Помощь развивает дружбу и усиливает профессиональные бонусы жителей. Заказы и портовые поставки учитываются в месячном сезоне «Дела леса». [Торговые отношения](docs/game/trade-relations.md).
- Игровой уровень растёт за выполненные дела. Девять навыков развиваются практикой; у костра открываются страницы книги рецептов и кулинарные опыты. Для береговой рыбалки можно сравнить шансы разных снастей. [Навыки](docs/game/cooking-skills.md) · [Книга рецептов](docs/game/cooking.md) · [Рыбалка у берега](docs/game/fishing.md).
- В каменоломне добычу заказывают партиями, для вылазок показаны диапазоны добычи, а кладовая выросла до 15 уровней. У Листохвоста можно обменивать повторные реликвии, в магазине — накопленный жемчуг на золото. [Каменоломня](docs/game/quarry-batches.md) · [Кладовая](docs/game/rewards-and-relics.md) · [Магазин](docs/game/currency-shop.md).

Первоначальный игровой выпуск 0.7.2 довёл схему до Flyway V82. Интеграция мобильного клиента добавляет **V83/V84** для мобильного входа и привязок push. Штатное обновление переводит веб и API на один коммит с сохранением прогресса. Для `imlive-cloud` следуйте инструкции по переключению на релиз с действующим маршрутом `auto-gorizont.ru` в общем Caddy. [Обновление сервера с двумя сайтами](docs/operations/operations.md#второй-сайт-на-imlive-cloud).

## Что умеет приложение

- **Связь с близкими:** отметки, календарь и серии дней, личные статусы, друзья и группы с настройками видимости. Вход через ВК или почту, привязка аккаунтов и код восстановления.
- **Живой лес:** круг на главном экране и большая карта используют одну Tiled-сцену. Мохлик выбирает занятия с учётом потребностей; Плёска и строитель Шишколап занимаются своими делами. Персонажи обходят препятствия и соседей, разговаривают и взаимодействуют. Поведение задаётся локальной логикой Utility AI.
- **Окружение и звук:** день и ночь, дождь, вода, освещение и лесная живность; собственная музыка, звуки занятий и реакции жителей. Отдельные регуляторы музыки, окружения, погоды, действий, шагов, голосов и интерфейса; анимированный запуск с восстановлением после сетевой ошибки.
- **Хозяйство:** монеты, жемчуг, ресурсы, восемь типов построек, один строитель и цепочки производства. Улучшения дома открывают новые рецепты, работы и маршруты; мост и маяк восстанавливаются отдельно. В меню видны текущие работы и доступная продукция; будущие открытия собраны в карточках улучшения.
- **Рыбалка и торговля:** удочки, крючки и прикормки, разные виды и редкость рыбы, обновляемая лавка Плёски, продажа товаров и личная витрина на рынке игроков.
- **Развитие:** книга рецептов и блюда с бонусами, доска заказов жителей, одноразовая цепочка семи подарков, уровни и достижения, книга находок, коллекции и гардероб. Справка ищет ответы по ситуации и помогает перейти к нужному действию.
- **Знакомство и настройки:** Мохлик объясняет приложение, проводит по полянке и помогает освоить отдельные разделы. Новым экономическим профилям доступны стартовые запасы и вводный заказ; за полное прохождение обучения предусмотрена одноразовая награда. Настройки звука, уведомлений и внешнего вида открываются отдельными экранами.
- **Уведомления и подарки:** после подключения устройства PWA может сообщать о готовой стройке, производстве и возвращении Мохлика; категории, тихие часы и ограничения частоты настраиваются независимо. В магазине валют можно ввести действующий промокод.
- **Сохранение и поддержка:** память полянки в аккаунте, серверное подтверждение операций, защита от одновременной записи разных устройств, пауза при потере связи и AFK. При конфликте управления центральное окно предлагает явно продолжить игру здесь. В админке доступны пакетная выдача валюты, предметов и улучшений, управление промокодами и сроками, обращения, модерация и аналитика хозяйства и активности.

Правила и цены — в [экономической основе](docs/game/economy-foundation.md), [рыбалке](docs/game/fishing.md), [еде и заказах](docs/game/food-and-orders.md), [коллекциях](docs/game/collections-and-achievements.md). Некоторые уровни зданий используют ближайший доступный рисунок. [Описание предыдущего выпуска 0.7.1](docs/releases/release-0.7.1.md).

## Технологии и контуры

| Часть | Основа |
|---|---|
| Web/PWA на VPS | Next.js 16, React 19, TypeScript |
| Установленный клиент | Capacitor 8, Vite, общий React/Canvas/WebGL; собственные модули Swift и Kotlin |
| Данные на телефоне | SQLite для неподтверждённых действий; Keychain / Android Keystore для сеанса; Preferences для настроек |
| Сервер и данные | Kotlin, Ktor, PostgreSQL 18, Flyway |
| Мир | Tiled, общий TypeScript-рендер и логика персонажей |
| Карта | MapLibre GL, адаптеры геопозиции браузера и телефона |
| Развёртывание | Docker Compose, Caddy, HTTPS, мониторинг |
| Совместимый контур Sites | Vite, Vinext, Cloudflare Workers |
| Отдельный Engine | TypeScript и Canvas 2D в `packages/engine`; React/Vite-редактор в `apps/engine` |

Точные зависимости — в [package.json](package.json), [мобильном workspace](apps/mobile/package.json) и [сборке API](apps/api/build.gradle.kts). Новая PostgreSQL создаётся из [B49__current_schema.sql](apps/api/src/main/resources/db/migration/B49__current_schema.sql), затем применяет V50–V84; [V1–V49](apps/api/src/main/resources/db/migration/history/) сохранены для обновления существующих БД. [Правила baseline и следующих миграций](docs/development/database-baseline.md). У веб- и мобильного клиентов общие игровые компоненты; их границы описаны в [архитектуре](docs/architecture.md) и [мобильной интеграции](docs/development/native-mobile.md).

## Где искать код

Проект разделён по функциям (`features/`), крупные модули — по ответственности. Общая сборка приложения находится в [`features/app/app-shell.tsx`](features/app/app-shell.tsx). Игровые окна — в [`features/world/ui/`](features/world/ui/), сцена — в `features/world/scene/`, поведение — в `features/world/simulation/`. Экономика отделяет [`domain/`](features/economy/domain/) (правила), `sync/` (команды и состояние) и `ui/` (экраны по темам).

Для профиля «Мой Мохлик» откройте [`features/world/ui/profile/`](features/world/ui/profile/); профиль аккаунта находится в `features/account/`. [Правила размещения кода](docs/development/code-organization.md) · [Задача → конкретный файл](docs/repository-guide.md) · [Владельцы состояния и API](docs/architecture.md).

Ядро экспериментального движка — [`packages/engine/`](packages/engine/), самостоятельный редактор и лесной пример — [`apps/engine/`](apps/engine/). Основная игра пока использует свой Tiled-рендер. [Запуск Engine и перенос JSON](docs/engine/README.md) · [Границы и API](docs/engine/architecture.md).

## Локальный запуск

Рекомендуется **Node.js 24**, как в CI; минимум — **22.13.0**. Из корня репозитория:

```bash
npm ci
npm run dev:local
```

Откройте [localhost:3000](http://localhost:3000). Локальный API-имитатор хранит данные в памяти процесса. Для постоянного хранения и полноценной авторизации подключите Ktor по [инструкции локальной разработки](docs/development/local-development.md).

Для телефона используйте `npm run dev:lan`. Для DEV-проверки карты без аккаунта откройте `/prototype/tiled-world`; `npm run world:watch` во втором терминале обновляет экспорт после сохранения Tiled. DEV-панели, стенд карты и API-имитатор закрыты в production. Серверная админка использует отдельную проверку сессии и `ADMIN_PUBLIC_IDS`.

Самостоятельный редактор запускается командой `npm run dev:engine` на [http://localhost:5174](http://localhost:5174). Ему нужны npm-зависимости; запуск API, Next и вход в игру не требуются. [Пошаговая инструкция](docs/engine/README.md).

Для установленного приложения после `npm ci`:

```bash
npm run mobile:sync
npm run mobile:ios
# либо npm run mobile:android
```

`mobile:sync` собирает и копирует игровые ресурсы в проекты платформ; одно открытие IDE их не обновляет. Для iOS нужны Mac/Xcode и локальная настройка подписи; для Android — JDK 21 и SDK 36. Полный вход использует совместимый сервер с V83/V84. [Требования, установка поверх прежней версии и проверка устройства](docs/development/native-mobile.md).

## Проверки

Для изменений приложения выполняйте из корня, последовательно:

```bash
npm run typecheck
npm run architecture:check
npm run lint
npm run world:check
npm run security:check
npm test
npm run build:vps
```

`npm test` собирает Sites и запускает веб-тесты; сборки и тесты, читающие `dist/`, выполняются последовательно. API проверяется командой `./gradlew --no-daemon clean test` из `apps/api` и требует **JDK 25 и Docker** для PostgreSQL-тестов. [CI](.github/workflows/ci.yml) проверяет секреты, обе web-сборки, Ktor/PostgreSQL и полный production Compose.

Мобильные контракты проверяются `npm run test:mobile`. [Native CI](.github/workflows/mobile.yml) проверяет геометрию интерфейса, Android APK/lint/JUnit и сборки iOS со Swift-проверками. Состояние конкретного коммита — в [GitHub Actions](https://github.com/NolReaction/zhiv-app/actions); автоматические тесты не подтверждают физическую слышимость звука, расход батареи или доставку push. [Матрица приёмки](docs/development/native-mobile.md#проверки-и-приёмка).

Для изменений только документации достаточно сверить факты, команды и ссылки. Порядок работы и проверки перед публикацией — в [CONTRIBUTING.md](CONTRIBUTING.md).
