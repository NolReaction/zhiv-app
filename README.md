# Я живой

PWA с одной главной кнопкой: пользователь нажимает **«Я ЖИВОЙ»**, а близкие видят подтверждённое сервером время последней доступной отметки.

## Версия 0.3.5

- понятный ввод публичного ID: дефисы можно набрать вручную или полностью пропустить;
- постоянное нижнее меню **«Я живой» / «Свои»**, которое не уезжает под длинный список;
- копирование ID участников на iPhone через совместимый с Safari и локальным HTTP fallback;
- поиск подтверждённых личных связей по имени при создании группы;
- выбранные участники сохраняются при фильтрации списка.

Возможности версии 0.3.0 сохранены:

- новый брендинг **«Я живой»** в PWA, manifest и системном меню «Поделиться»;
- постоянный счётчик подтверждённых отметок;
- редкие мемные рубежи на 10, 20, 50, 100, 200, 500, 1000 и далее через каждую тысячу отметок;
- локальная антиспам-серия быстрых нажатий и конфетти на пятом сохранены;
- раздел групп внутри **«Своих»**: семья, друзья или произвольная группа;
- создание, переименование и мягкое удаление группы;
- приглашения только для подтверждённых личных связей;
- человек вступает в группу только после собственного согласия;
- владелец приглашает и удаляет участников, участник может выйти сам;
- отдельное включение новых отметок для личной связи и для каждой группы;
- выключение скрывает доступную отметку, повторное включение не раскрывает старые;
- получатель, доступный через личную связь и несколько групп, считается один раз;
- создание групп и приглашений идемпотентно;
- аудитория каждой отметки и история membership остаются append-only.

Сохранены возможности 0.2.1: onboarding только с именем, случайный публичный ID, `HttpOnly`-сессия, взаимные личные заявки, приватные отметки, 30-секундный cooldown, совместимое с iPhone копирование ID и offline PWA shell без кэширования `/api/**`.

## Быстрый локальный запуск

```powershell
npm ci
npm run dev:local
```

Откройте `http://localhost:3000`. Встроенный in-memory API повторяет контракты Ktor, включая личные связи, группы, приглашения и приватность. Данные удаляются после перезапуска dev-сервера.

## Проверка с телефона в локальной сети

Компьютер и телефон должны быть подключены к одному роутеру.

1. Выполните `ipconfig` и найдите IPv4 активного адаптера с `Default Gateway`.
2. Создайте в корне `.env.local`:

```text
NEXT_ALLOWED_DEV_ORIGINS=192.168.1.232
```

3. Подставьте свой адрес, запустите `npm run dev:lan` и откройте на телефоне `http://192.168.1.232:3000`.

Не используйте на телефоне `localhost`. Локальный HTTP подходит для функциональной проверки; установка PWA, service worker, Web Share и будущие push-уведомления проверяются через HTTPS.

## Production-запуск

Контур: Next.js, Ktor, PostgreSQL и Caddy.

Linux/VPS:

```bash
cp deploy/.env.example deploy/.env
docker compose --env-file deploy/.env -f deploy/compose.yml up --build
```

Windows PowerShell:

```powershell
Copy-Item deploy\.env.example deploy\.env
docker compose --env-file deploy\.env -f deploy\compose.yml up --build
```

Перед запуском заполните домен и длинный случайный пароль PostgreSQL в `deploy/.env`. Caddy принимает HTTPS, отправляет `/api/**` в Ktor, остальные запросы — в Next.js.

## Проверки

Web:

```powershell
npm run lint
npx tsc --noEmit --incremental false
npm run build:vps
```

Полная Sites-сборка и web-тесты:

```bash
npm test
```

Backend на Windows:

```powershell
cd apps\api
.\gradlew.bat test
```

Backend использует JDK 25 и Gradle 9.6. В IntelliJ IDEA откройте корень, импортируйте `apps/api/build.gradle.kts`, выберите JDK 25 для `Project SDK` и `Gradle JVM`, затем используйте конфигурацию **API · Ktor**. PostgreSQL-интеграционные тесты автоматически пропускаются без Docker.
