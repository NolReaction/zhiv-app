# Я живой

PWA для короткой отметки близким и игры с Мохликом. Нажатие «Я живой» сообщает выбранным людям подтверждённое сервером время. В круглой кнопке живёт Мохлик; простой вид можно включить в настройках профиля.

Релиз **0.6.1**: надёжность игровых нажатий, история сбоев в админке и исправления Мохлика. Открытый мир в этом релизе отключён. Его разработка продолжается в **`feature/mochlik-world`**. [Изменения и обновление сервера](docs/releases/release-0.6.1.md).

**Начните с [путеводителя по репозиторию](docs/repository-guide.md).** Там написано, где менять картинки, персонажа, достижения, цены построек и интерфейс.

## Запустить на компьютере

Нужен Node.js 24.

```bash
npm ci
npm run dev:local
```

Откройте `http://localhost:3000`. Локальный API хранит данные в памяти: после перезапуска они могут исчезнуть. Настоящие аккаунты, вход по почте/ВК и постоянная БД обслуживаются Ktor API на сервере.

Для телефона в одной сети создайте `.env.local` по [.env.example](.env.example), укажите адрес компьютера и запустите `npm run dev:lan`. Всем участникам нужен одинаковый адрес приложения. PWA и системные возможности браузера проверяются через HTTPS. Старое имя `npm run dev:mochlik` оставлено как сокращение для `dev:local`.

## Основные возможности

- Отметки, статусы, люди и группы, приглашения, календарь и серия отметок.
- Вход через ВК или почту, объединение профилей и резервный код восстановления.
- Игровой прогресс до 100 уровня, шесть достижений, предметы за серии, рейтинги по тапам и рекорду игры.
- Мохлик в круглой кнопке, день и ночь, грибы, бабочки, светлячки и сон.
- Открытый мир, путешествия и постройки пока доступны только в ветке разработки.
- Админка с выдачей наград, диагностикой, журналами и разбором пользовательских сбоев.

Отметка считается отправленной после ответа сервера. Очередь игровых тапов и восстановление синхронизации описаны [отдельно](docs/game/game-sync-reliability.md). Сервер проверяет игровые результаты; локальная анимация сама не выдаёт наград.

## Проверки перед сохранением

```bash
npm run typecheck
npm run lint
npm run build:vps
npm test
```

`npm test` включает сборку Sites-контура и веб-тесты. После готовой сборки отдельно запустить тесты можно командой `npm run test:web`. Для Ktor нужны JDK 25 и Docker: `cd apps/api`, затем `./gradlew test`.
