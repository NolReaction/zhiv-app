# Engine: отдельный редактор и библиотека Canvas 2D

Engine можно запускать самостоятельно из этого репозитория. Для локальной работы нужны Node.js и npm-зависимости; игровой аккаунт, API, БД и dev-сервер Next не требуются. Теперь редактор работает с проектами v6: можно открыть сохранённый проект или создать лес/пустую сцену своего размера. [Проекты, PNG и миграция](projects.md) · [Диагностика](diagnostics.md).

## Запуск

Из корня рабочей копии ветки `engine`:

```bash
npm ci
npm run dev:engine
```

Откройте [http://localhost:5174](http://localhost:5174). Начните с переноса предмета, рисования тропы или загрузки своего PNG. Подробные клавиши и действия описаны в [руководстве редактора](../game/engine.md).

Если npm-зависимости уже установлены, достаточно `npm run dev:engine`. Версия Node указана в корневом [package.json](../../package.json). Выбор Git-ветки и сохранность своих правок проверяйте перед переключением, отдельно от команды запуска.

## Что находится в репозитории

| Часть | Где | За что отвечает |
| --- | --- | --- |
| Библиотека движка | [`packages/engine/src/`](../../packages/engine/src/) | Типы предметов, координаты, порядок, земля, PNG, Canvas-рендер и свет; без React и игрового аккаунта |
| Приложение редактора | [`apps/engine/src/editor/`](../../apps/engine/src/editor/) | React-интерфейс, жесты, история, миграция, IndexedDB/session и диагностика |
| Примеры | [`forest/`](../../apps/engine/examples/forest/) и [`empty/`](../../apps/engine/examples/empty/) | Лес и чистая рабочая область с собственными каталогами и исходным содержимым |
| Встраивание в основное приложение | `/engine` и `/prototype/procedural-forest` | Тонкие страницы-хосты того же редактора; основной игровой мир остаётся отдельной системой |

React строит панели и кнопки; Canvas 2D рисует сцену. TypeScript описывает данные и команды, Vite запускает и собирает самостоятельный редактор. [Архитектура и API](architecture.md) объясняют, как использовать библиотеку без интерфейса редактора и где менять конкретную возможность.

## Сохранить работу и перенести старую сцену

Законченные правки автоматически сохраняются в IndexedDB текущего браузера. **Скачать сцену** создаёт редактируемый JSON v6 со встроенными исходными PNG; **Скачать PNG** создаёт только готовое изображение. Для переноса работы между браузерами и компьютерами нужен JSON. [Как создать, назвать, скопировать и удалить проект](projects.md#создать-и-организовать-проекты).

`http://localhost:3000` и `http://localhost:5174` — разные origin, даже при одном имени компьютера. У них отдельные БД проектов и localStorage. Откройте прежнюю страницу там, где работали, нажмите **Скачать сцену**, затем **Открыть сцену** в самостоятельном редакторе. На том же origin старое сохранение localStorage переносится в проект один раз; исходный JSON не удаляется. [Метка миграции и старые v1–v5](projects.md#старые-сцены-v1v5).

Новый экспорт — v6 с именем, размером, шаблоном/версией и снимком `baseObjects`. Старые v1–v5 импортируются с прежними правками и PNG; историческое исключение — программный дом-пень из v1. При отказе БД сцена остаётся редактируемой и доступной для JSON-экспорта. Дождитесь **Сохранено** или скачайте копию перед закрытием: асинхронная запись при уходе не гарантирует сохранность. [Формат, ограничения и ошибки](projects.md).

## Проверить и собрать

Из корня, последовательно:

```bash
npm run typecheck:engine
npm run test:engine
npm run build:engine
npm run preview:engine
```

`build:engine` создаёт библиотеку в `packages/engine/dist` и редактор в `apps/engine/dist`. `preview:engine` показывает собранный редактор на [http://localhost:4174](http://localhost:4174). Это отдельный origin: для переноса работы с dev-порта 5174 также нужен JSON. Эти папки — результаты сборки, исходники меняются в `src/`. Итог конкретного прогона смотрите в [WORK_STATE.md](../../WORK_STATE.md); наличие команды в инструкции не означает, что проверки уже прошли.

## Границы текущего этапа

Это локальный экспериментальный инструмент. Самостоятельная сборка не означает согласованный выпуск на публичный сервер. Анимация, адаптер основной игры, авторизация, серверное сохранение и дальнейшие бюджеты кэшей относятся к следующим отдельным этапам. Диагностика показывает время операций и оценку удерживаемой памяти, а не подтверждённый FPS.

Основная игра пока не переведена на эту библиотеку: её Tiled-карта, персонажи, навигация, экономика и сохранения продолжают работать через существующие игровые модули. Изменение сцены Engine не меняет игровой аккаунт.
