# 0.5.2

- Профиль: имя и краткая статистика сверху, остальные настройки в раскрывающихся разделах. Незавершённая привязка почты и резервный код сохраняются при сворачивании раздела.
- Люди: одна кнопка «Добавить человека» открывает приглашение, QR, ввод ID или приглашения. Существующие правила взаимного согласия и приватности сохранены.
- Огонёк открывает личный календарь отметок с выбором месяца и дня. В календаре считаются только сохранённые сервером отметки, включая собственную историю объединённых профилей. Игровые нажатия туда не попадают.
- Дни календаря определяются временем, сохранённым при отметке. Правило серии осталось прежним: промежуток между отметками не больше 24 часов.
- Плавное появление разделов и календаря; настройка уменьшения движения учитывается. Кольца вокруг главной кнопки используют её квадратную область и не растягиваются вслед за экраном.

- Исправлена редкая ошибка объединения профилей при выборе имени второго профиля: обе временные метки изменения имени используют одно серверное время.

## API и обновление

`GET /api/v1/me/calendar?month=YYYY-MM` требует действующий сеанс и возвращает `month`, `today`, `timeZone`, `firstMonth`, `days: [{date, count}]`, `serverTime`. Без `month` выбирается текущий месяц профиля по серверному времени. Неверный или повторённый параметр возвращает 400. Ответы не кэшируются; чужой публичный ID не принимается.

Достаточно обычного обновления Docker Compose по README. Новых миграций нет: используется схема V17. Сбрасывать базу или заново создавать профили не нужно.

## Проверка

Регрессионные проверки охватывают авторизацию календаря, объединённую историю, переход локальной полуночи и месяца, 29 февраля, повторы отправки и изоляцию пользователей. Production Compose проверяет новый запрос под ограниченной ролью БД.

Реальный вход через VK/SMTP и жесты физического iPhone проверяются отдельно от автоматического CI.
