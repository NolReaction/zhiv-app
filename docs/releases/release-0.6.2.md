# Релиз 0.6.2

Выпуск объединяет мир Мохлика и инструменты модерации в один коммит поверх `master` 0.6.1. Приложение пока помечено как **beta-режим**.

## Что изменилось

- Открыт мир с общей домашней сценой, мягким освещением, сменой суток и погодой. Вода движется от бриза и дождя, рыбы плескаются, птицы синхронизированы между картой и круглой кнопкой. После дождя появляются улитка и лягушка, сухой ночью — мотыльки.
- Рыбалка на 5, 15, 30 и 60 минут включает путь к берегу, ловлю с удочкой и возвращение. Награда начисляется после ручного подтверждения; счётчики ресурсов плавно увеличиваются. Исправлены перекрытие персонажа на тропе и отрисовка удочки.
- Основная карта и детальная домашняя поляна сохранены без изменения изображений. Разбитая лодка — отдельный объект; ремонт, посадка и звуки остаются следующими этапами.
- В админке доступны выдача предметов и ресурсов, цветные теги `НИК [тег]`, бан/разбан, ручные пометки и анализ кликов за 10/30/60 секунд и полчаса. Алгоритм отмечает подозрительную регулярность для ручной проверки, **автоматического бана нет**. Все изменения требуют серверных прав и записываются в журнал.
- Значок сервера больше не вращается при каждом игровом тапе. На кнопках отключено случайное выделение при удерживании; поля ввода сохраняют обычное поведение. Блок имени и тега выровнен вправо.
- Удалены неиспользуемые компоненты и старые материалы, обновлены README и эксплуатационные инструкции.

Сохранены исправления 0.6.1: атомарный архив просроченных очередей тапов, диагностика инцидентов, ограничения отправки и обновление правил активного Prometheus. Мир не запускает фоновые таймеры без аккаунта; чтения объединяются и соблюдают паузу после ограничения API.

## Обновление существующего сервера

Веб-клиент и Ktor API обновляются вместе. При переходе с 0.6.1 применяется миграция **V27**; V25–V26 уже входят в предыдущий выпуск. Flyway сохраняет существующие данные. Публикация коммита в `master` сама по себе не развёртывает VPS.

Из чистого серверного checkout:

```bash
git switch master
git pull --ff-only origin master
bash scripts/deploy-update.sh
```

Скрипт собирает образы, создаёт и проверяет резервную копию PostgreSQL до миграций, обновляет сервисы и проверяет readiness. Сброс данных не нужен. Подробности: [эксплуатация](../operations/operations.md), [панель управления](../operations/admin-panel.md).

После обновления проверьте `/readyz`, вход и сохранение тапов, затем `/admin`: выдачу награды, тег и его цвет, бан/разбан тестового аккаунта, аналитику кликов и журнал действий. Доступ задаётся существующим `ADMIN_PUBLIC_IDS`. Регулярность кликов — повод проверить игрока, а не доказательство автоматизации. [Правила модерации](../operations/player-moderation.md).

## Проверки выпуска

Обязательные проверки: ESLint, TypeScript, обе веб-сборки и полный набор веб-тестов; Ktor и интеграции с PostgreSQL; изолированный production Compose с проверкой HTTPS, API, админки и мониторинга. Результат привязан к SHA коммита в GitHub Actions. Проверка админки на реальном сервере выполняется после его обновления.
