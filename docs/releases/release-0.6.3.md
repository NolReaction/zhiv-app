# Релиз 0.6.3

Полное проверенное состояние `feature/mochlik-world-v2` на коммите `d47f2f6` перенесено одним релизным коммитом поверх `master` 0.6.2. Веб-клиент и Kotlin API имеют версию **0.6.3**. Приложение остаётся в beta-тесте.

## Изменения

- Клики сохраняются при потере сети, долгом открытии игровой сессии и перезагрузке. Одновременно видимые вкладки принимают нажатия независимо и передают их одному отправителю с дедупликацией. Результат каждой вкладки сохраняется после подтверждения. Ограничение серверного античита остаётся; превышение частоты явно показано пользователю.
- Карта появляется целиком из лёгкого обзора, а подробные изображения догружаются отдельно. Рабочие WebP и игровые модули сохраняются в версионном кэше. Исходные PNG не изменены. Прицел находит текущее положение Мохлика.
- Исправлены дневное стекло фонаря, маршрут у камней и перекрытие персонажа порогом. Перерисованы три календарных украшения, гирлянда получила мягкие огоньки. В постройках добавлена кастомизация с сохраняемыми переключателями; выключение не удаляет заработанные предметы.
- Имя размещено отдельно от beta-test и уровня. ID копируется только специальной кнопкой. Beta открывает контакты разработчика, уровень — список уровней и условий получения, также доступный из профиля.
- Новые улучшения дома ограничены вторым уровнем; ранее полученные более высокие уровни сохранены. Далее показано «Игра в разработке».
- Лесные прогулки доступны на 5/10 минут, рыбалка — на 5/15/30/60. Иллюстрации и выбор времени приведены к единому виду, награды пропорциональны длительности. Уже начатые путешествия сохраняют прежние награды.
- Все шесть прежних находок доступны. Добавлены шесть речных предметов, ивовая удочка за речной комплект и достижение «Хранитель находок» за все 12.
- Наблюдение в админке выделено красным; добавлены месячная история кликов и CSV для анализа. Доступ и операции защищены серверными правами.

## Обновление с 0.6.2

Веб-клиент и Ktor API обновляются вместе. Flyway применяет **V28**: месячные агрегаты кликов и расширение коллекций/достижений. Сброс данных не требуется. Сохранившаяся секундная история переносится в агрегаты; уже удалённые старые интервалы восстановить невозможно. Каталоги мира v3 и достижений API4 сохраняют предусмотренную совместимость с прежними версиями.

Публикация `master` не развёртывает VPS автоматически. Из чистого серверного checkout:

```bash
git switch master
git pull --ff-only origin master
bash scripts/deploy-update.sh
```

Скрипт собирает образы, создаёт и проверяет резервную копию PostgreSQL перед миграциями, обновляет сервисы и проверяет readiness. После обновления перезапустите старые игровые вкладки/PWA, сохранив данные браузера и локальные очереди. Затем проверьте вход, клики с двух устройств, кастомизацию и месячный CSV тестового аккаунта. Подробности: [эксплуатация](../operations/operations.md), [история и наблюдение](../operations/player-moderation.md).

## Проверки

Исходное состояние `d47f2f6` прошло 338 веб-тестов, обе сборки, проверки типов и ESLint, Ktor/PostgreSQL и production Compose через HTTPS, включая админку. Пользователь проверил версию и одобрил выпуск. Для релизного SHA полный CI запускается повторно.

Регрессии включают 1000 отложенных кликов с reload, 1000 кликов с моделируемой частотой 25/с, экстремальный онлайн-всплеск с дальнейшим продолжением игры и две вкладки по 720 кликов. Мгновенное превышение допустимой частоты может быть отклонено античитом; очередь продолжает работу.
