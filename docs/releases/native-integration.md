# Интеграция веба, iOS и Android

Общая кодовая база объединяет веб/API 0.7.2 и мобильный пакет 0.3.2/build 5. Пакет имеет отдельную версию и пока использует app ID `ru.zhiv.mochlik.lab`. Это интеграция подготовленного клиента; публикация в App Store/TestFlight, подписанный Android release и подключение провайдеров push остаются отдельными этапами.

## Что входит

- Общий AppShell: аккаунт, отметки, лес, экономика, лодочная рыбалка, карта и профиль. Web/PWA и поддерживаемая сборка Sites сохраняются.
- Capacitor с собственными Swift/Kotlin-модулями: системный браузер и PKCE/state, защищённый сеанс Keychain/Keystore, нативные HTTP-запросы, SQLite для неподтверждённых действий, геопозиция, сеть, lifecycle и safe areas.
- Явно включаемая геопередача в фоне; выбор получателей и OFF/призрак сохраняют действие. Ограничения ОС и принудительное закрытие могут остановить передачу.
- Локальные напоминания строительства, производства и путешествий. Серверные APNs/FCM для новой административной почты и напоминания об отметке требуют конфигурации.
- Исправление загрузки встроенного звука HUD/производства на iOS из `4c4cab6`, корректировки Swift capture и экранных отступов.
- V83/V84 и совместимые серверные проверки миграций, сбросов, сеансов и уведомлений. Исторические SQL и конфигурация общего Caddy сохранены.

## Как объединена история

База интеграции - `master` `d45316b`. Перенесён итог мобильной разработки `493d399..4c4cab6`, после чего обновлена документация и включён native CI для master. Сохраняются единая новость 0.7.2 и исправления очистки релиза. Интеграция вошла в master одним squash-коммитом `205f0d9` через [PR #43](https://github.com/NolReaction/zhiv-app/pull/43), поэтому прежние 134 промежуточных коммита не вернулись в его историю.

Ветка `experiment/native-mobile` остаётся источником истории. Новые изменения начинайте от актуального master; не сливайте старую ветку повторно обычным merge. Архив прежнего master - `archive/master-before-0.7.2-squash-2026-11-16`.

## Сервер и установка

1. Выбрать полный SHA объединённого выпуска с успешными проверками. Проверить исходный SHA сервера, историю Flyway и резервную копию по [инструкции эксплуатации](../operations/operations.md#второй-сайт-на-imlive-cloud).
2. Выполнить штатное обновление web/API. С V82 применяются V83 и V84; с уже совместимой V84 новые миграции не требуются. Общий маршрут «Авто-Горизонта» сохраняется. Обычное обновление не сбрасывает игроков.
3. Проверить `/healthz`, `/readyz`, веб-вход и `/mobile/connect`; затем собрать клиент для того же HTTPS origin через `npm ci` и `npm run mobile:sync` по [мобильной инструкции](../development/native-mobile.md).
4. Устанавливать поверх прежней версии с тем же bundle/application ID и подписью. Team Xcode и Android signing key - настройки разработчика, их не следует затирать при обновлении Git.
5. Для APNs/FCM отдельно выполнить [настройку провайдеров](../operations/native-push.md). Старому мобильному сеансу без платформы после V84 может понадобиться повторный вход. Без этих настроек remote push остаётся отключён.

## Приёмка на устройствах

- Слышны меню, HUD и начало производства; после сворачивания/возврата звук восстанавливается.
- Вход, выход, смена аккаунта и отзыв сеанса не смешивают данные владельцев.
- После потери связи и перезапуска сохраняются неподтверждённые действия, улов и квитанции; повторы не удваивают награду.
- Разрешение/отказ GPS, OFF/призрак, фон и выключение геопередачи соответствуют выбору пользователя.
- Safe areas, поворот и клавиатура не перекрывают действия; память и батарея проверены при длительной сцене.
- Локальное напоминание и, после подключения провайдеров, remote push доставляются; переход по уведомлению проверяет текущего владельца.

Зелёный CI не подтверждает физический аудиовыход, фактическую доставку уведомления или состояние VPS. Текущий CI собирает Android debug APK; release signing требуется перед распространением release-сборки. Доступ к TestFlight и APNs зависит от Apple Developer. Для разработки, локальной проверки и демонстрации веба ожидание публикации в магазине не требуется.
