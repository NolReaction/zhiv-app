# Земля, карта и геопозиция

Начало разработки в ветке `earth`, созданной от `work/0.7.1` на `29c9eac`. В основной навигации четыре раздела: «Я живой», «Люди», «Карта», «Профиль».

## Текущий этап

Вкладка «Карта» содержит вращаемый глобус с приближением до улиц, кнопки масштаба, возврат к Земле целиком, ориентацию на север и собственное местоположение. «Моя полянка» открывает существующую игру; возвращение сохраняет ракурс карты. Кнопка «Близкие» показывает реальные контакты из существующего People controller. Координат друзей в этом этапе нет, интерфейс прямо сообщает об этом.

MapLibre GL JS 6.15.0 рендерит глобус. OpenFreeMap предоставляет стиль Liberty и векторные данные OpenStreetMap. SDK загружается только при открытии вкладки. Картографический движок не связан с собственной технологией Canvas 2D в `packages/engine/`: географические проекции и уличная карта имеют отдельные задачи.

Поставщик карты задан одной константой в `features/earth/map-style.ts`. Публичный endpoint не требует ключа для этого этапа, но доступность и пропускная способность внешнего сервиса не гарантируются приложением. Перед массовым выпуском нужно отдельно выбрать условия обслуживания или собственное размещение. Спутниковые снимки и рельеф пока не подключены.

## Геопозиция

- Браузерное разрешение запрашивается только после «Где я». Открытие вкладки не включает GPS.
- Первая полученная точка перемещает камеру. Дальнейшие обновления двигают маркер, позволяя свободно изучать карту; «К себе» снова центрирует камеру.
- Показываются время последнего обновления и точность в метрах/километрах. Круг точности рассчитывается на сфере, включая переход через линию перемены дат.
- При скрытии страницы, игровом overlay или приостановке активности наблюдение выключается. Возобновление возможно только после ранее сделанного явного запроса в этом экземпляре раздела.
- «Выключить», уход в другую вкладку, смена аккаунта и отзыв разрешения очищают координаты. Поздние callbacks и ответы Permissions API не восстанавливают отменённое состояние.
- Координаты не сохраняются в localStorage, IndexedDB, URL, игровой профиль или серверный API. Запросы картографических тайлов идут поставщику карты; выбранная область карты и IP видны поставщику. Отдельной передачи координат другим игрокам нет.
- Настройка браузера `enableHighAccuracy: false` предпочтёт экономичное определение. Полученная точность не обещает работу GPS на уровне нескольких метров.
- Нужен HTTPS либо localhost. Для телефона с LAN-адресом по HTTP разрешение недоступно; обхода ограничения нет. `Permissions-Policy` разрешает геолокацию только самому приложению (`self`), камера и микрофон остаются выключенными.

Гарантированной фоновой геолокации в PWA нет. Для следующего мобильного этапа потребуется нативный модуль с разрешениями Android/iOS.

## Сборка и файлы

Основная точка сборки: `features/app/app-shell.tsx`. Экран и контроллеры находятся в `features/earth/`; навигация остаётся в `features/app/`.

MapLibre 6 использует отдельный module worker. `scripts/prepare-earth-assets.mjs` копирует worker, shared module и лицензию из установленной закреплённой версии в `public/vendor/maplibre-gl-<version>/`. Сгенерированные файлы исключены из Git и ESLint. Подготовка выполняется автоматически:

- `npm run dev` через `predev`;
- `npm run dev:local`, `dev:lan`, `dev:vps`, `dev:mochlik` через `next-dev.mjs`;
- `npm run build` и `npm run build:vps` через общий `app-build.mjs`.

Ручная подготовка: `npm run earth:prepare`. После прямого вызова `next dev` или Vite без npm-обёртки её нужно выполнить отдельно. Worker размещается на своём origin, выполняемый JavaScript с CDN не подключается. Атрибуция карты видна внизу canvas. Географические тайлы не добавлены в service worker приложения; загрузка новых областей требует сети.

## Проверка

`node --test --test-concurrency=1 tests/earth-*.test.mjs` проверяет контракты экрана, навигацию, разрешения и lifecycle геопозиции, поздние callbacks, геометрическую точность и подготовку worker. Дополнительные регрессии: `tests/next-dev.test.mjs`, `tests/deploy-lifecycle.test.mjs`, `tests/pwa-contract.test.mjs`, `tests/app-onboarding.test.mjs`, `tests/browser-zoom-guard.test.mjs`.

Для браузерной проверки: открыть «Карта» на 320/390px и desktop, повернуть и приблизить глобус, проверить атрибуцию, разрешить/запретить геопозицию, выключить её, перейти в другую вкладку и обратно, открыть полянку, потерять сеть и повторить загрузку. При отсутствии WebGL 2 экран показывает объяснение. Короткий landscape допускает прокрутку содержимого без перекрытия нижней навигацией. Реальную точность GPS и расход батареи нужно проверять на телефоне.

## Следующие этапы

1. Серверный контракт временной геопозиции и отдельное согласие на показ конкретным подтверждённым друзьям. Не использовать текущий SharingMode отметок как разрешение геолокации. Отзыв, удаление дружбы и смена аккаунта должны сразу закрывать доступ.
2. Последняя точка с TTL, точностью и временем; ограничения частоты, проверка владельца, запрет общедоступных списков координат. Эквивалентные контракты Ktor/PostgreSQL и локального API с миграцией и тестами доступа.
3. Аватары друзей, расстояния и переход в разрешённый игровой профиль. Фоновое обновление и native SDK отдельным этапом.
4. Игровые места и совместные события поверх географии. Реальные координаты не доказывают физическое присутствие и не должны сами выдавать награды; правила и защита остаются серверными.
