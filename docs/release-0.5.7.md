# 0.5.7 — закрытая панель управления

Панель доступна по `/admin` после существующего входа в разрешённый аккаунт. Доступ задаётся только серверным `ADMIN_PUBLIC_IDS`, по умолчанию закрыт.

- Обзор регистраций, отметок и активности, D1/D7 по завершённым дням UTC, игровые показатели и состояние БД.
- Поиск пользователей, сортировка и страницы; завершение сеансов с точным подтверждением, причиной и защитой администраторов.
- Транзакционный неизменяемый журнал действий и идемпотентные повторы операций; миграция V22, 35 прикладных таблиц.
- Метрики VPS и API, графики последнего часа и сигналы проблем. Prometheus и node-exporter работают в необязательном приватном Compose-профиле, без открытых портов и Docker socket.
- Случайный секрет доступа к внутренним метрикам, no-store для панели/API, исключение административных страниц из offline service worker.
- Мобильная компоновка, автообновление видимой вкладки, явные состояния устаревших или недоступных данных.
- Скрипт настройки администратора и короткий скрипт обновления с проверенной резервной копией. Права секретов нормализуются и при `umask 077`.

Статистика рассчитывается по существующим данным; посещения без отметок не собираются. История серверной нагрузки появляется после включения мониторинга. Завершение сеансов не запрещает повторный вход. Внешние уведомления пока не подключены.

Подключение и управление: [инструкция панели](admin-panel.md).
