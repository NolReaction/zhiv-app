# 0.5.4

## Игровой прогресс в аккаунте

Уровень, общее число игровых тапов и рекорд теперь опираются на подтверждённый сервером прогресс. Один аккаунт использует общие данные на Android, iOS и в других браузерах. Анимация и текущая игровая серия реагируют на нажатие сразу; сетевые запросы отправляются небольшими последовательными пакетами.

Старая локальная статистика сохраняется отдельным архивом в профиле. Она не импортируется в сетевой счёт: прежний localStorage можно было изменить вручную, и сервер не может проверить эти результаты. Новый сетевой отсчёт начинается с нуля. Без интернета игровые эффекты работают, но новые тапы не копятся для последующего начисления.

Диагностический `/api/v1/game-events` остаётся совместимым с прежними клиентами и не начисляет очки. Отметка «Я живой» и игровая статистика — независимые операции: клики не обходят паузу между отметками и не увеличивают календарную серию.

## Рейтинг месяца

Кнопка с кубком на главной странице и в профиле открывает топ 100. Вверху видны собственные игровые тапы за текущий месяц и место, даже за пределами первой сотни. При равном счёте используется стабильный порядок.

Участие выключено по умолчанию. Включение явно разрешает показывать другим авторизованным игрокам имя и игровые тапы. Публичный ID, последняя отметка, статус, часовой пояс и список связей в рейтинг не передаются. Отключение скрывает игрока из следующих ответов рейтинга и сохраняет личный прогресс.

Все игроки используют один месяц по UTC. Смена месяца обнуляет месячный зачёт, общий прогресс сохраняется. Часовой пояс профиля и часы телефона не определяют период рейтинга. При объединении аккаунтов общее число тапов складывается, рекорд берётся наибольший, а месячный зачёт — наибольший из двух, без суммирования. Настройка участия остаётся от текущего профиля.

## Серверная проверка игры

- Сервер выдаёт короткую игровую сессию, привязанную к пользователю. Сессия ограничена текущим месяцем.
- Каждый пакет содержит номер по порядку, число тапов и ID игровой серии. Клиент не передаёт итоговый счёт, уровень или доверенные даты.
- Непрерывная серия сохраняется при продлении сессии и переходе месяца, если между принятыми пакетами не больше 12 секунд. Параллельные игровые сессии не объединяют свои серии.
- Повтор последнего принятого пакета не начисляет очки повторно; замена его содержимого возвращает конфликт. Клиент держит один пакет в отправке и повторяет неизвестный результат с прежними параметрами.
- Общий лимит на аккаунт — 12 тапов в секунду с запасом на короткую серию из 60 тапов. Несколько вкладок и устройств расходуют один лимит. Сервер может принять только часть пакета.
- Игровое время и месяц рассчитываются сервером; права владельца и версия настройки участия проверяются при изменениях.

Эти правила ограничивают завышенные пакеты, повторы и обход через смену часов. Они не доказывают физическое нажатие человеком: автокликер, имитирующий допустимую скорость, полностью исключить таким протоколом нельзя. Рейтинг не предназначен для денежных призов без дополнительной защиты.

## Приглашения

Окна добавления по ID, создания ссылки/QR и открытия приглашения оформлены в стиле календаря: полупрозрачное стекло, мягкое появление и закрытие, компактные кнопки и безопасная область экрана. Способы добавления появляются последовательно. Учитываются уменьшение движения и прозрачности в настройках устройства. Порядок ID → ссылка → QR → открытие сохранён.

## Обновление

V20 добавляет таблицы игрового прогресса, месячных результатов и сессий. Существующие миграции и отметки не изменяются; сброс базы не нужен. Перед обновлением сохраните резервную копию, затем используйте обычный запуск `sudo docker compose --env-file deploy/.env -f deploy/compose.yml up -d --build --wait --wait-timeout 240`.

Проверки включают протокол повторов, лимит нескольких устройств, границу месяца, отдельный учёт игры, добровольное участие, удаление/объединение аккаунтов и новые маршруты под production-ролью PostgreSQL. Внешний вид и жесты физического iPhone проверяются на устройстве.
