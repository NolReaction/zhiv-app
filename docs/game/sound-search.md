# Звуки для окружения: что искать

Это список для подбора. Звук в приложение пока не добавлен.

| Слой | Поисковый запрос | Что выбирать |
|---|---|---|
| Тихий лес | `quiet forest ambience seamless loop no music` | Мягкий дальний фон, без голосов и навязчивого постоянного щебета |
| Речка | `gentle small stream water loop` | Спокойная вода без мощного водопада |
| Бриз | `soft breeze leaves rustling loop` | Лёгкий шелест без свиста и сильных порывов |
| Дождь | `light rain leaves water seamless loop no thunder` | Мелкий дождь по листве и воде, без грома |
| Факелы | `small fire soft crackle loop` | Тихое потрескивание, без резких хлопков |
| Птицы | `small forest bird distant single chirp` | Несколько отдельных коротких записей для редких пролётов |
| Рыбки | `small water plop gentle splash` | Небольшие всплески с мягкой атакой |
| Лягушка | `single soft frog croak` | Один негромкий голос для появления у камышей |

Для фона удобны бесшовные петли 30–90 секунд; отдельные действия — короткие записи примерно 0.3–3 секунды, желательно 3–5 вариантов. Искать чистые исходники WAV/FLAC; сжатие для веба можно сделать после выбора. С каждой записью сохранить страницу источника, автора и условия использования.

Сначала стоит собрать лес, воду, дождь и птиц. В будущей реализации речка должна становиться слышнее при приближении камеры, огонь — рядом с факелами. Птичий крик и всплеск лучше привязать к событию; ветер и дождь — к погоде. При переходе между кружком и картой менять громкости плавно, не перезапускать запись. Улитку и мотыльков оставить тихими.
