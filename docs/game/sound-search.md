# Звуки для окружения: что искать

Движок, пространственная разметка Tiled, события, настройки и диагностика уже подготовлены: [устройство звука](audio-system.md). Реальные записи ещё не выбраны; пустые слоты каталога молчат. Здесь — список для следующего этапа, когда будет возможность прослушивать варианты.

| Слой | Поисковый запрос | Что выбирать |
|---|---|---|
| Основная тема | `cozy woodland instrumental game music loop` | 2–4 минуты спокойной инструментальной музыки, без вокала, громких ударов и резкого вступления; мягкие деревянные тембры |
| Тихий лес | `quiet forest ambience seamless loop no music` | Мягкий дальний фон, без голосов и навязчивого постоянного щебета |
| Речка | `gentle small stream water loop` | Спокойная вода без мощного водопада |
| Бриз | `soft breeze leaves rustling loop` | Лёгкий шелест без свиста и сильных порывов |
| Дождь | `light rain leaves water seamless loop no thunder` | Мелкий дождь по листве и воде, без грома |
| Костёр | `small fire soft crackle loop` | Тихое потрескивание, без резких хлопков |
| Птицы | `small forest bird distant single chirp` | Несколько отдельных коротких записей для редких пролётов |
| Рыбки | `small water plop gentle splash` | Небольшие всплески с мягкой атакой |
| Лягушка | `single soft frog croak` | Один негромкий голос для появления у камышей |
| Мастерская | `woodworking workshop wooden mallet hand saw loop` | Столярная работа с паузами: дерево, молоток, пила; без голосов и музыки |
| Интерфейс | `soft organic game UI click confirm` | Короткий спокойный набор одной стилистики, без резкого металлического звона |
| Мохлик | Собственная запись приветствия, удивления, радости, усилия | Короткие реакции без слов, по 3–5 разных дублей; исходник без музыки и обработки |

Длинный исходник фона можно принести целиком; для текущего движка готовим петли примерно 5–20 секунд, чтобы несколько источников помещались в память телефона. Отдельные действия — записи примерно 0.3–3 секунды, желательно 3–5 вариантов. Чистые исходники WAV/FLAC предпочтительны; обработку и экспорт выполняем после отбора. Музыка воспроизводится потоково и может быть длиннее петли окружения.

Первый комплект: **одна основная тема, лес, река, мастерская, костёр и UI-нажатие/открытие/подтверждение**. Ночной трек, птицы, отдельный ветер, голоса и остальные эффекты можно добавлять постепенно. Для птиц, лягушки и ветра ещё понадобятся отдельные профили/события; это список поиска, а не обещание автоматического подключения каждого файла.

С каждой записью принесите оригинальный файл, точную страницу источника, имя автора и сохранённые условия использования. Предпочтительные кандидаты — собственные записи и записи с явно указанной CC0. Для любого внешнего материала проверяем происхождение и условия коммерческой публикации; надпись «бесплатно» сама по себе ничего не подтверждает. Музыку из другого произведения можно использовать как референс настроения, пока право на её включение в игру не установлено.

Начать поиск UI можно с [Kenney UI Audio](https://kenney.nl/assets/ui-audio) и [Interface Sounds](https://kenney.nl/assets/interface-sounds): страницы этих наборов указывают CC0. Для природных и предметных записей подходит [Freesound](https://freesound.org/), с проверкой лицензии каждой записи и фильтром CC0; [FAQ о лицензиях](https://freesound.org/help/faq/) объясняет различия. Сведения проверены 8 октября 2026 года; карточку выбранного файла сохраняем отдельно.

Для собственной озвучки: тихая комната, одинаковое расстояние до телефона, несколько дублей с паузами, без телевизора и фоновой музыки. Сохраните нетронутый файл. Пока нет возможности слушать, достаточно собрать ссылки и исходники — финальный отбор, уровни и стыки позже проверим в игре.

Размещение оригиналов, монтажных копий, лицензионных карточек, ограничения и команды экспорта описаны в [art/audio/README.md](../../art/audio/README.md). После подключения река будет меняться по положению камеры, мастерская — по реальной работе производства, костёр — по огню; эти правила уже находятся в адаптере мира.
