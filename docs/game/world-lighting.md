# Ночь и освещение

[Навигация по документации](../README.md) · [Устройство мира](world-foundation.md) · [Редактор Tiled](tiled-editor.md)

Актуально для новой Tiled-карты. День и ночь используют один рисунок: приложение накладывает холодное освещение и локальные источники. Круг, большая карта и Tiled preview получают один набор источников: фонари дорог из экспорта Tiled и лампы, привязанные к активному рисунку здания.

## Где менять

| Задача | Источник |

| Изменить контракт источника | `features/world/tiled/types.ts` → `WorldLight` |
| Сделать ночь темнее, изменить лунный свет и форму пятен | `features/world/forest-lighting.ts` → `lightTexture` |

Изменения в них **не меняют текущую ночь** при `WORLD_PRESENTATION.rebuilding = true`. Имя `dusk` в текущем коде означает степень ночного освещения 0–1; отдельного режима сумерек нет.

## Добавить источник в Tiled

1. Откройте `world/tiled/forest.tmj`. В **Lights** дублируйте подходящую точку или вставьте **Point**.
2. Дайте уникальное имя, например `bridge-torch-1`. Поставьте точку в центр лампы или пламени. Стойка факела рисуется ниже неё примерно на 17 единиц мира.
3. Задайте свойства из таблицы. `role` и `siteId` для объектов **Lights** не нужны; ширина и высота точки остаются нулевыми.
4. При запущенном `npm run world:watch` сохраните карту. В приложении откройте **DEV → Время суток → Ночь**. В `/prototype/tiled-world` включите ночной режим.
5. Проверьте день, ночь, круг, большой масштаб и общий обзор. Затем `npm run world:check`. Сохраняйте в Git и `.tmj`, и `features/world/tiled/forest.generated.json`.

| Свойство | Тип Tiled | Значение |
| --- | --- | --- |
| `kind` | string | `lantern`, `torch`, `glow`; по умолчанию `lantern` |
| `radius` | float | Радиус в единицах мира: больше 0, не больше 500; по умолчанию 70 |
| `intensity` | float | 0–2; по умолчанию 1. При 0 огонь и свет выключены, стойка факела остаётся |
| `color` | color | Непрозрачный цвет; также принимается string `#RRGGBB`. Яркость задаётся через `intensity` |
| `flicker` | float | 0–1; 0 полностью останавливает мерцание |

Значения цвета/мерцания по умолчанию:

| `kind` | Цвет | `flicker` | Что рисуется |
| --- | --- | --- | --- |
| `lantern` | `#ffd28a` | 0.04 | Свет поверх уже нарисованного фонаря; новый корпус не добавляется |
| `torch` | `#ffb45d` | 0.12 | Стойка днём и ночью; пламя и свет ночью |
| `glow` | `#8adbd0` | 0 | Цветное свечение без стойки |

**Lights** может быть объектным слоем либо группой с вложенными слоями `Torches`, `Lanterns`, `Glows`. У объектных слоёв допустимы **Manual** и **Top Down**. Имя `Lights` чувствительно к регистру. Не вкладывайте его в `Water`/`WaterExclusions`; смещение, параллакс, скрытые объекты и неполная непрозрачность не поддерживаются. Выключайте источник через `intensity: 0`.

Для известных PNG лампы привязываются к изображению через `siteImagePoint`: перенос, масштаб и поворот выбранного Tiled-уровня применяются также к свету. `home-lantern` следует нарисованному фонарю каждого из пяти уровней дома; его яркость, цвет и радиус по-прежнему можно задать в **Lights** (сейчас радиус 135). Положение старой точки больше не сдвигает лампу отдельно от дома. Для остальных изображений без такой привязки точки **Lights** остаются мировыми координатами. Для совместимости `role: light` + `siteId` вне **Lights** даёт обычный фонарь с радиусом 70; источник из **Lights** ближе 2 единиц к нему предотвращает дублирование. Новые источники удобнее делать через **Lights**.

## Как формируется кадр

1. Рисуются фон, вода и земля, здания, стойки факелов, герой, бабочки и птицы.
2. `drawForestLighting` накладывает общую текстуру через `multiply`: базовый холодный тон `#2d3d62`, широкий лунный градиент и локальные цветные пятна. Фактура земли и персонаж получают одно освещение.
3. Светлячки и воздушный дождь рисуются после затемнения. `drawForestLighthouseBeams` добавляет мягкие лучи маяка, `drawForestLightEmitters` — свечение стекла, огонь и небольшие ореолы; `drawBuildingDetails` — локальное тепло размеченных окон и дым из труб. Стекло осветляется полупрозрачным `screen`, поэтому рама и переплёт остаются видимыми.

Шахта уровня 1 получает свет точно в подвесном фонаре справа от входа. У мастерской визуального уровня 2 светятся фонарь и окно слева. Маяк уровня 1 испускает два противоположных луча: полный оборот занимает 36 секунд, направление сжато по вертикали под перспективу карты. Разрушенные варианты и мастерская без нарисованного фонаря не получают свет из работающего варианта. Это декоративный эффект, он не открывает будущие игровые функции маяка.

Луч — общая кешированная текстура 384×144; каждый кадр только два её поворота/масштабирования. Размытие и пересоздание холста в кадре не используются. Свет работает только ночью и плавно следует общей степени ночи. Пауза замораживает угол; «Меньше движения» оставляет статичные лучи без мерцания. Скрытие зданий скрывает также их лампы и лучи, даже если камера видит только конец луча.

Тени домов рисуются до PNG по прозрачности картинки и нижней части её коллизии. Контактная, окружающая и короткая падающая тени запекаются в две кешированные текстуры до 512 px; покадрового размытия нет. Ночью тени мягче, но опора под корнями сохраняется. Это декоративное приближение: направление не пересчитывается от каждого факела. Окна 3–5 уровней светятся только внутри своего полигона, а дым 4–5 использует общий таймер сцены и маленькую кешированную текстуру: перекрывающиеся сегменты образуют непрерывную струю, узкую у трубы и расширяющуюся с рассеиванием выше. Плотность и изгиб плавно движутся вверх; нижний край ограничен выходом трубы. Пауза замораживает дым, reduced motion отключает его. При скрытии здания эффекты также исчезают.

В автоматическом режиме ночь — **19:00–07:00 по часовому поясу профиля**. Переход сглаживается общими часами сцены. Пауза останавливает эти часы, «Меньше движения» убирает мерцание. DEV переопределяет время только для предпросмотра.

Текстура света имеет длинную сторону максимум 768 px и кешируется по составу/параметрам источников; хранится не более четырёх вариантов на сцену. Мерцание меняет небольшие эмиттеры, не пересобирая текстуру каждый кадр. Позиции задаются в мире, поэтому свет не должен ездить за камерой. При скрытии зданий в DEV привязанные источники и обычные точки внутри рамок зданий также скрываются.

## Частые изменения

- **Темнее весь лес:** меняйте базовую заливку и лунный градиент в `lightTexture`. Сравнивайте одинаковый участок в круге и на карте; не добавляйте независимую тёмную заливку в каждом виде.
- **Слишком большой засвет от одного факела:** уменьшайте его `radius`, затем `intensity` в Tiled. Не меняйте общий ночной слой ради одной лампы.
- **Более спокойный огонь:** уменьшайте `flicker`. Форму пламени меняйте в `drawForestLightEmitters`; стойку — в `drawForestLightFixtures`.
- **Новый вид света:** добавьте значение в `WorldLight`, валидацию/defaults в `compileLight`, рисунок и тесты. Новое произвольное свойство Tiled без изменения экспортёра будет отклонено.

## Проверка и ограничения

После правки кода:

```bash
node --test --test-concurrency=1 tests/forest-lighting.test.mjs tests/new-map-scene.test.mjs tests/tiled-world.test.mjs tests/tiled-preview-state.test.mjs
npm run typecheck
```

После правки импорта или свойств проверьте также `tests/tiled-world-watch.test.mjs`. Вручную: день/ночь, пауза, «Меньше движения», `intensity=0`, скрытые здания, панорамирование и повторное открытие мира. Сборки/тесты не измеряют FPS телефона.

Пока нет перекрытия лучей деревьями, физических теней, отражения факелов в воде и освещения от каждого светлячка. Лучи маяка — атмосферное приближение, не физическая трассировка света. `WaterExclusions` исключает водные эффекты, но не блокирует свет. Стойки факелов не добавляют коллизии. Крупные пятна света статичны; мерцают огонь и ближайший ореол. Графика фонаря, запечённая в изображении дома, сама по себе не меняется днём.
