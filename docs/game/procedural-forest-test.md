# Лес, нарисованный кодом

Эксперимент в ветке `work/procedural-forest-test`, основан на `master` v0.6.9 (`214fda6`).

## Открыть

```sh
npm ci
npm run dev:local
```

Перейти на `http://localhost:3000/prototype/procedural-forest`. Маршрут доступен и в сборке ветки, помечен `noindex`. Основной игровой экран и действующие рисунки не меняются.

![Карта, нарисованная кодом](procedural-forest-preview.png)

Превью документации уменьшено до 800×800; размер самой карты и её PNG-экспорта сохраняется.

## Что проверяем

Можно ли передать объём нарисованного леса через Canvas 2D и хранить мир как отдельные элементы. Земля, трава, тропы, вода, берег, деревья, кусты, камни, руины, мост и причал рисуются программно. Исходные PNG, текстуры из сети и генерация изображений не используются. Кроны состоят из освещённых листьев и перекрывающихся масс; корни и тени связывают дерево с землёй.

Карта начинается с 1600×1600 и раскрывается вправо двумя шагами по 800 до 3200×1600. Геометрия троп и берега задана в мировых координатах; растительность зависит от seed и координат ячейки. Размер открытой карты не участвует в генерации объектов. За границей учитываются соседние кроны и тени, поэтому расширение сохраняет существующий рисунок.

Управление: перетаскивание, колесо, два пальца, стрелки, `+`/`−`, `0` для обзора. Инструменты позволяют сажать и убирать объекты. `Enter` применяет выбранный инструмент в центре экрана. Отдельно включаются растительность и сетка участков. PNG сохраняет всю открытую карту вместе с посадками и удалениями, без сетки.

## Где менять

Все модули находятся в `features/world/dev/procedural-forest/`:

| Файл | Ответственность |
|---|---|
| `layout.ts` | Тропы, берег, поляны, выборка типа земли, координатный hash |
| `terrain.ts` | Текстуры земли, песка и воды, объём берега |
| `foliage.ts` | Отдельные деревья и кусты; 24 используемых варианта |
| `objects.ts` | Расстановка, исключения для воды/дорог/построек, выбор объекта |
| `props.ts` | Камни, руины, мост, причал |
| `renderer.ts` | Земля участками 512×512, кэш растительности, порядок глубины |
| `controller.ts` | Камера, жесты, временные правки, расширение и PNG |
| `procedural-forest-preview.tsx` | Экран проверки и соседний CSS module |

Рендер обновляется при изменении камеры, размера окна или данных. Постоянного анимационного цикла нет. Кэши создаются для видимой земли и вариантов объектов, освобождаются при уходе со страницы; смена seed очищает землю. Плотность canvas ограничена DPR 2.

## Границы эксперимента

Это не WFC и не бесконечный генератор рельефа: схема троп, полян и воды нарисована координатами до предела тестового мира. Seed меняет растительность и фактуру на этой схеме. Для бесконечного мира нужен отдельный генератор связной геометрии.

Внешний вид стилизован и не воспроизводит исходный макет точно. Игровые здания, герой, навигация, столкновения, экономика, день/ночь и сохранения основной игры не подключены. Правки редактора сбрасываются при перезагрузке и смене seed. При скрытой растительности редактирование недоступно. Руины, мост и причал пока не выбираются инструментом удаления.

## Проверки

- `npm run typecheck`, `npm run architecture:check`, `npm run lint` — проходят.
- `node --test tests/procedural-forest.test.mjs` — 7/7: детерминизм, расширение, соседние области, ограничения расстановки, сохранение правок при расширении/скрытии слоя, порядок выбора.
- Chromium: открытие, посадка/удаление/сброс, масштаб, слои, оба расширения, смена seed, экспорт PNG 3200×1600; экран 1440×1050 и мобильные 390/320 px, touch и reduced motion. Ошибок страницы и горизонтального переполнения нет.
- Сравнение двух рендеров в native Canvas: исходные 1600×1600 и та же область после расширения до 3200×1600 совпадают попиксельно.

Production-сборки и полный набор тестов игры не запускались: изменение изолировано в новом маршруте, это не выпуск. Деплой не выполнялся.
