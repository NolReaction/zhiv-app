# Игровые профили друзей

В разделе «Люди» нажмите имя человека с принятой личной связью. В карточке открываются уровень дома, число завершённых вылазок, полученные достижения мира и открытые страницы книги находок. Личная подпись остаётся ниже и видна только её владельцу. Посещение самой поляны пока не реализовано; чужая сцена, обустройство и игровые команды не загружаются.

## Доступ и видимость

`GET /api/v1/people/{circleId}/game-profile` требует действующей сессии и активной прямой связи. Общая группа, заявка или знание публичного ID недостаточны. Эффективное исходящее `OFF` человека закрывает и игровой профиль: учитывается сохранённое решение для получателя, в том числе принятое через общую группу. Снятие групповой связи не отменяет сохранённый запрет. Собственное `OFF` посетителя не закрывает согласие второго человека делиться своим профилем.

Чужая, архивированная, удалённая или закрытая связь, а также заблокированный/удалённый владелец дают один ответ `404 GUEST_PROFILE_UNAVAILABLE`. Проверка доступа и выборка данных выполняются в одном SQL-снимке; профиль читается без создания хозяйства, выдачи достижений, изменения прогресса или принятия завершённых заданий. Недействующая сессия даёт `401`. Дополнительные query-параметры не поддерживаются.

Ответ `Cache-Control: no-store` содержит:

- `ownerPublicId`, `circleId`, `user: {publicId, displayName}` — посетитель, связь и владелец карточки;
- `homeLevel`, `completedExplorations` — завершённый прогресс;
- `achievements: [{id, level}]` — только уже полученные ступени разрешённых игровых медалей;
- `collections: {travel: string[], fishing: string[], quarry: string[]}` — известные каталогу открытые ID без количеств;
- `serverTime` — время чтения.

Перечень разрешённых медалей общий для Ktor и DEV: [`guest-profile-policy.json`](../../apps/api/src/main/resources/world/guest-profile-policy.json). Исключены достижения безопасности, отметок, друзей и рекордов тапов, для которых существует отдельная настройка рейтинга. Не передаются балансы, склад, редкие материалы, активные задания, снаряжение, заявки, история действий, время получения медалей, личный статус, данные входа, seed и внутренние таймеры. Покупка рыбы не открывает её страницу: учитывается только сохранённый личный улов. Старые находки из `world_profiles` объединяются с завершёнными коллекциями хозяйства и фильтруются по актуальному каталогу.

Клиент проверяет владельца сессии, связь и адресата ответа. При смене любого из них, закрытии карточки, переходе офлайн или получении `OFF` запрос отменяется; прежние данные не показываются. Карточка не сохраняется в localStorage и не используется офлайн. Пока она открыта, сервер повторно проверяет доступ каждые 30 секунд и при возвращении на вкладку; при видимом фоновом обновлении снимок сохраняется, чтобы не закрывать страницы книги; скрытие вкладки, отключение сети и любой отказ очищают его. Изменение настройки другим устройством может стать видимым только при следующем таком запросе.
