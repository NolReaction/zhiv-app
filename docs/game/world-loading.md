# Загрузка мира и кэш

Первый кадр больше не ждёт многомегабайтную карту и подробную домашнюю текстуру. PNG остаются исходниками; рабочие WebP-файлы находятся в `public/world/runtime`, их адреса — в `features/world/runtime-art.json`.

| Изображение | Размер | Загрузка |
|---|---:|---|
| Домик, 256×256 | 27.7 KiB | Предзагрузка из HTML, первый кадр и Мохлик |
| Обзор карты, 384×384 | 49.3 KiB | Целая карта при входе в мир |
| Полная карта, 1254×1254 | 830.7 KiB | Фоновая замена обзора |
| Домашние детали, 1254×1254 | 552.8 KiB | После полной карты, с прежним плавным краем |
| Разбитая лодка, ширина 512 | 33.2 KiB | Отдельно, без блокировки карты |

Оба вида используют общий загрузчик и одни завершённые изображения. Карта сначала появляется целиком; частичная полоса PNG через CSS больше не видна. Детали загружаются с низким приоритетом, не блокируя персонажа и управление. Неудачные загрузки удаляются из памяти; зависшие запросы отменяются по таймауту. Возвращение сети или фокуса повторяет загрузку деталей. Закрытый или приостановленный вид не запускает новую анимацию после завершения запроса.

Имена рабочих изображений содержат SHA-256 содержимого. HTTP-кэш получает `max-age=31536000, immutable`; изменение рисунка автоматически меняет URL. Сервис-воркер сохраняет также ленивые игровые JS-модули в отдельном кэше `zhiv-assets-v1`, переживающем обновление оболочки. Кэш ограничен 96 ответами; заполненное или недоступное хранилище не блокирует успешный сетевой ответ. Ошибки, HTML и приватные ответы не сохраняются как игровые ресурсы. API и админка остаются сетевыми.

Модули мира подгружаются после появления главного экрана. Уже скачанные ресурсы доступны без сети, пока браузер не очистил кэш. Первый запуск без ранее загруженных файлов требует подключения.

Для обновления копий: `node scripts/prepare-world-assets.mjs`. Используется закреплённая версия Sharp. Вместе с изображениями следует коммитить обновлённый JSON. Исходные PNG и координаты объектов не меняются. Тесты проверяют размеры, бюджет первых кадров, соответствие хэшей, работоспособность сцены при задержке подробных файлов и кэш после смены версии оболочки.

Кнопка «Найти Мохлика» и клавиша Home используют текущую позицию персонажа; при рыбалке берётся его положение на маршруте. Камера приближает героя с учётом границ карты.
