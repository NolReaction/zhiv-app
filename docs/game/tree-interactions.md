# Отклик нарисованных деревьев

В экспериментальной ветке `water` нажатие на крону слегка колышет её рисунок, выпускает семь падающих листьев и играет короткий тихий шелест. Деревья используют исходный фон; области эффекта размечаются в отдельной папке слоёв **TreeInteractions → Crowns** в Tiled.

## Геометрия и жесты

Источник — полигоны внутри папки **TreeInteractions** из [forest.tmj](../../world/tiled/forest.tmj). В объектный слой **Crowns** добавлены 15 готовых стартовых зон: их контуры отдельно скопированы из прежних крон и теперь редактируются независимо. Объекты **Occluders** сохраняют своё назначение — перекрытие персонажей и зданий; эффект деревьев не читает их список и не требует определённого суффикса имени.

Точка проверяется по точному, в том числе вогнутому, контуру зоны. При наложении выбирается зона с большим `frontY`; это приоритет контакта, а не граница перекрытия персонажей. Неразмеченные участки фонового рисунка пока не реагируют. Пустая папка отключает отклик всех деревьев.

`map-engine.ts` принимает только завершённый одиночный тап. Видимые герои, здания, игровые объекты и явные маркеры сохраняют приоритет. Drag, pinch, правая кнопка, отмена и потеря захвата не запускают эффект. Тап по кроне во время её паузы повторения поглощается и не обращается к скрытому герою под ней.

## Разметить дерево вручную

1. Откройте `world/tiled/forest.tiled-project`, затем `forest.tmj`. Раскройте папку **TreeInteractions** и выберите объектный слой **Crowns**; зоны выделены фиолетовым. Фон **Terrain** удобно заблокировать, а **Occluders** скрыть глазиком.
2. Для готовой зоны выберите **Select Objects (S)** и двигайте весь полигон; **Edit Polygons (O)** меняет отдельные вершины. Чтобы убрать отклик конкретного дерева, удалите его объект из **Crowns**.
3. Для нового дерева выберите **Insert Polygon (P)** и обведите именно листву на рисунке, обходя ствол, землю и соседние постройки. Замкните контур. Можно также продублировать готовую зону и изменить вершины. Полигон должен иметь хотя бы три вершины и не пересекать сам себя.
4. В **Properties** задайте уникальный **Name**, например `river-oak`. Этого достаточно: название не обязано заканчиваться на `-tree`, `-canopy` или `-touch`, пользовательское свойство `role` не нужно. Необязательный **Class** (в старых версиях — **Type**) может оставаться пустым или быть `TreeInteraction`, как у стартовых зон.
5. Сохраните карту и из корня репозитория выполните:

   ```bash
   npm run world:export && npm run world:check
   ```

6. Проверьте одиночный тап по кроне в основной большой карте: движение, место появления листьев и тихий шелест. Если экспорт обновил метаданные Tiled, закройте и заново откройте карту перед следующей правкой. Сохраните в Git исходную карту и автоматически обновлённый `forest.generated.json`; экспорт вручную не редактируйте.

| Поле | Тип | Назначение |
| --- | --- | --- |
| **Name** | Имя объекта | Уникальный стабильный ID зоны; строчные латинские буквы, цифры, дефис или подчёркивание |
| **Class / Type** | Класс объекта, необязательно | Пустое значение или `TreeInteraction` |
| `frontY` | float или int, необязательно | Смещение от Y объекта: больший итоговый Y выигрывает при наложении зон. Без свойства используется нижняя точка полигона |
| `siteId` + `level` | string + int, необязательно вместе | Зона активна только при выбранном визуальном уровне существующего здания; обычным деревьям эта пара не нужна |

Координаты вводятся в единицах карты **1254 × 1254**, а не исходного PNG. Например, объект с `y: 425` и `frontY: 105` получает приоритет **530**. При обычной разметке оставляйте `frontY` незаданным. При желании добавляйте другие объектные слои внутри папки **TreeInteractions** для группировки деревьев. Изменение зоны влияет на попадание, колебание фактуры и место рождения листьев; видимость зданий, препятствия и маршруты задаются своими слоями. Полный справочник — [редактор Tiled](tiled-editor.md#зоны-нажатия-на-деревья).

## Состояние и рисунок

- [forest-tree-interactions.ts](../../features/world/environment/trees/forest-tree-interactions.ts): локальное состояние текущей камеры, точная геометрия, паузы 350 мс между контактами и 700 мс для одной кроны, максимум шесть активных крон и 40 листьев.
- [forest-tree-interactions-painter.ts](../../features/world/environment/trees/forest-tree-interactions-painter.ts): внутренние пиксели кроны смещаются максимум на 1,4 единицы мира с затухающим колебанием; внешний контур и ствол остаются на месте. Используется текущий mip фона, локальная переиспользуемая поверхность 512×512 и кэш мягких масок, без чтения пикселей и копий всей карты.
- Листья рождаются внутри нажатой кроны, вращаются, переворачиваются, плавно падают и исчезают через 2,5–3,8 секунды. Рисование не двигает часы и не создаёт звук. Крона рисуется сразу после фона, листья — до освещения сцены.
- `new-map-scene.ts` продвигает эффект только часами активного владельца. Закрытие, скрытие, смена аккаунта/геометрии и reduced motion убирают незавершённые частицы. В reduced motion тап допускает только звук. Косметика не сохраняется на сервер, не меняет ресурсы и не влияет на путь жителей.

`world-audio-controller.ts` отправляет `action.tree.rustle` только для принятого контакта. Шелест использует два существующих семпла, уровень −16 dB, мягкую панораму и канал «Постройки и действия». Зум не повышает громкость, декодирование старше 200 мс не догоняет действие. Подробности — [звуковая система](audio-system.md).

## Проверка

`forest-tree-interactions.test.mjs` проверяет настоящие зоны, независимость от Occluders, границы, верхний силуэт, рождение и предел частиц, паузы, reduced motion, чистоту рисования и размер кэша. `new-map-scene.test.mjs` проверяет реальные pointer-жесты, видимость и режим без движения. `world-tree-touch-audio.test.mjs` и общий `audio-runtime.test.mjs` проверяют фиксированную громкость, паузу повторения и отмену запоздавшего звука. В браузере проверять дерево крупным планом и на телефоне, день/ночь, drag и повторные тапы; после окончания эффекта фон должен совпадать с неподвижным оригиналом.
