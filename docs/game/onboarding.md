# Знакомство с лесом Мохлика

Первое знакомство показывает, где находятся основные действия игры. При первом открытии большой карты после загрузки мира, экономики и самой сцены Мохлик предлагает пройти короткую инструкцию или пропустить её. До выбора инструкция не начинается. При сообщении «Полянка на паузе» обучение уступает место восстановлению управления; после продолжения игры показ снова доступен. Вход в аккаунт и загрузочная заставка остаются отдельными экранами.

## Экраны инструкции

| Шаг | Что объясняет |
|---|---|
| Полянка | Здесь живёт Мохлик; карту можно перемещать и приближать, а здания открываются нажатием. |
| Мой Мохлик | Кнопка профиля показывает героя, его уровень, настроение и другие сведения. |
| Кладовая | Здесь хранятся материалы и находки; вместимость ограничена. |
| В путь | Вылазки помогают получать ресурсы; направления и доступность зависят от текущего развития. |
| Справка | Кнопка ⓘ открывает ответы, поиск и подсказки по текущей ситуации. |

Мохлик нарисован существующим Canvas-спрайтом из [pixel-sprite.ts](../../features/mochlik/pixel-sprite.ts), тем же, что используется в мире. Оформление экранов следует лесной палитре приложения. Рамка выделяет соответствующую кнопку поверх карты и пересчитывается при изменении размеров экрана; это указатель на действующий интерфейс, а не отдельная копия его кнопок.

Кнопка «Дальше» и стрелка назад переключают информационные экраны. Инструкция не отправляет игровых команд, не тратит валюту или предметы, не запускает производство, стройку и вылазки. Выделенные элементы карты объясняются в тексте; взаимодействовать с ними можно после закрытия инструкции. Кнопка «Начать играть» завершает инструкцию и возвращает игрока к карте.

## Прогресс и повтор

Выбор пропуска и завершённая инструкция запоминаются в браузере отдельно для каждого `ownerPublicId`. Формат сохранения имеет версию 1. Начатая инструкция сохраняет стабильный ID текущего шага: при следующем открытии карты можно продолжить с него. Изменение порядка экранов не должно превращать сохранённый ID в другой шаг.

Escape и закрытие приостанавливают показ, сохраняя текущий шаг; это не пропуск и не завершение. Повтор доступен через меню «Ещё» и игровую справку. Повторный запуск позволяет заново пройти экраны независимо от прежнего выбора.

Прогресс инструкции хранится локально и не синхронизируется с сервером. Другой браузер или очистка его данных снова приведут к первому предложению. При недоступном хранилище текущий показ остаётся работоспособным в памяти. Смена аккаунта не переносит шаги между владельцами.

## Где менять

| Ответственность | Источник |
|---|---|
| Тексты пяти шагов, стабильные ID и формат прогресса | [domain/world-onboarding.ts](../../features/world/domain/world-onboarding.ts) |
| Восстановление, сохранение и пауза показа | [state/use-world-onboarding.ts](../../features/world/state/use-world-onboarding.ts), [state/world-onboarding-storage.ts](../../features/world/state/world-onboarding-storage.ts) |
| Приветствие, информационные экраны, ожидание сцены, портрет и подсветка | [ui/onboarding/](../../features/world/ui/onboarding/) |
| Момент открытия, готовность данных, повтор из «Ещё», связь со справкой | [world-view.tsx](../../features/world/world-view.tsx) |
| Повтор из справки | [world-help.tsx](../../features/world/ui/help/world-help.tsx) |
| Персонаж на экранах | [pixel-sprite.ts](../../features/mochlik/pixel-sprite.ts) |

Сохраняйте ID шагов и привязку к владельцу при правке текстов. Подсветка использует DOM-кнопки HUD; геометрия зданий, Canvas-движок и Tiled-карта для этого этапа не меняются. Общий внешний диалог карты и диалог инструкции должны закрываться раздельно. После закрытия инструкции фокус возвращается к доступной кнопке карты; запуск из справки не должен возвращать фокус в уже закрытый лист справки.

Проверьте первый вход, явный пропуск, завершение, возврат назад, Escape, повтор из обоих мест и продолжение после перезагрузки. Дополнительно проверьте смену аккаунта, недоступное хранилище, узкий и широкий экран, поворот телефона, клавиатуру и reduced motion. Порядок общих проверок — в [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Отдельная ветка и обновление основы

Обучение разрабатывается в `work/0.6.8-onboarding`, созданной от `work/0.6.8` на `cfff61f` — исправлении включения DEV-инструментов при локальном запуске. Основная разработка 0.6.8 может продолжаться параллельно. Новые изменения основы вливаются в ветку обучения обычным merge; обратное объединение выполняется отдельным согласованным этапом.

Перед обновлением проверьте текущую ветку и рабочие файлы. Выполняйте merge только находясь в `work/0.6.8-onboarding` и сохранив незавершённые правки:

```sh
git branch --show-current
git status --short
git fetch origin refs/heads/work/0.6.8:refs/remotes/origin/work/0.6.8
git log --oneline HEAD..origin/work/0.6.8
git merge --no-edit origin/work/0.6.8
```

Разрешите возможные конфликты в ветке обучения и выполните проверки затронутых частей. История сохраняется обычными новыми коммитами; force push и слияние обучения обратно в `work/0.6.8` в этот порядок не входят.

## Следующие этапы

История игры, разговоры по ходу развития, подсветка конкретных зданий и обучение через реальные действия планируются отдельно. Текущий этап — добровольное знакомство с основными экранами. Будущие шаги должны опираться на подтверждённое состояние игры и доступные игроку действия.
