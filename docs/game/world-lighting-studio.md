# Студия света: практическое руководство

[Навигация по документации](../README.md) · [Свет и тени: устройство и Tiled](world-lighting.md) · [Мастерская зданий](building-workbench.md)

Студия редактирует **разметку света поверх нарисованной карты**: объёмы, принимающую землю и источники. Это DEV-инструмент, который не меняет игровой аккаунт. Контур дома в студии — условный объём для расчёта тени; он не является самим рисунком дома.

## Начать работу

1. На нужной Git-ветке запустите локальный проект через `npm run dev:local`. Если карта открыта в Tiled, сначала сохраните её и закройте: студия будет записывать тот же файл.
2. Откройте мир и нажмите **Студия** рядом с **DEV**. Студия включает черновик, тени и ночной предпросмотр; большую карту открывает при необходимости.
3. Выберите элемент в **Объектах**. Двойной щелчок по строке или **Найти · F** направляет камеру к нему; **Показать выбранное** находится в разделе **Папки и выделение**. На компьютере панели занимают место по содержимому: справа в одной позиции открываются свойства, вид или история, а не несколько перекрывающих друг друга колонок. На телефоне используйте вкладки; **Свернуть** освобождает карту на любом экране.
4. В **Свойствах** настройте контур, высоту или свет. Имя, папка и блокировка собраны в сворачиваемом разделе **Имя, папка и защита**; **F2** автоматически раскрывает его и выбирает имя для ввода. Технический ID и создание своей папки находятся глубже, в **Имя, папки и ID**.
5. В **Виде и легенде** сравните день и ночь, включённые и выключенные рассчитанные тени, черновик и сохранённую версию. Проверьте близкий вид и общий обзор.
6. Дождитесь **Проект сохранён**. Скачайте полный JSON, если нужна переносимая копия. Проверьте `npm run world:check` и сохраняйте в Git оба файла: `world/tiled/forest.tmj` и `features/world/tiled/forest.generated.json`.

## Поиск по смыслу

Нажмите **Поиск** или **Ctrl/Cmd+K**. Поиск работает в русской и английской раскладке по физической клавише K и ищет сразу в двух группах:

- **Настройки и действия**: «яркость», «радиус», «мерцание», «мягкость», «производительность», «откат». Переход к настройке открывает нужную панель и вложенные разделы, прокручивает к полю и передаёт ему фокус. Для свойств света сначала выберите источник; для свойств тени — объём. Поиск объясняет это возле недоступного перехода.
- **Объекты**: имя, ID, папка и смысловые слова. Например, «яркость» находит источники, «исключение» — поверхности земли, «свечение» — источники типа glow, даже переименованные. Можно вводить несколько слов в любом порядке; е/ё равнозначны. Фильтры «Свет», «Объёмы», «Земля» ограничивают только список объектов.

«Добавить свечение/фонарь/факел» выбирает инструмент размещения: источник появится после нажатия на карту. Сам поиск не меняет существующие значения. История, Undo/Redo, исходные ID и автосохранение используют прежние механизмы.

В **Виде и легенде** основные настройки разделены на **Освещение** и **Разметку**; объяснение цветов свёрнуто отдельно. Панель сохранения остаётся компактной внизу слева, а резервные копии и ручной перенос в Tiled раскрываются по запросу.

## Что означают контуры

| Цвет | Элемент | Как размечать |
| --- | --- | --- |
| Фиолетовый | Объём `ShadowCaster` — отбрасывает тень | Горизонтальная проекция условного объёма на землю, затем его основание и высота |
| Синий | Поверхность `ShadowReceiver` — принимает тени | Видимая земля, на которую может падать тень; для обычной земли высота **0** |
| Золотистый | Источник `Lights` | Центр лампы или пламени, высота источника и радиус его света |

**Синие участки — принимающая земля, а не части дома и не препятствия для ходьбы.** Соседние поверхности одной высоты работают как общая принимающая область. Разделение на «запад», «передний план» и «восток» удобно для обхода объектов и редактирования, оно не создаёт разные типы света.

Объём дома не нужно обводить по крыше на рисунке: его основной контур лежит у основания, а высота поднимает объём вверх. Ствол дерева — маленький контур у корней с основанием 0; крона — более широкий контур над той же опорой с положительным основанием. Включите каркас, чтобы видеть эту разницу.

PNG, положение нарисованного здания, игровые коллизии, `Occluders` и `TreeInteractions` студия не изменяет. Если нужно перенести сам дом или заменить его изображение, используйте [мастерскую зданий](building-workbench.md) и Tiled.

### Пример: вся поляна обведена вместе с домом

Удобный вариант — **одна поверхность поляны или всей карты с высотой 0 и внутренним исключением под видимым домом**. Внешний синий контур определяет землю, а внутренний вырез убирает из этой поверхности участки стены и крыши на рисунке. Сам PNG остаётся прежним.

Без исключения широкий контур означает: «вся эта область считается землёй на высоте 0». Для быстрого дневного предпросмотра это допустимо: направленная тень рисуется до отдельного PNG дома, который её закрывает. Ночью маски ламп накладываются поверх готовой сцены, без выбора видимой плоскости. Поэтому наземная тень может оказаться прямо на изображении крыши. Исключение предотвращает такое вычитание света на пикселях дома, но **не создаёт физическое освещение стен или крыши**: общий ночной тон и световое пятно фонаря остаются.

Практический порядок:

1. Оставьте **Высоту поверхности = 0**.
2. Выберите поверхность и раскройте **Контур поверхности**. Нажмите **Добавить исключение**: появится маленький начальный вырез внутри поверхности, уже выбранный для работы инструментом **P**. Если для него нет свободного места, студия покажет причину; проверьте границы и уже существующие вырезы.
3. В **Редактируемом контуре** выберите **Исключение N**, если нужно вернуться к нему позже. Его граница показана пунктиром. Инструментом **Контур · P** подведите точки к видимому силуэту дома; нажатие на ребро добавляет вершину. Стены и крышу вычитайте; нарисованный участок грунта оставьте принимающей землёй. Прозрачная рамка PNG не является стеной.
4. Чтобы снова менять внешнюю границу земли, выберите **Внешний контур**. **G** переносит всю поверхность вместе с её вырезами; **Удалить исключение** убирает выбранный вырез и возвращает приём теней в этой области.
5. Проверьте все используемые уровни дома: силуэт меняется. Привязку отдельных поверхностей к `siteId`/`level` задавайте в Tiled; папка «Уровень 2» сама такой привязки не создаёт.
6. Включите показ всей разметки и проверьте пересечения: если старый receiver тоже покрывает дом, вырежьте дом и из него либо уберите лишнюю принимающую поверхность. Исключение действует **только в своей поверхности**. Кнопка глаза лишь скрывает контур и не отключает его влияние на тени.
7. Включите ночь и посмотрите тени от нескольких ламп. Если одна лампа подсвечивает тень другой, это ожидаемо: маски источников рассчитываются отдельно.

У поверхности может быть **до 16 внутренних исключений**, по 3–64 вершины каждое. Они должны полностью лежать внутри внешнего контура, не касаться его, не пересекаться и не касаться друг друга. Вырез внутри другого выреза недопустим. Контуры могут быть вогнутыми, но без самопересечений, совпадающих вершин или нулевой площади. Неверная правка оставляет последнюю допустимую форму.

Если дом касается внешней границы земли, замкнутый вырез вокруг него создать нельзя: измените внешний контур, сделайте в нём выемку или используйте несколько поверхностей. Не соединяйте внешний обход и вырез повторяющимся ребром — это не заменяет внутреннее исключение.

Объекты, уже нарисованные внутри фонового изображения, не закрываются отдельным проходом PNG зданий: дневная тень также может лечь поверх них. Их видимые силуэты тоже исключайте из принимающей земли. Нарисованные в исходной картинке тени и освещение остаются на месте, даже когда направление рассчитанного света меняется.

### Поднятые поверхности

Число высоты у receiver задаёт **горизонтальную плоскость**. Оно не превращает синий контур в крышу, не меняет наклон и не заставляет рендер выбирать верхнюю видимую поверхность. При пересечении земли и поднятой поверхности обе участвуют в масках; направленные тени по-прежнему рисуются до зданий. Для рабочего участка используйте землю с высотой 0. Разметка крыш, стен и самозатенение зданий требуют дальнейшей доработки рендера.

## Имена, ID и папки

В **Свойствах → Имя элемента** можно задать понятное название, в том числе по-русски, например «Земля перед домом» или «Крона северного дерева». **F2** выделяет имя для замены. **Enter** или выход из поля подтверждает ввод, **Esc** отменяет текущий ввод. Пустое имя возвращает автоматическую подпись. **Ctrl/Cmd+S** подтверждает введённое имя перед запросом сохранения.

**ID** — отдельный технический идентификатор. Он остаётся прежним при переименовании и переносе, чтобы сохранялись связи, патчи и история. Изменение имени элемента также не переименовывает файл PNG или JSON. Для замены имени PNG и его ссылки используйте Tiled/каталог ассетов, а не поле имени студии.

Папки по умолчанию: **Здания → название → уровень**, **Деревья → дерево → ствол/крона**, **Камни**, **Свои объёмы**, **Поверхности земли**, **Источники света**. Исключённые элементы находятся в **Удалённых / выключенных**.

Перенести живой элемент можно двумя способами:

- В **Свойствах → Папка в списке** выбрать существующую папку. **Автоматическая папка** возвращает группировку по назначению элемента.
- Перетащить строку элемента на заголовок нужной папки в **Объектах**. Целевая папка раскрывается, чтобы был виден результат. На телефоне удобнее пользоваться полем в свойствах.

Для своего раздела раскройте **Имя, папки и ID → Новая папка**, заполните **Путь новой папки** и нажмите **Создать и перенести**. Например, `Поляна/Дом` создаёт вложенный путь и помещает туда выбранный элемент. Пользовательская папка существует, пока содержит элементы; пустая исчезает из дерева. Автоматические папки доступны как назначения для переноса.

Имя — до 128 символов; пользовательский путь — до 8 сегментов по 64 символа, общая сохранённая строка папки — до 256. Разделитель вложения — `/`; сегменты `.` и `..`, пустые сегменты и управляющие символы не принимаются.

**Папки организуют только список студии.** Перенос объёма в «Дом → Уровень 2» не связывает его с уровнем 2, не меняет координаты и не переносит физический объектный слой Tiled. Условия `siteId`/`level` остаются прежними. Имя и папка хранятся в свойствах `studioName` и `studioFolder`, проходят через черновик, JSON, Tiled и generated-экспорт; их изменение участвует в общей Undo/Redo.

Поиск учитывает имя, ID и названия родительских папок. Фильтры **Все / Объёмы / Свет / Земля / Правки** сохраняют дерево. **Показать выбранное** очищает поиск и фильтр и раскрывает путь выбранного объекта. После переименования или переноса выбранный элемент показывается в новом месте, даже если раньше действовал фильтр.

## Несколько элементов, блокировка и видимость

Для работы с группой используйте **Ctrl/Cmd+щелчок** по строкам или объектам на карте: щелчок добавляет элемент к выбору или убирает его. **Shift+щелчок** в списке выбирает диапазон между строками. На телефоне используйте флажки строк. **Выделить видимые / Ctrl/Cmd+A** выбирает показанные живые элементы списка: поиск, фильтр и раскрытые папки ограничивают выбор. Удалённые и выключенные записи в этот выбор не входят.

При нескольких элементах появляется **Выбрано N** с общими действиями: перенос в папку, показать/скрыть разметку, заблокировать/разблокировать, дублировать и удалить. Перетаскивание выбранной строки на папку переносит всю группу. **F** при выборе группы показывает область всей группы. В инструменте **G** перетаскивание уже выбранного элемента на карте перемещает выбранную группу.

Две кнопки строки помогают работать с плотной разметкой:

| Кнопка | Что меняется |
| --- | --- |
| Глаз — **Скрыть / Показать разметку** | Скрываются только направляющие этого элемента на карте. Рисунок и рассчитанный свет остаются; элемент можно найти в списке |
| Замок — **Заблокировать / Разблокировать** | Элемент можно выбрать и рассмотреть, но случайная правка не изменит его |

Скрытые контуры не выбираются щелчком по карте; выбирайте их в списке и включайте глаз для перетаскивания точек. Скрытие разметки источника не выключает фонарь: для отключения света используйте **Источник включён** в его свойствах.

Глаз и замок — настройки текущего браузера. Они сохраняются при повторном открытии и дополнительно входят в полный резервный JSON как настройки редактора; Tiled, generated-экспорт, patch и история Undo/Redo их не содержат. Чтобы вернуть их, нажмите соответствующие кнопки. Если хотя бы один выбранный элемент заблокирован, общая правка отклоняется целиком: сначала разблокируйте его или уберите из выбора. Undo/Redo уже выполненного действия допускается и после блокировки.

Массовую правку проверяйте по счётчику **Выбрано N**, особенно после изменения поиска. Дублирование создаёт новые ID, сохраняет имена, папки и условия уровней и выделяет полученные копии. Контуры и их исключения копируются вместе. Копия обычно сдвигается рядом с оригиналом; у контура размером со всю карту свободного места для сдвига может не быть.

## Редактировать и удалять

**Объекты → Добавить элемент** создаёт объём тени или поверхность земли в центре свободной части карты. Начальный прямоугольник нужно подогнать по месту. У нового объёма нет автоматической привязки к зданию; условия существующих элементов сохраняются, новые условия задавайте в Tiled.

1. Выберите элемент в дереве или инструментом **Выбрать · V** на карте. **Показать уровень N** в свойствах объёма здания включает его рисунок в DEV; аккаунт не меняется. На карте выбираются объёмы активного состояния здания.
2. **Двигать · G** переносит весь контур. **Контур · P** перемещает пронумерованные точки; координаты можно ввести через **Выбранная точка**, **X точки / Y точки**. **Шаг** включает привязку: нет, 1, 5 или 10 единиц карты.
3. В **P** нажмите на ребро выбранного контура, чтобы добавить точку и сразу потянуть её. **Добавить точку** в свойствах делит следующее ребро пополам; **Удалить точку** удаляет выбранную вершину. Допустимы 3–64 вершины внутри карты, без совпадений, самопересечений и нулевой площади. Недопустимая правка оставляет последнюю верную форму и показывает причину.
4. **Высота · H** меняет объём ручками на карте. **Высота** — толщина вверх от **Основания**, **Верх** — их сумма. Основание 20 и высота 50 дают верх 70. Это единицы карты, не метры; размер PNG не меняется. Толщина не больше 300, верх не больше 400. У поверхности есть только высота её плоскости, 0–300.
5. В разделе **Тень** задаются плотность 0–1 и мягкость 0–12. Высоту, форму и мягкость проверяйте с видимым результатом, а не только по каркасу.

**Удалить объём тени** убирает препятствие для света, сам дом или дерево остаётся. **Удалить поверхность** убирает принимающую область, рисунок земли остаётся. Исходная удалённая геометрия появляется в **Удалённых / выключенных**, где её можно восстановить до записи проекта. После записи она уже отсутствует в исходнике; Undo текущей сессии может вернуть её и снова сохранить.

По умолчанию виден выбранный контур. В **Виде и легенде** можно показать все, только выбранный или скрыть разметку, отдельно включить объёмы, поверхности и каркас. Скрытие направляющих не удаляет элементы и не выключает их влияние на свет.

### Источники

Для нового источника выберите **Фонарь / Факел / Свечение** в **Добавить элемент**, затем нажмите на карту инструментом **Источник · L**. X/Y — центр лампы или пламени; её опора для теней находится на `y + height`. В свойствах задаются включение, яркость 0–2, радиус больше 0 и не больше 500, цвет, высота 1–200 и мерцание 0–1. Без указанной высоты используется подбор по типу/привязке источника.

**G** перемещает источник, **H** меняет высоту; ручка радиуса меняет световое пятно. Перенос лампы, привязанной к зданию, в том числе ввод X/Y, включает `manualPosition=true`: свет перестаёт следовать стеклу рисунка здания. **Дублировать** создаёт отдельный источник с новым ID и ручной позицией.

Удаление исходного источника выключает его через `enabled=false`, сохраняя запись в **Удалённых / выключенных**. Ещё не записанный новый источник удаляется целиком. Для исходной лампы используйте выключение: удаление её записи через сырой JSON может вернуть автоматически добавляемый свет здания. Привязанная лампа пока не перекрывается объёмами своего здания; это приближение наружного фонаря, остальные объекты перекрывают её свет.

## Камера, клавиши и отмена

Перетаскивание пустого места или инструмент **Камера** перемещает карту; **Space** временно включает камеру поверх текущего инструмента. Колесо мыши и жест двумя пальцами меняют масштаб. Если второй палец появляется во время правки, правка отменяется и начинается жест камеры.

Клавиши определяются по месту на клавиатуре, поэтому **русскую раскладку переключать не нужно**. Например, выбор работает на **V / М**, контур — **P / З**, отмена — **Ctrl+Z / Ctrl+Я**. **Ctrl** на Windows/Linux соответствует **Cmd** на Mac. Подсказку можно открыть кнопкой **Клавиши · ?**.

| Действие при фокусе на карте | Клавиши |
| --- | --- |
| Выбрать / двигать / контур / высота / новый источник | **V / G / P / H / L**; в русской раскладке **М / П / З / Р / Д** |
| Временно перемещать камеру | Удерживать **Space** |
| Найти выбранный элемент или всю группу | **F / А** |
| Переименовать выбранный элемент | **F2** |
| Дублировать выбранный объём, поверхность или источник | **Ctrl/Cmd+D** |
| Выделить показанные строки списка | **Ctrl/Cmd+A** |
| Отменить | **Ctrl/Cmd+Z** |
| Повторить | **Ctrl/Cmd+Shift+Z** или **Ctrl/Cmd+Y** |
| Открыть подсказку клавиш | **?** |
| Открыть историю действий | **Ctrl/Cmd+Shift+H** |
| В P удалить выбранную вершину; без вершины — выбранное исключение; иначе — выбранные элементы | **Delete** или **Backspace** |
| Сохранить черновик и запросить запись проекта | **Ctrl/Cmd+S** |
| Отменить ввод или жест; выйти из размещения света; иначе закрыть студию | **Esc** |
| Сдвинуть вершину в P, контур в G или источник на шаг привязки; без привязки — на 1 | **Стрелки** |
| Сдвинуть на 10 единиц | **Shift+стрелки** |

При вводе в полях буквы инструментов, стрелки, Delete и **Ctrl/Cmd+Z** остаются за полем, а **Ctrl/Cmd+A** выделяет его содержимое. В числовом поле **Enter** завершает ввод, **Esc** отменяет текущую правку поля. **Ctrl/Cmd+S** сначала подтверждает ввод имени, затем сохраняет работу.

Для **?** нажмите **Shift** вместе с клавишей **/?** английской раскладки. В русской раскладке эта же физическая клавиша обычно выводит запятую, но открывает подсказку студии.

Кнопки **Назад / Вперёд** показывают, какое действие будет отменено или возвращено. **История** открывает список выполненных и отменённых действий. Объёмы, поверхности, источники, имена, папки и пакетные правки используют общую историю. Перетаскивание или изменение числового поля отменяется как одно действие; одна пакетная операция также не требует отменять каждый элемент отдельно. История до 100 действий существует только в текущей сессии. После перезагрузки браузера сохранённая разметка остаётся, но старой истории уже нет.

**Сбросить** выбранный элемент возвращает его к последней подтверждённой версии проекта. После автосохранения эта версия уже содержит правку; для возврата к более ранней используйте Undo текущей сессии либо Git.

## Как сохраняется работа

В студии видны **два независимых статуса**:

| Статус | Что он подтверждает |
| --- | --- |
| Черновик браузера сохранён | Завершённая правка записана в `localStorage` текущего браузера; это ещё не запись файлов проекта |
| Проект сохранён | Локальный dev-сервер подтвердил запись и `.tmj`, и `forest.generated.json` |

Черновик записывается после завершения жеста и восстанавливается в этом же браузере на совместимой исходной разметке. При ошибке хранилища нажмите **Повторить сохранение черновика** и скачайте JSON. После полной перезагрузки страницы Undo/Redo начинается заново.

На локальном `dev:local` или `dev:lan` после правки и паузы около **800 мс** студия автоматически пишет `world/tiled/forest.tmj` и `features/world/tiled/forest.generated.json`. Запросы последовательны: правки во время записи сохраняются следующим запросом. **Сохранить сейчас / Ctrl/Cmd+S** завершает жест, сохраняет черновик и запрашивает немедленную запись. **Автоматически сохранять в проект** ставит запись файлов на паузу; черновик и ручное сохранение продолжают работать.

**`dev:lan` предназначен для доверенной сети.** У студии нет отдельной авторизации: устройство с доступом к dev-серверу может отправлять команды сохранения от собственного клиента. Проверки приватного Host и точного Origin защищают от чужих сайтов и DNS rebinding в браузере, но не удостоверяют пользователя LAN. Для работы только на компьютере используйте `dev:local`; не открывайте dev-сервер в интернет или общей недоверенной сети. В production endpoint отсутствует.

Сервер принимает несжатый JSON до 2 МБ и ждёт его загрузку не больше 10 секунд. Медленная загрузка не занимает очередь записи файлов. Одновременно допускаются 8 запросов, включая загрузку и ожидание записи; при превышении сервер возвращает `429` с `Retry-After: 1`. Превышение размера даёт `413`, времени — `408`, неверный формат/сжатие — `415`. В этих случаях черновик остаётся в браузере; **Повторить сохранение** отправляет прежнюю операцию без повторного применения. До компиляции проверяются существующие пределы patch: 128 объёмов, 32 поверхности, 128 источников, до 64 вершин контура и 16 исключений поверхности.

В Sites и при недоступном локальном endpoint остаются черновик и JSON. Студия не делает Git-коммит, push, деплой или запись аккаунта. После работы откройте Tiled заново: его старая открытая копия карты может затереть записанный студией файл.

В Next/webpack запись только света, объёмов или поверхностей принимается на границе данных карты и не перезапускает игру, DEV и открытую студию. Выбор, инструмент, шаг, Undo/Redo и неподтверждённое сохранение остаются в текущей сессии; проверка файлов дожидается ответа собственного POST. Внешняя версия принимается автоматически только без несохранённых правок и активного жеста; иначе возникает конфликт. Изменения остальных частей карты и работа `world:watch` вне подключённой студии используют обычное обновление модулей, чтобы перестроить навигацию и прочую геометрию.

### Конфликт с Tiled или другим окном

При **В проекте есть другие правки** автозапись останавливается, черновик остаётся. Сначала скачайте **полный JSON**, затем сверяйте его с актуальной картой. **Проверить и повторить** сверяет ревизию и данные заново; кнопка не принуждает сервер перезаписывать конфликт.

**Загрузить версию проекта → Скачать копию и загрузить проект** сначала скачивает текущую работу или исходный текст непрочитанного черновика и только потом читает свежую версию. Черновик заменяется после успешного чтения и проверки; ошибка или новые правки во время запроса сохраняют его на месте. **Оставить черновик** отменяет загрузку. Автоматического слияния разных версий нет.

При сетевой ошибке черновик также остаётся. Повтор запроса не применяет одну операцию дважды. Детали проверки ревизий и записи файлов описаны в [технической документации](world-lighting.md#сохранение-файлов-проекта).

## JSON и ручное применение

| Кнопка | Файл | Для чего |
| --- | --- | --- |
| **Скачать JSON** | `world-studio-backup.json` | Полный снимок текущих объёмов, поверхностей и источников; не становится пустым после автосохранения |
| **Скачать патч для Tiled** | `studio-patch.json` | Только ещё не записанная разница с подтверждённым исходником; после полного автосохранения разницы нет |
| **Скачать непрочитанный черновик** | Исходный текст черновика | Сохранить работу, которую не удалось восстановить из-за несовместимости или конфликта |

Полный снимок имеет `type: "world-studio-backup"`, `schemaVersion: 1`, ID и размеры карты. Он содержит контуры с внутренними исключениями, имена и папки разметки. Необязательный `editorPrefs` сохраняет глаз и замок для восстановления студии; эти настройки не меняют игровой рендер. PNG, коллизии и остальные слои Tiled в снимок не входят. Для резервной копии законченной работы скачивайте именно **JSON**, а не patch.

**Загрузить JSON** принимает снимок или patch до 1 МБ. Снимок заменяет текущую разметку освещения после проверки карты, ID, элементов, геометрии и условий уровней. Перед заменой скачайте свою копию. Восстановление можно отменить; при включённой автозаписи восстановленная разметка затем попадёт в проект.

Patch **v3** содержит создание, изменение и удаление объёмов, поверхностей и источников с `before`/`after`; имя и папка также входят в эти данные. Старые **v1/v2** принимаются. Импорт проверяет исходные `before` и свободные ID; устаревший patch отклоняется целиком.

Если запись проекта недоступна:

1. Скачайте `studio-patch.json`. Полный backup восстанавливается через **Загрузить JSON** в студии; CLI ожидает patch.
2. Сохраните и закройте карту в Tiled. Если меняли её отдельно, сначала выполните `npm run world:export` и сверяйте patch с актуальной версией.
3. Из корня проекта выполните:

   ```bash
   npm run world:lighting:apply -- ./studio-patch.json --check
   npm run world:lighting:apply -- ./studio-patch.json
   npm run world:export
   npm run world:check
   ```

4. Откройте карту заново и обновите приложение. Сохраните в Git `.tmj` вместе с generated-экспортом.

CLI сохраняет ID и условия существующих элементов, переносит `studioName`/`studioFolder` и не меняет остальные слои. `--check` проверяет без записи. Уже применённый patch v3 принимается повторно только при совпадении с `after`; конфликтующие данные не перезаписываются.

## Проверить результат

После разметки земли посмотрите, где заканчивается тень: она должна заканчиваться у границы принимающей поверхности. Проверяйте дневное солнце, ночь с ближайшим фонарём и несколько уровней дома. **Черновик / Сохранённое** сравнивает работу с последней подтверждённой версией проекта; после автосохранения сравнение использует уже записанный результат. В режиме **Сохранённое** редактирование заблокировано, черновик сохраняется.

Если объект «пропал», проверьте поиск и фильтры, его папку, активный уровень здания и видимость разметки. Если рисунок остался после удаления объёма, это ожидаемо: удалена геометрия света. Если тень из исходной картинки не поворачивается вместе с солнцем, это тоже ожидаемо: студия не меняет запечённое освещение PNG.
