# Tiled: что редактировать на нашей карте

Для настройки прогулок нужны **три слоя: `WalkAreas`, `Obstacles`, `PointsOfInterest`**. Для бабочек и светлячков — ещё два: `Habitats`, `WildlifeAnchors`. Остальные слои можно оставить как есть.

Открывайте `world/tiled/forest.tiled-project` → `forest.tmj`. Здесь — практическая памятка; точные свойства и ограничения всех объектов находятся в [справочнике Tiled](tiled-editor.md).

## Сначала сделать редактор удобным

1. В панели **Слои** выберите нужный слой. В панели **Объекты** найдите конкретный объект по имени — так проще, чем попадать по наложенным контурам.
2. Включите **Highlight Current Layer** клавишей **H**: текущий слой будет выделяться. Это настройка отображения редактора.
3. Заблокируйте остальные слои замками. **Terrain** с фоном лучше всегда держать заблокированным. Блокировка не меняет поведение игры.
4. Выключите сетку через **Ctrl+G**; на macOS — **⌘G**. Для наших контуров она обычно не нужна.
5. Если выбираются чужие объекты, в настройках Tiled найдите **Object selection behavior** и разрешите выбор только из текущих слоёв. Сверните ненужные списки объектов стрелками.

**Не сохраняйте карту со скрытыми «глазиком» слоями или объектами.** Наш экспортёр требует видимость и непрозрачность 100%. Если временно скрывали что-то для удобства, перед сохранением включите обратно. Замки, подсветка текущего слоя и сворачивание списка безопасны. Не собирайте слои в произвольные новые папки: экспортёр поддерживает только определённые группы, например существующую `WaterExclusions`.

| Действие | Инструмент / клавиша |
|---|---|
| Передвинуть точку или весь объект | **Select Objects — S** |
| Изменить отдельные вершины границы или маршрута | **Edit Polygons — O** |
| Создать точку | **Insert Point — I** |
| Создать контур | **Insert Polygon — P**, замкнуть нажатием на первую вершину |
| Создать незамкнутый маршрут | **P**, поставить вершины, закончить **Enter** |
| Дублировать объект со свойствами | **Ctrl+D / ⌘D**, затем задать новое уникальное имя |

Это стандартные сочетания Tiled 1.12.2; при своей раскладке смотрите подсказку инструмента. В прежней инструкции была ошибка: **E вставляет текст; вершины редактирует O**.

## Что означает каждый слой

| Слой | За что отвечает | Что обычно править |
|---|---|---|
| **WalkAreas** | Где Мохлику разрешено свободно ходить | Границу травы `home-clearing` |
| **Obstacles** | Что надо обходить на разрешённой земле | Контур основания камня `clearing-south-stone` |
| **PointsOfInterest** | Где Мохлик может остановиться и заняться делом | Точки осмотра, обнюхивания, отдыха и ухода за собой |
| **Habitats** | Где живут и обычно летают насекомые | Территории `clearing-butterflies`, `clearing-fireflies` и лесные `forest-*` |
| **WildlifeAnchors** | Конкретные места посадки и укрытия насекомых | Точки на нарисованных листьях, связанные с территорией |
| **Bushes** | Интерактивный куст: перекрытие героя листвой, укрытие и шевеление | Контур `clearing-bush`, точки `clearing-bush-entry` и `clearing-bush-hide` |
| **Mushrooms** | Где появляются игровые грибы | Точку основания `mushroom-1`; можно добавлять другие |
| **Lights** | Источники ночного света | Точки фонаря/факелов и их параметры; [инструкция по свету](world-lighting.md) |
| **WaterExclusions** | Где внутри воды не рисовать водные эффекты | Контуры листьев, камней, растений и причала |
| **Routes** | Точные подходы к дому/кусту и прежние прогулки по линиям | `home-approach`, `clearing-bush`; обычные линии нужны для прежнего режима |
| **Actors** | Начальная опора и размер героя | `mochlik-spawn`; без необходимости не переносить |
| **Clearing focus** | Какой участок показывает круг главного экрана | Рамку `clearing-focus`; это настройка камеры |
| **Buildings** | Изображение дома, его вход, порог, коллизия и область нажатия | Связанные объекты дома вместе; [порядок переноса](tiled-editor.md#переместить-здание-после-новой-разметки) |
| **Water** | Точная поверхность реки | Контур `river-main` |
| **Terrain** | Основной рисунок леса | Обычно ничего; фон держать под замком |

Большинство объектов — **разметка поверх рисунка**. Перемещение точки посадки не передвигает нарисованный лист, а изменение контура куста не переносит сам куст на фоне.

## Хочу настроить прогулки Мохлика

### 1. Разрешить ходить по нужной траве

Выберите **WalkAreas → home-clearing**, затем **O** и двигайте вершины. Контур должен охватывать свободную траву возле дома. Не ведите его через кусты, корни и другие предметы, которые Мохлик должен обходить.

Это **область**, а не последовательность движения: Мохлик сам выбирает цель и ищет путь внутри неё. Сетку маршрутизации вручную рисовать не надо.

Оставляйте запас от препятствий: проверяется круг опоры под ногами радиусом **5.6 единицы мира**, а не только центральная точка. Узкий проход шириной около 11 единиц уже не годится; делайте его заметно шире. `mochlik-spawn` и точки занятий должны оставаться на доступной земле.

### 2. Обозначить камень, который нужно обходить

В **Obstacles** поправьте `clearing-south-stone` или продублируйте его для нового препятствия. Обводите **занимаемое место на земле**, а не всю крону дерева. У копии задайте другое имя; сохраните строковое свойство `role: nav-obstacle`.

Вода и коллизия дома исключаются автоматически. `WaterExclusions` не превращает камень посреди реки в доступную сушу. Сам рисунок карты не распознаёт препятствия.

### 3. Выбрать места занятий

В **PointsOfInterest** двигайте точки инструментом **S**. Точка обозначает положение **ног**, а не головы. Новое место удобнее сделать копией подходящей точки с новым именем.

| Текущий объект | Строковое свойство `activity` | Занятие |
|---|---|---|
| `clearing-grass-look` | `look` | Осмотреться |
| `clearing-leaf-sniff` | `sniff` | Понюхать траву |
| `clearing-soft-grass-rest` | `rest` | Отдохнуть |
| `clearing-path-groom` | `groom` | Привести себя в порядок |

У всех этих точек остаётся строковое `role: interest`. Они должны быть доступны с учётом препятствий и опоры героя. Это варианты занятий: герой выбирает их с паузами и может гулять по другой свободной траве. Жёсткого расписания и обязательного обхода каждой точки нет.

**Обычные прогулки теперь меняются здесь, а не в Routes.** Линии `clearing-look`, `clearing-sniff`, `clearing-rest` сохранены для режима **Прежние маршруты**. Подходы `home-approach` и `clearing-bush` всё ещё используются — их не удаляйте. [Точные свойства навигации](tiled-editor.md#свободная-полянка-и-места-занятий).

## Хочу указать, откуда прилетает бабочка

1. В **Habitats** выберите `clearing-butterflies`. Его полигон обозначает домашнюю территорию бабочек возле поляны. Поправьте её границы инструментом **O**. Это не наземная коллизия: она относится только к насекомым. Полянка может служить исключением внутри большой лесной территории.
2. В **WildlifeAnchors** найдите `butterfly-north-leaf`. Передвиньте точку на подходящий нарисованный лист **внутри этой территории** — туда бабочка сможет сесть.
3. `butterfly-north-shelter` поставьте на защищённое место в листве той же территории. Это укрытие при неподходящей погоде или времени суток.
4. Для дополнительных посадок дублируйте точки, задавайте уникальные имена и сохраняйте связь `habitatId`.

| Объект | Пользовательские свойства |
|---|---|
| Территория `clearing-butterflies` | `role: wildlife-habitat`, `species: butterfly` — **string**; `capacity: 3` — **int** |
| Посадка `butterfly-north-leaf` | `role: wildlife-anchor`, `habitatId: clearing-butterflies`, `kind: rest` — всё **string** |
| Укрытие `butterfly-north-shelter` | Те же `role` и `habitatId`; `kind: shelter` — **string** |

Для светлячков принцип тот же: `species: firefly` и связь с нужной территорией светлячков. `capacity` — число особей на территории; общий предел сейчас **6 бабочек и 12 светлячков на всю карту**. Простое увеличение capacity не поднимает этот предел.

**Лес без повторной обводки центра:** у `forest-butterflies` уже установлено строковое `excludeHabitatId: clearing-butterflies`, у `forest-fireflies` — `excludeHabitatId: clearing-fireflies`. Правьте внешний контур forest и отдельно полянку clearing; игра сама вычитает полянку. В Tiled исходные полигоны могут перекрываться — в игре исключение уже действует. Лесные посадки должны оставаться снаружи этого выреза. DEV показывает его красным пунктиром.

Эти точки дают насекомым реальные места жизни; они не задают момент запуска сценки. Встреча зависит от доступной особи и состояния героя. Для проверки используйте запрос бабочки в DEV днём без дождя, светлячка — ночью; **Особи и их цели** покажет текущие позиции и цели. Днём видны только бабочки, ночью — только светлячки, даже при DEV «Включено». Птицы через `WildlifeAnchors` пока не настраиваются. [Полные правила](tiled-editor.md#территории-и-посадки-насекомых).

## Хочу поправить куст или поставить гриб

**Гриб:** в **Mushrooms** передвиньте `mushroom-1` к основанию будущей ножки. Для нового гриба — копия, другое имя и строковое `role: mushroom`. Мохлик подходит к выросшим грибам только там, куда может пройти. [Подробности](tiled-editor.md#расставить-грибы).

**Куст:** в верхнем слое **Bushes** контур `clearing-bush` обводит листья, `clearing-bush-entry` обозначает точку перед прыжком, `clearing-bush-hide` — место внутри листвы. `hide` должен находиться внутри **самого полигона**, с запасом для спрятавшегося тела; попадания в прямоугольную рамку выделения недостаточно. Ягоды отдельно размечать не надо.

При переносе `entry` поправьте конец одноимённого пути **Routes → clearing-bush**. Полная таблица свойств и допустимые расстояния — в [инструкции куста](tiled-editor.md#куст-контур-укрытие-и-подход).

**Не путайте похожие названия:**

- `WalkAreas → home-clearing` — проходимость; `Clearing focus → clearing-focus` — камера.
- `Bushes → clearing-bush` — листва; `Routes → clearing-bush` — путь к ней.
- `WaterExclusions → Bushes / Leaves` — маски водных эффектов; `WildlifeAnchors` — посадки насекомых.
- Пользовательское свойство **role** задаётся через **Добавить свойство**, тип **string**. Поле **Класс** его не заменяет. В `Water`, `WaterExclusions`, `Lights` добавлять role не нужно.

## Сохранить и увидеть результат

Из корня репозитория запустите приложение:

```bash
npm run dev:local
```

Во втором терминале запустите перенос сохранений:

```bash
npm run world:watch
```

Сохраните `forest.tmj` в Tiled и дождитесь **Exported**. **output unchanged** означает, что игровые данные не изменились. При ошибке игра продолжает использовать последний корректный экспорт — исправьте указанную причину и сохраните снова.

Проверяйте жизнь Мохлика в **основном приложении**, в круге и на большой карте. При необходимости обновите страницу. `/prototype/tiled-world` помогает смотреть геометрию, но не заменяет проверку живого поведения.

- Для прогулок: DEV → **Лесные сценки → Способ прогулки → Свободная полянка**. Затем в разделе **Постройки и разметка** включите **Проходимость и цель Мохлика**.
- Для насекомых: **Постройки и разметка → Особи и их цели**; подходящие время суток и погода.
- Для водной разметки: **Постройки и разметка → Границы воды**, затем дождь.

Без наблюдения выполните `npm run world:export`, затем `npm run world:check`. После правок карты в коммит входят `world/tiled/forest.tmj` и полученный `features/world/tiled/forest.generated.json`; второй файл вручную не редактируют.

## Если что-то пошло не так

| Симптом | Что проверить |
|---|---|
| `hide must be inside its leaf contour` | Координаты `clearing-bush-hide` должны быть внутри контура листьев, не просто его рамки |
| Ошибка `visible` или `opacity` | Включить скрытые слои/объекты, вернуть непрозрачность 100% |
| Мохлик не идёт к точке | Точка внутри WalkAreas, есть достаточно широкий проход, мешающих Obstacles/Water/коллизий нет |
| Меняю Routes, а прогулки прежние | В свободном режиме редактировать WalkAreas и PointsOfInterest; Routes нужны специальным подходам и прежнему режиму |
| После копирования экспорт ругается на объект | Дать копии уникальное имя, сохранить правильные типы свойств; сверить указанное в ошибке поле со справочником |
| Ошибка `inside excluded habitat` | Посадка леса оказалась в полянке: перенести точку или изменить её habitatId на подходящую территорию |
| Насекомое не садится на новую точку | Правильный habitatId, точка внутри соответствующего Habitats, подходящая погода/время; посмотреть цель в DEV |

**С чего начать сейчас:** уточните только `home-clearing`, проверьте обход камня и разместите четыре точки занятий на понравившейся траве. Затем поправьте посадки бабочек на листья. Вся остальная разметка уже работает и не требует повторной настройки.

Источники по редактору: [клавиши Tiled](https://doc.mapeditor.org/en/latest/manual/keyboard-shortcuts/), [настройка выбора объектов](https://doc.mapeditor.org/en/stable/manual/preferences/), [инструменты объектов](https://doc.mapeditor.org/en/stable/manual/objects/). Правила проходимости, свойств и экспорта выше относятся к нашему приложению.
