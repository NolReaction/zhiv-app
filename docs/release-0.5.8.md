# 0.5.8 — компактный главный экран и стеклянные окна

- Убран вращающийся индикатор отправки из игрового счётчика. Очередь тапов, повторы запросов, подтверждение рекорда и предупреждения об ошибках сохранены.
- Иконка сервера расположена по центру. Относительное и точное время последней отметки находятся в раскрытии по нажатию на неё; отдельной строки под кнопкой больше нет.
- Кнопки сервера и статуса используют общий стеклянный фон, обводку, блик, размер иконок и отклик на нажатие.
- Окна «Мой статус» и «Новая группа» оформлены как календарь: полупрозрачное стекло, анимация открытия/закрытия, отступы под безопасные области iPhone и ограниченная высота с прокруткой.
- При открытии статуса фокус получает заголовок, поэтому клавиатура появляется только после нажатия на поле. При закрытии фокус возвращается на кнопку статуса.
- Новые статусы ограничены 30 символами после нормализации пробелов. Проверка действует в интерфейсе, dev API, Kotlin API и репозитории. Кириллица и обычные emoji считаются одинаково; составные emoji могут занимать несколько кодовых точек Unicode.

Старые статусы длиннее 30 символов остаются целыми и доступными для чтения. При редактировании их нужно сократить перед сохранением. Срок действия, удаление статуса пустым полем и повтор запроса после потери ответа сохраняются.

Новых миграций нет: схема остаётся V22. Панель `/admin` и настройки мониторинга сохраняются. После получения выпуска в чистую ветку обновление VPS выполняется через `bash scripts/deploy-update.sh` с проверкой главной страницы и `/readyz`.
