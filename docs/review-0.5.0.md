# Ревью 0.5.0 — 7 сентября 2026

## Оценка

Как MVP для небольшого круга близких — **8/10**: основное действие понятно, доступ к отметкам управляется явно, вход сохраняет профиль между устройствами. Это оценка продукта по коду и присланным экранам, а не результат исследования пользователей или нагрузочного теста.

## Что исправлено в этом проходе

- Сообщения больше не участвуют в сетке страницы. Уведомление закрывается через 10 секунд видимого времени, показывает остаток, поддерживает паузу и ручное закрытие.
- Поиск учитывает имя и личную подпись, не меняет порядок людей.
- ID и резервный код копируются отдельно от системного действия «Поделиться».
- Настройки профиля собраны в последовательную колонку; статистика имеет собственную колонку на широком экране. Обещание загрузки аватарки перемещено в конец.
- Повтор использованного callback ВК не обменивает код заново. Возврат к профилю разрешён только с прежней привязкой браузера и действующей сессией.
- README сокращён, примеры секретов и восстановления тестовой БД актуализированы. Удалены только пустые заглушки снятого восстановления через друзей, три стартовых SVG без ссылок, неиспользуемые функции старого комбинированного копирования и связанные стили.

## Проверка безопасности и её границы

Проверены текущие отслеживаемые файлы, доступные локальные Git-объекты и исходные файлы в исторических ZIP. Подтверждённых действующих паролей, приватных ключей или токенов не обнаружено. Тестовые значения и публичные идентификаторы не считаются секретами.

Ревью затронуло авторизацию, привязку браузера, отзыв сеансов, восстановление, ограничения запросов, SQL и обращение с секретами. В проверенных изменениях блокирующих дефектов безопасности не выявлено. Проверка не охватывает недоступную или удалённую историю Git, содержимое секретов на VPS и секреты в изображениях; это не независимый аудит безопасности.

Автотесты проверяют логику Clipboard API, но не подтверждают физическую вставку на конкретном iPhone. После отложенного отказа браузер может потерять разрешение на legacy-копирование: приложение сообщает об отказе и оставляет полный код для ручного копирования. Веб-сайт также не может гарантированно убрать страницы ВК из системной истории Safari.

## Приоритеты следующих изменений

1. **Надёжность эксплуатации.** Автоматические резервные копии вне VPS, регулярное полное восстановление, уведомления о недоступности приложения, переполнении диска и сбоях отправки почты. Инструкции и CI не заменяют настройку на рабочем сервере.
2. **Проверки реальных сценариев.** Два пользователя на разных устройствах: вход, приглашение, отметка, скрытие через общую группу, повторный вход, отзыв второго сеанса. Отдельно Safari/PWA и встроенные браузеры, потеря сети во время запроса.
3. **Управление доступом.** Подсказка привязать второй способ входа; безопасная смена почты и отвязка провайдера с повторным подтверждением. Не разрешать случайно удалить последний доступный способ.
4. **Собственные данные.** Экспорт и удаление профиля самим пользователем с ясным описанием последствий для связей и истории. Административный сброс всей БД не заменяет эту возможность.
5. **Полезность каждый день.** Необязательные напоминания с тихими часами. Сначала проверить спрос и доставку уведомлений на реальных устройствах; не превращать отсутствие отметки в обещание обнаружить экстренную ситуацию.

## Отдельные вопросы о входе

**Объединение профилей.** Привязка второго способа внутри текущего профиля решает обычный сценарий. Если два профиля уже созданы, будущий мастер объединения должен отдельно подтвердить контроль обоих, показать сохраняемые данные и получить явное согласие. Автоматическое объединение по имени или похожей почте небезопасно; перенос истории также требует сохранить прежние ограничения видимости.

**Резервный код.** Оставить необязательным запасным способом. Он помогает при потере одновременно ВК и почты, но не должен выглядеть обязательным шагом обычного входа. Тексты теперь это объясняют.

**Яндекс ID.** Технически подходит: есть [официальный OAuth API для сайтов](https://yandex.ru/dev/id/doc/ru/). Я бы добавлял его после стабильной работы ВК и почты и по запросам пользователей. Почтовый вход уже принимает адреса Яндекса; новая кнопка прежде всего сокращает число действий, но добавляет ещё один сценарий поддержки.

Аватарки и новые игровые механики имеют меньший приоритет, чем сохранность профиля и предсказуемая доставка отметок.
