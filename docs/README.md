# Документация разработчика

Выберите задачу ниже. [Карта исходников](repository-guide.md) отвечает на вопрос «в каком файле это находится», а тематические инструкции — «как изменить и проверить». Тематические инструкции описывают текущий код приложения. Датированные исследования и выпущенные версии сохраняют прежние условия; это история проверки, а не действующий каталог.

Текущая версия в `master` — [0.6.7](releases/release-0.6.7.md): состав, границы и результаты проверок опубликованного кода. Развёртывание на сервере выполняется отдельно по эксплуатационной инструкции.
